This page is for the engineer or operator choosing where an instance runs. After reading it you will know which products work on which network for development and production instances, how to read the same list from the API, and what each refusal for a missing product means.

A product runs on a network only where Trusset has deployed its contracts for that instance type. Development instances use the network's testnet and production instances its mainnet, so the two environments of one network can differ. An instance can be created on any listed network, but on a network where nothing is deployed it can only do what needs no Trusset contract, such as customer verification against an identity register you control.

## Availability

| Network | Development instances | Production instances |
|---|---|---|
| Ethereum | Sepolia: Trusset ID Register, external securities lending, operator vaults, whitelists, liquidation bots, NFT lending, Financing (beta), stock tokens, commodity tokens, equity shares, price indexes | Not yet available |
| Polygon PoS | Polygon Amoy: not yet available | Polygon: Trusset ID Register, external securities lending, operator vaults, whitelists, liquidation bots |
| Arbitrum One, Avalanche C-Chain, Base, BNB Smart Chain, Gnosis Chain, Hedera, Optimism, XRP Ledger (EVM Sidechain), ZKsync Era | Not yet available | Not yet available |
| Solana, Stellar, Aptos, Tezos, Canton | Not yet available | Not yet available |

Stock lending, commodity lending, Tether Gold lending and the earlier external securities lending generation run on Ethereum development instances only. Every other network answers them with `501` and the code of the family, listed under [refusals](#refusals-for-a-missing-product).

<Note>
Own register mode works on every EVM network, including those marked not yet available. An instance bound to an ERC-3643 identity registry or a Trusset-compatible register you deploy verifies customers there without any Trusset contract. Bind it under **Identity Register** in the instance settings of the Issuer Portal.
</Note>

The Create Instance dialog of the Issuer Portal reads the same list. A network marked not yet available for the chosen instance type cannot be selected, and the line under the network field names the products that run on the selected one.

## Read availability from the API

`GET /public/networks` returns the list above, derived from the contract addresses Trusset has configured for each network. It needs no API key, allows 60 requests a minute per address and may be cached for five minutes.

```bash
curl https://api.trusset.org/public/networks
```

```json
{
  "success": true,
  "data": {
    "families": [
      { "id": "IDENTITY_REGISTER", "label": "Trusset ID Register", "group": "identity" },
      { "id": "LENDING", "label": "External securities lending", "group": "lending" }
    ],
    "networks": [
      {
        "network": "POLYGON",
        "label": "Polygon PoS",
        "vm": "evm",
        "environments": {
          "DEVELOPMENT": { "environment": "DEVELOPMENT", "chainId": 80002, "name": "Polygon Amoy", "testnet": true, "available": false, "families": [] },
          "PRODUCTION": {
            "environment": "PRODUCTION",
            "chainId": 137,
            "name": "Polygon",
            "testnet": false,
            "available": true,
            "families": [
              { "id": "IDENTITY_REGISTER", "label": "Trusset ID Register", "group": "identity", "address": "0x7AacF15EBbe3cDb829ef2027a4825011dA2A19c9" },
              { "id": "LENDING", "label": "External securities lending", "group": "lending", "address": "0xcE944846fc2038369c1fb7Ba15Fc4faCB2da448A" }
            ]
          }
        }
      }
    ]
  },
  "metadata": { "timestamp": "2026-10-28T09:00:00.000Z" }
}
```

The example is shortened: the response carries every family in `families` and every network in `networks`.

| Field | Meaning |
|---|---|
| `families` | Every product family the list reports on, with its `id`, `label` and `group` (`identity`, `lending` or `tokenization`) |
| `networks[].network` | The network value an instance is created with, such as `ETHEREUM` or `POLYGON` |
| `networks[].environments.DEVELOPMENT` / `.PRODUCTION` | The testnet behind development instances and the mainnet behind production instances |
| `available` | `true` when at least one family is deployed there |
| `families[].address` | The contract the family runs through on that chain: the register, or the factory that deploys its markets, vaults, whitelists or bots |

Family ids: `IDENTITY_REGISTER`, `LENDING`, `VAULTS`, `WHITELISTS`, `LIQUIDATION_BOTS`, `NFT_LENDING`, `FINANCING`, `STOCK_TOKENS`, `COMMODITY_TOKENS`, `EQUITY_SHARES`, `PRICE_INDEXES`.

## Production access

Production instances need access granted by Trusset. Without it, creating a production instance is refused with `403 PRODUCTION_ACCESS_REQUIRED`, in the Issuer Portal and on `POST /instances/app` alike. Request access by email to hello@trusset.de, or with **Request access** next to Production in the Create Instance dialog. Until it is granted, create development instances.

A development instance does not convert into a production one. To go live, create a production instance on a network where the products you need run, and point your integration at its API keys.

## Refusals for a missing product

A product that is not deployed for the instance's network and type is refused with HTTP `501`. The answer stays the same until Trusset deploys the product there, so do not retry it. The SDK does not retry a `501`. The message names the network, the instance type and where the product is available.

| Code | HTTP | Meaning | Next step |
|---|---|---|---|
| `SECURITY_LENDING_V2_NOT_CONFIGURED` | `501` | External securities lending is not deployed for the instance's network and type | Use an instance on a network where `LENDING` is available |
| `SECURITY_LENDING_NFT_NOT_CONFIGURED` | `501` | NFT lending is not deployed there | Use an instance on a network where `NFT_LENDING` is available |
| `SECURITY_LENDING_NOT_CONFIGURED` | `501` | The earlier external securities lending generation is not deployed there | Create new markets as external securities lending markets |
| `VAULTS_NOT_CONFIGURED` | `501` | The operator vault factory is not deployed there | Use an instance on a network where `VAULTS` is available |
| `ACCESS_LISTS_NOT_CONFIGURED` | `501` | The whitelist factory is not deployed there | Gate on an identity register instead, or use a network where `WHITELISTS` is available |
| `SHIM_NOT_CONFIGURED` | `501` | The liquidation bot factory is not deployed there | Liquidate from your own wallet, or use a network where `LIQUIDATION_BOTS` is available |
| `STOCK_LENDING_NOT_CONFIGURED` | `501` | Stock lending runs on Ethereum instances only | Use the lending families the message names for this network |
| `COMMODITY_LENDING_NOT_CONFIGURED` | `501` | Commodity lending runs on Ethereum instances only | Use the lending families the message names for this network |
| `TETHER_GOLD_LENDING_NOT_CONFIGURED` | `501` | Tether Gold lending runs on Ethereum instances only | Use the lending families the message names for this network |
| `IDENTITY_REGISTRY_NOT_CONFIGURED` | `501` | The instance writes to the Trusset ID Register, which is not deployed for its network and type | Bind an identity register you control under **Identity Register** in the instance settings |
| `TRUSSET_REGISTRY_UNAVAILABLE` | `409` | Trusset register mode was chosen in the instance settings on a network and type without the Trusset ID Register | Choose Own register and bind a register you control |
| `PRODUCTION_ACCESS_REQUIRED` | `403` | A production instance was requested by an account without production access | Request access at hello@trusset.de, or create a development instance |
