---
title: 'List RFQ Quotes'
api: 'GET /orderbooks/stocks/api/rfq/{id}/quotes'
description: 'Read the quotes on one request, oldest first'
---

Returns an RFQ together with its quotes in submission order. This is the polling endpoint: open a request, then read this until a quote you want appears or the request expires.

Ordering is by arrival, not by price. Pick the best executable quote yourself, and check `validUntil` before accepting, since a quote can expire between two polls.

Only quotes with `status: ACTIVE` can be accepted.

## Path Parameters

<ParamField path="id" type="string" required>RFQ ID.</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="rfq" type="object">
      The request itself, including its own `quotes` array. Same shape as [Get RFQ](/endpoints/stock-trading/get-rfq).
    </ResponseField>
    <ResponseField name="quotes" type="array">
      Quotes on this request, oldest first.
      <Expandable>
        <ResponseField name="id" type="string">Quote ID.</ResponseField>
        <ResponseField name="lpAddress" type="string">Liquidity provider's wallet.</ResponseField>
        <ResponseField name="lpAccountId" type="string">Provider's trading account, or `null`.</ResponseField>
        <ResponseField name="price" type="string">Quoted price in order book units.</ResponseField>
        <ResponseField name="validUntil" type="string">When the quote stops being executable.</ResponseField>
        <ResponseField name="lockId" type="string">Balance lock committing the provider's funds.</ResponseField>
        <ResponseField name="status" type="string">`ACTIVE`, `ACCEPTED`, `EXPIRED` or `WITHDRAWN`.</ResponseField>
        <ResponseField name="createdAt" type="string">ISO 8601 timestamp.</ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/orderbooks/stocks/api/rfq/clx_rfq_0091/quotes" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/orderbooks/stocks/api/rfq/${rfqId}/quotes`,
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { data } = await res.json();

const now = Date.now();
const best = data.quotes
  .filter((q: any) => q.status === 'ACTIVE' && Date.parse(q.validUntil) > now)
  .sort((a: any, b: any) =>
    data.rfq.side === 'BUY' ? Number(a.price) - Number(b.price) : Number(b.price) - Number(a.price)
  )[0];
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `INVALID_PARAM` | `400` | `id` is missing or longer than 100 characters |
| `NOT_FOUND` | `404` | No RFQ with that ID on your instance |
| `SERVICE_NOT_ENABLED` | `403` | The Trading service is not enabled on this instance |
