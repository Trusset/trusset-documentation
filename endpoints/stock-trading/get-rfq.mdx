---
title: 'Get RFQ'
api: 'GET /orderbooks/stocks/api/rfq/{id}'
description: 'Read one request for quote and the quotes attached to it'
---

Returns an RFQ with every quote that has been submitted against it, in whatever state each is in. Only RFQs opened by your own instance resolve; anything else reads as not found.

Status tells you what is still possible. `PENDING` and `QUOTED` accept an acceptance or a cancellation. `ACCEPTED`, `CANCELLED` and `EXPIRED` are terminal.

## Path Parameters

<ParamField path="id" type="string" required>RFQ ID.</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="id" type="string">RFQ ID.</ResponseField>
    <ResponseField name="instanceId" type="string">Your instance.</ResponseField>
    <ResponseField name="requesterAddress" type="string">Requesting wallet.</ResponseField>
    <ResponseField name="baseToken" type="string">Base token.</ResponseField>
    <ResponseField name="quoteToken" type="string">Quote token.</ResponseField>
    <ResponseField name="custodyContract" type="string">Custody contract.</ResponseField>
    <ResponseField name="side" type="string">`BUY` or `SELL`.</ResponseField>
    <ResponseField name="baseAmount" type="string">Requested size in order book units.</ResponseField>
    <ResponseField name="status" type="string">`PENDING`, `QUOTED`, `ACCEPTED`, `CANCELLED` or `EXPIRED`.</ResponseField>
    <ResponseField name="expiresAt" type="string">ISO 8601 deadline.</ResponseField>
    <ResponseField name="createdAt" type="string">ISO 8601 timestamp.</ResponseField>
    <ResponseField name="updatedAt" type="string">ISO 8601 timestamp.</ResponseField>
    <ResponseField name="quotes" type="array">
      <Expandable>
        <ResponseField name="id" type="string">Quote ID. Pass it to [Accept Quote](/endpoints/stock-trading/accept-rfq-quote).</ResponseField>
        <ResponseField name="quoteRequestId" type="string">RFQ this quote answers.</ResponseField>
        <ResponseField name="lpAddress" type="string">Liquidity provider's wallet.</ResponseField>
        <ResponseField name="lpAccountId" type="string">Provider's trading account, or `null`.</ResponseField>
        <ResponseField name="price" type="string">Quoted price in order book units.</ResponseField>
        <ResponseField name="validUntil" type="string">When the quote stops being executable.</ResponseField>
        <ResponseField name="lockId" type="string">Balance lock committing the provider's funds, or `null`.</ResponseField>
        <ResponseField name="status" type="string">`ACTIVE`, `ACCEPTED`, `EXPIRED` or `WITHDRAWN`.</ResponseField>
        <ResponseField name="createdAt" type="string">ISO 8601 timestamp.</ResponseField>
        <ResponseField name="updatedAt" type="string">ISO 8601 timestamp.</ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<Note>
  A quote's `validUntil` is capped at the RFQ's own `expiresAt`, so a quote never outlives the request it answers.
</Note>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/orderbooks/stocks/api/rfq/clx_rfq_0091" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/orderbooks/stocks/api/rfq/${rfqId}`,
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { data } = await res.json();
const live = data.quotes.filter((q: any) => q.status === 'ACTIVE');
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `INVALID_PARAM` | `400` | `id` is missing or longer than 100 characters |
| `NOT_FOUND` | `404` | No RFQ with that ID on your instance |
| `SERVICE_NOT_ENABLED` | `403` | The Trading service is not enabled on this instance |
