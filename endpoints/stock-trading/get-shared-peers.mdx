---
title: 'Get Shared Peers'
description: 'List instances that share liquidity on an order book'
api: 'GET /orderbooks/stocks/api/order-books/{orderBookId}/shared-peers'
---

Returns the set of instances that share liquidity on this order book. Shared peers are the other instances that have imported the book (or whose book this instance has imported), forming a single combined liquidity pool routed across per-instance relayers.

## Authentication

Requires an instance API key with the `trading` service enabled.

## Path Parameters

<ParamField path="orderBookId" type="string" required>
  The order book identifier. Max 100 characters.
</ParamField>

<RequestExample>
```bash
curl -X GET "https://api.trusset.org/orderbooks/stocks/api/order-books/ob_abc123/shared-peers" \
  -H "x-api-key: trusset_{instanceRef}_{secret}"
```
</RequestExample>

## Error Codes

| Code | Status | Description |
|------|--------|-------------|
| `ORDER_BOOK_NOT_FOUND` | 404 | No order book found with this ID in your instance |
