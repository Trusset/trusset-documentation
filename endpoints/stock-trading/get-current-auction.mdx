---
title: 'Get Current Auction'
description: 'Retrieve the active auction for an order book'
api: 'GET /orderbooks/stocks/api/order-books/{orderBookId}/auctions/current'
---

Returns the auction currently collecting or matching on an order book. Applies to books running in `PERIODIC_AUCTION` mode, or in `HYBRID` mode while batching. The indicative price and volume reflect where the auction would clear if it ran at the time of the request.

## Authentication

Requires an instance API key with the `trading` service enabled.

## Path Parameters

<ParamField path="orderBookId" type="string" required>
  The order book identifier. Max 100 characters.
</ParamField>

<RequestExample>
```bash
curl -X GET "https://api.trusset.org/orderbooks/stocks/api/order-books/ob_abc123/auctions/current" \
  -H "x-api-key: trusset_{instanceRef}_{secret}"
```
</RequestExample>

## Error Codes

| Code | Status | Description |
|------|--------|-------------|
