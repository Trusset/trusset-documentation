---
title: 'List Order Books'
api: 'GET /orderbooks/stocks/api/order-books'
description: 'List the stock order books your instance owns or has imported'
---

Returns every stock order book on your instance, followed by every book you have imported from another instance. The list is filtered to `tokenType: STOCK_TOKEN`, so an off-chain book created without an explicit `tokenType` will not appear here. Owned books are ordered newest first.

Imported books carry two extra fields, `_imported` and `_importId`, which owned books do not have. `_importId` is what [Remove Import](/endpoints/stock-trading/remove-import) takes.

## Query Parameters

<ParamField query="status" type="string">
  Restrict to one status: `ACTIVE`, `PAUSED` or `CLOSED`. Applies to owned and imported books alike. Omit for all statuses.
</ParamField>

## Response Fields

`data` is an array of order book records. Each entry carries the same fields as [Get Order Book](/endpoints/stock-trading/get-order-book), plus:

<ResponseField name="_imported" type="boolean">
  Present and `true` only on imported books.
</ResponseField>

<ResponseField name="_importId" type="string">
  Present only on imported books. Pass it to [Remove Import](/endpoints/stock-trading/remove-import).
</ResponseField>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/orderbooks/stocks/api/order-books?status=ACTIVE" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(
  'https://api.trusset.org/orderbooks/stocks/api/order-books?status=ACTIVE',
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { data } = await res.json();

const owned = data.filter((b: any) => !b._imported);
const imported = data.filter((b: any) => b._imported);
```
</RequestExample>
