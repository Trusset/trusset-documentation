---
title: 'Get Price Reference History'
description: 'Retrieve historical reference price points for an order book'
api: 'GET /orderbooks/stocks/api/order-books/{orderBookId}/price-reference/history'
---

Returns a paginated list of historical reference price points for an order book, ordered by most recent first. Each point records the reference price and its source at the time it was captured.

## Authentication

Requires an instance API key with the `trading` service enabled.

## Path Parameters

<ParamField path="orderBookId" type="string" required>
  The order book identifier. Max 100 characters.
</ParamField>

## Query Parameters

<ParamField query="limit" type="integer">
  Number of points to return. Default `50`, maximum `100`.
</ParamField>

<ParamField query="offset" type="integer">
  Offset for pagination. Default `0`.
</ParamField>

<RequestExample>
```bash
curl -X GET "https://api.trusset.org/orderbooks/stocks/api/order-books/ob_abc123/price-reference/history?limit=20" \
  -H "x-api-key: trusset_{instanceRef}_{secret}"
```
</RequestExample>

| Code | Status | Description |
|------|--------|-------------|
