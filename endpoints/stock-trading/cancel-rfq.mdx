---
title: 'Cancel RFQ'
api: 'POST /orderbooks/stocks/api/rfq/{id}/cancel'
description: 'Withdraw an open request and release the quotes against it'
---

Cancels an RFQ you opened. Only the original `requesterAddress` may cancel.

Cancelling withdraws every live quote and releases the funds each provider had committed, so it is the courteous way to close a request you no longer want rather than letting it expire. Providers get their inventory back immediately instead of at the next sweep.

An RFQ that is already `ACCEPTED`, `CANCELLED` or `EXPIRED` is returned unchanged. The call succeeds, so a retry is safe.

## Idempotency

Accepts an optional `Idempotency-Key` header.

## Path Parameters

<ParamField path="id" type="string" required>RFQ ID.</ParamField>

## Body Parameters

<ParamField body="requesterAddress" type="string" required>
  Must equal the RFQ's `requesterAddress`.
</ParamField>

## Response Fields

Returns the RFQ with its quotes, in the same shape as [Get RFQ](/endpoints/stock-trading/get-rfq). Live quotes now read `WITHDRAWN`.

<Note>
  Releasing a provider's committed funds is a custody operation. Where that release needs a signature that is not available, the release is retried by the balance lock reconciler rather than failing the cancel: the RFQ is cancelled either way.
</Note>

<RequestExample>
```bash cURL
curl -X POST "https://api.trusset.org/orderbooks/stocks/api/rfq/clx_rfq_0091/cancel" \
  -H "X-API-Key: trusset_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{ "requesterAddress": "0xabc7f1093d5e26b804a1c3f78de025916b47c0d3" }'
```
```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/orderbooks/stocks/api/rfq/${rfqId}/cancel`,
  {
    method: 'POST',
    headers: {
      'X-API-Key': 'trusset_your_key_here',
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({ requesterAddress: await wallet.getAddress() })
  }
);
const { data } = await res.json();
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `VALIDATION_ERROR` | `400` | `requesterAddress` is missing or not an address |
| `INVALID_PARAM` | `400` | `id` is missing or longer than 100 characters |
| `FORBIDDEN` | `403` | The caller is not the RFQ's requester |
| `NOT_FOUND` | `404` | No RFQ with that ID on your instance |
| `IDEMPOTENCY_MISMATCH` | `409` | The key was used before with a different body |
| `SERVICE_NOT_ENABLED` | `403` | The Trading service is not enabled on this instance |
