---
title: 'Approve Security'
api: 'POST /orderbooks/external-securities/api/order-books/{orderBookId}/security-approval'
description: 'Build the approval a seller needs when the security is delivered by allowance'
---

Returns unsigned `approve` calldata letting the custody contract deliver the security from a seller's wallet at settlement.

Sellers need this only when the security uses `TRANSFER` delivery. The custody contract then moves the security with `transferFrom`, and the token runs its own transfer rules. Without an allowance a sell order's tradable balance reads as zero, because the venue reports the lesser of the unfrozen balance and the allowance. A security under `AGENT` delivery moves by forced transfer and ignores this allowance. See [Delivery modes](/endpoints/external-securities-trading/introduction#delivery-modes).

The transaction is signed by the seller and targets the security token. [Prepare Order](/endpoints/external-securities-trading/prepare-order) reports the amount a sell order needs in `approval.required`, which covers the order and the seller's other resting sell orders together. The custody contract can only use the allowance to settle a sell order the seller signed.

## Path Parameters

<ParamField path="orderBookId" type="string" required>
  Order book whose security and custody contract the approval is for. Must be `ACTIVE` and reachable from your instance.
</ParamField>

## Body Parameters

<ParamField body="amount" type="string" required>
  Allowance to set, in the security's base units, as a digit-only string. This replaces any existing allowance rather than adding to it.
</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="action" type="string">`SIGN_TRANSACTION`.</ResponseField>
    <ResponseField name="transaction" type="object">
      <Expandable>
        <ResponseField name="to" type="string">The security token contract.</ResponseField>
        <ResponseField name="data" type="string">Encoded `approve` calldata.</ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="functionName" type="string">`approve`.</ResponseField>
    <ResponseField name="description" type="string">The spender and amount the approval covers.</ResponseField>
  </Expandable>
</ResponseField>

<Note>
  Read the current allowance from `securityAllowance` on [Get Security Status](/endpoints/external-securities-trading/get-security-status).
</Note>

<RequestExample>
```bash cURL
curl -X POST "https://api.trusset.org/orderbooks/external-securities/api/order-books/clx_ob_extsec_001/security-approval" \
  -H "X-API-Key: trusset_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{ "amount": "10000000000000000000" }'
```
```typescript TypeScript
const prep = await fetch(
  'https://api.trusset.org/orderbooks/external-securities/api/orders/prepare',
  {
    method: 'POST',
    headers: { 'X-API-Key': 'trusset_your_key_here', 'Content-Type': 'application/json' },
    body: JSON.stringify({ orderBookId, userAddress: await seller.getAddress(), side: 'SELL', price, quantity })
  }
).then(r => r.json());

const approval = prep.data.approval;
if (approval && !approval.sufficient) {
  const res = await fetch(
    `https://api.trusset.org/orderbooks/external-securities/api/order-books/${orderBookId}/security-approval`,
    {
      method: 'POST',
      headers: { 'X-API-Key': 'trusset_your_key_here', 'Content-Type': 'application/json' },
      body: JSON.stringify({ amount: approval.required })
    }
  );
  const { data } = await res.json();
  const tx = await seller.sendTransaction(data.transaction);
  await tx.wait();
}
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `VALIDATION_ERROR` | `400` | `amount` is missing or not a digit-only string |
| `INSTANCE_REQUIRED` | `400` | The request carried no resolvable instance |
| `ORDER_BOOK_INACTIVE` | `400` | The book is `PAUSED` or `CLOSED` |
| `ORDER_BOOK_NOT_FOUND` | `404` | The book does not exist, is not reachable, or is not an external securities book |
| `SERVICE_NOT_ENABLED` | `403` | The Trading service is not enabled on this instance |
