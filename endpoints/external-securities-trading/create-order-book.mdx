---
title: 'Create Order Book'
api: 'POST /orderbooks/external-securities/api/order-books'
description: 'Open a trading venue for an imported security'
---

Creates an order book for one imported security token quoted in one settlement asset. Three properties are fixed by this venue and cannot be overridden: settlement is always on-chain, the token type is always an external security, and the trading mode is always continuous.

The book cannot be created until its on-chain prerequisites hold. See [Custody setup](/endpoints/external-securities-trading/introduction#custody-setup). New books are created on the current custody contract of your network.

<Warning>
  Generation 2 of the custody contract is not deployed on any network yet. Until it is, `deliveryMode` `TRANSFER`, `access` gates and tokens without an identity registry are refused with `409 CUSTODY_UPGRADE_REQUIRED`. Read `generation` on [Get Custody Contract](/endpoints/external-securities-trading/get-custody-contract) first. On generation 1, book an ERC-3643 token and leave `deliveryMode` and the gates out; `access.onboarding` still applies to buyers the security's identity registry refuses.
</Warning>

One instance may hold a single open book per pair. If an `ACTIVE` or `PAUSED` book already quotes this pair, the request returns `ORDER_BOOK_EXISTS`.

## Body Parameters

<ParamField body="tokenAddress" type="string" required>
  The security token. Must be imported into your instance and readable on chain. On generation 2 an ERC-3643 token can use either delivery mode, and a token without an identity registry, such as an ERC-1400 or plain ERC-20 security, uses allowance delivery and needs a buyer gate. On generation 1 only an ERC-3643 token with an identity registry can be booked.
</ParamField>

<ParamField body="quoteTokenAddress" type="string" required>
  Settlement asset the security is quoted in. Must be authorized for this security on the custody contract, which is one of the setup steps. Must differ from `tokenAddress`.
</ParamField>

<ParamField body="name" type="string" required>Display name, 1 to 64 characters.</ParamField>

<ParamField body="symbol" type="string" required>Display symbol, 1 to 16 characters.</ParamField>

<ParamField body="settlementOperator" type="string" required>
  Wallet that will sign settlement transactions for this book. It must be authorized on the custody contract for this security, which is one of the setup steps. It also signs the `accessGates` step when you request access gates, because the gates apply to the settlements this wallet sends. Naming a wallet you control is what lets settlements be driven through this API.
</ParamField>

<ParamField body="underlyingIdentifier" type="string">
  Instrument identifier, 1 to 31 characters, trimmed and upper-cased. An ISIN, a WKN, or an issuer's own reference.

  Required when the security is not yet registered on the custody contract, because registration writes this identifier on chain. Optional afterwards, and if supplied it must match what is already registered, otherwise `ISIN_MISMATCH`. The stored value always comes from the chain.
</ParamField>

<ParamField body="custodyContract" type="string">
  Custody contract to use. Defaults to the address from [Get Custody Contract](/endpoints/external-securities-trading/get-custody-contract). Any other address is refused with `INVALID_CONFIG`.
</ParamField>

<ParamField body="deliveryMode" type="string">
  `AGENT` or `TRANSFER`. See [Delivery modes](/endpoints/external-securities-trading/introduction#delivery-modes).

  For a security that is not registered yet, this is the mode it is registered with. It defaults to `AGENT` when the token has an identity registry and to `TRANSFER` when it has none. `AGENT` on a token without an identity registry is refused with `INVALID_CONFIG`.

  For a security that is already registered, the mode on chain applies. A different value is refused with `DELIVERY_MODE_MISMATCH`.
</ParamField>

<ParamField body="access" type="object">
  Who may trade on the book. See [Access module](/endpoints/external-securities-trading/introduction#access-module). `buyer` and `seller` gates need custody generation 2; `onboarding` works on both generations.
  <Expandable>
    <ParamField body="buyer" type="object">
      Buyer gate, or `null` for none. Name exactly one source.
      <Expandable>
        <ParamField body="profile" type="string">Key of a verification profile on your instance: up to 60 letters, digits, `_` or `-`. Its [eligibility register](/endpoints/customers/introduction#eligibility-registers) becomes the gate.</ParamField>
        <ParamField body="accessList" type="string">ID of a whitelist of your instance: up to 64 letters, digits, `_` or `-`.</ParamField>
        <ParamField body="register" type="string">Address of any contract that answers `isVerified(address)`.</ParamField>
      </Expandable>
    </ParamField>
    <ParamField body="seller" type="object">Seller gate, or `null` for none. Same shape as `buyer`.</ParamField>
    <ParamField body="onboarding" type="object">
      What a wallet the gates refuse is told.
      <Expandable>
        <ParamField body="mode" type="string" required>`NONE`, `VERIFICATION_SERVICE`, `ID_LINK` or `INTEGRATION`.</ParamField>
        <ParamField body="url" type="string">Your own onboarding page, used in `INTEGRATION` mode only. Must be an HTTPS address on a public host.</ParamField>
      </Expandable>
    </ParamField>
  </Expandable>

  Each gate is checked before any step is built: it must be a contract and must answer `isVerified(address)`, otherwise `ACCESS_GATE_INCOMPATIBLE`. A security without an identity registry needs a buyer gate, otherwise `BUYER_GATE_REQUIRED`. Gates apply per security and settlement operator, so another open book of the same operator on the same security must use the same gates, otherwise `ACCESS_GATES_SHARED`. When the gates on chain differ from the ones requested, the setup steps include `accessGates` for the settlement operator to sign. The policy is saved with the book.
</ParamField>

<ParamField body="priceFeed" type="object">
  Where the reference price comes from. See [Price feed module](/endpoints/external-securities-trading/introduction#price-feed-module). When sent, it sets `priceRefMode`, `priceRefFeedUrl`, `priceRefFeedPath` and `priceRefFeedHeaders` for you.
  <Expandable>
    <ParamField body="source" type="string" required>`MANUAL`, `STOCK`, `COMMODITY` or `CUSTOM`.</ParamField>
    <ParamField body="symbol" type="string">`STOCK`: the ticker of the listing, with its exchange MIC after a colon for a listing outside the US, such as `SAP:XETR` or `AIR:XPAR`. A bare ticker such as `AAPL` reads the US listing. `COMMODITY`: `XAU`, `XAG`, `XPT` or `XPD`.</ParamField>
    <ParamField body="unit" type="string" default="TROY_OUNCE">`COMMODITY` only: what one token represents, `TROY_OUNCE`, `GRAM` or `KILOGRAM`.</ParamField>
    <ParamField body="url" type="string">`CUSTOM` only: HTTPS feed endpoint on a public host.</ParamField>
    <ParamField body="path" type="string">`CUSTOM` only: dotted JSON path to the price, such as `data.price`.</ParamField>
    <ParamField body="headers" type="string">`CUSTOM` only: request headers as a JSON string. Write-only.</ParamField>
  </Expandable>
</ParamField>

<ParamField body="minOrderSize" type="string" default="0">Smallest accepted quantity, in order book units.</ParamField>

<ParamField body="maxOrderSize" type="string">Largest accepted quantity, in order book units.</ParamField>

<ParamField body="tickSize" type="string" default="1">
  Price increment, in order book units. Enforced when an order is submitted: a price that is not a multiple is refused with `INVALID_PRICE`. [Prepare Order](/endpoints/external-securities-trading/prepare-order) does not check it, so a payload can be built at an off-tick price and then rejected on submission.
</ParamField>

<ParamField body="makerFeeBps" type="integer" default="0">Maker fee in basis points, 0 to 1000. Recorded on each trade for your own invoicing, never deducted at settlement. See [Units and decimals](/endpoints/external-securities-trading/introduction#units-and-decimals).</ParamField>

<ParamField body="takerFeeBps" type="integer" default="0">Taker fee in basis points, 0 to 1000. Recorded the same way as `makerFeeBps`.</ParamField>

<ParamField body="mmMakerRebateBps" type="integer">
  Fee applied in place of `makerFeeBps` when the resting side is a market maker account, −1000 to 1000. A negative value records a rebate for the market maker. Like the other fees, it is recorded on the trade and never paid out at settlement.
</ParamField>

<ParamField body="allowImport" type="boolean" default="false">
  Publish the book so other instances on the same network can import it.
</ParamField>

<ParamField body="allowSharedLiquidity" type="boolean" default="false">
  Pool depth with other books quoting the same instrument identifier. See [Shared liquidity](/endpoints/external-securities-trading/introduction#shared-liquidity).
</ParamField>

<ParamField body="priceRefEnabled" type="boolean" default="false">Enforce a reference price band on incoming orders.</ParamField>

<ParamField body="priceRefMode" type="string" default="MANUAL">`MANUAL`, `STOCK_FEED`, `COMMODITY_FEED` or `EXTERNAL_FEED`. Prefer `priceFeed`, which sets this for you.</ParamField>

<ParamField body="priceRefFeedUrl" type="string">HTTPS feed endpoint, up to 2048 characters. Must resolve to a public host.</ParamField>

<ParamField body="priceRefFeedHeaders" type="string">Feed request headers as a JSON string, up to 4096 characters. Write-only: reads return `"********"` in their place.</ParamField>

<ParamField body="priceRefFeedPath" type="string">JSON path to the price, the ticker symbol in `STOCK_FEED` mode, or the metal and unit in `COMMODITY_FEED` mode, such as `XAU:GRAM`.</ParamField>

<ParamField body="priceRefEnforcement" type="string" default="EVERY_TRADE">Refresh interval, from `EVERY_TRADE` to `1DAY`.</ParamField>

<ParamField body="priceRefSpreadBps" type="integer">Band half-width in basis points, 1 to 10000.</ParamField>

<ParamField body="priceRefHaltOnStale" type="boolean" default="false">Refuse orders when the reference is stale.</ParamField>

<ParamField body="priceRefStaleTolerance" type="integer">Staleness window in seconds, 60 to 604800.</ParamField>

<ParamField body="priceRefCircuitBreakerBps" type="integer">Reference move in basis points that pauses the book, 10 to 10000.</ParamField>

<ParamField body="custodySetupTxs" type="object">
  Hashes of the setup transactions you signed after a `CUSTODY_SETUP_REQUIRED` refusal, keyed by the step key. Unknown keys are rejected. A setup transaction sent through a Safe, an EIP-7702 account or an ERC-4337 smart account is accepted: the API reads the call the smart account made to the custody contract or the security token from the transaction's call trace.
  <Expandable>
    <ParamField body="agentRole" type="string">Hash of `addAgent` or `addController` on the security token.</ParamField>
    <ParamField body="security" type="string">Hash of `registerSecurity` or `registerSecurityWithMode` on the custody contract.</ParamField>
    <ParamField body="quoteAsset" type="string">Hash of `setQuoteAsset` on the custody contract.</ParamField>
    <ParamField body="operator" type="string">Hash of `setOperator` on the custody contract.</ParamField>
    <ParamField body="accessGates" type="string">Hash of `setAccessGates` on the custody contract. It must be signed by the settlement operator, because the gates apply to the wallet that signs it.</ParamField>
  </Expandable>
</ParamField>

## What is read from the chain

Both tokens' decimals are read at creation and recorded on the book, so every later conversion between order book units and on-chain amounts uses the real numbers rather than a default. A token that reports unusable decimals is refused with `TOKEN_METADATA_UNAVAILABLE`.

If the RPC endpoint for your instance does not answer, the request fails with `CHAIN_UNAVAILABLE` rather than reporting the prerequisites as unmet. No book is created and nothing is changed.

      'Content-Type': 'application/json'
    },
    body: JSON.stringify(payload)
  }

let body = await res.json();

if (!body.success && body.error.code === 'CUSTODY_SETUP_REQUIRED') {
  const custodySetupTxs: Record<string, string> = {};
  for (const step of body.error.setup.steps) {
    const tx = await wallet.sendTransaction({ to: step.to, data: step.data });
    await tx.wait();
    custodySetupTxs[step.key] = tx.hash;
  }
  res = await fetch(
    'https://api.trusset.org/orderbooks/external-securities/api/order-books',
    {
      method: 'POST',
      headers: {
        'X-API-Key': 'trusset_your_key_here',
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({ ...payload, custodySetupTxs })
    }
  );
  body = await res.json();
}

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `VALIDATION_ERROR` | `400` | A field failed schema validation |
| `INVALID_PAIR` | `400` | Base and quote token are the same |
| `INVALID_CONFIG` | `400` | `settlementOperator` is missing or malformed, a non-custody address was supplied, a price reference or `priceFeed` field is invalid, or `AGENT` delivery was requested for a token without an identity registry |
| `INVALID_ACCESS` | `400` | An `access` field is malformed, or the onboarding URL is not a public HTTPS address. Carries `field` |
| `GATE_SOURCE_CONFLICT` | `400` | A gate names more than one of `profile`, `accessList` and `register` |
| `INVALID_GATE_PROFILE` | `400` | `profile` is not a verification profile key. Send the `key` from [List Verification Profiles](/endpoints/customers/list-verification-profiles): up to 60 letters, digits, `_` or `-`. Carries `field`. Returned on both custody generations |
| `INVALID_GATE_ACCESS_LIST` | `400` | `accessList` is not a whitelist ID. Send the `id` from [List Access Lists](/endpoints/lending/list-access-lists): up to 64 letters, digits, `_` or `-`. Carries `field`. Returned on both custody generations |
| `PROFILE_NOT_FOUND` | `404` | The named verification profile does not exist on your instance |
| `ACCESS_LIST_NOT_FOUND` | `404` | The named whitelist is not an active whitelist of your instance on this network |
| `ACCESS_GATE_INCOMPATIBLE` | `422` | A gate is not a contract, or does not answer `isVerified(address)` |
| `IDENTITY_REGISTRY_RETIRED` | `422` | A gate is an archived Trusset ID Register, which takes no new identities |
| `BUYER_GATE_REQUIRED` | `409` | The security has no identity registry and the book would have no buyer gate |
| `ACCESS_GATES_SHARED` | `409` | The settlement operator settles another open book on this security with other gates |
| `DELIVERY_MODE_MISMATCH` | `409` | The security is registered with another delivery mode than the one requested |
| `CUSTODY_UPGRADE_REQUIRED` | `409` | Allowance delivery, an access gate, or a token without an identity registry was requested on a generation 1 custody contract. The message says whether generation 2 is missing on the network or only on that book |
| `TOKEN_NO_ISIN` | `400` | The security is unregistered and no identifier was supplied, or the registered security has no readable identifier |
| `ISIN_MISMATCH` | `400` | The declared identifier does not match what is registered on chain |
| `ORDER_BOOK_EXISTS` | `409` | An `ACTIVE` or `PAUSED` book already quotes this pair |
| `CUSTODY_SETUP_REQUIRED` | `409` | On-chain prerequisites are outstanding. `error.setup.steps` carries the unsigned transactions |
| `SECURITY_INACTIVE` | `409` | The token issuer has deactivated this security on the custody contract |
| `INVALID_CUSTODY_CONTRACT` | `400` | The address did not answer as the external securities custody contract |
| `TOKEN_METADATA_UNAVAILABLE` | `503` | Token decimals could not be read, or are outside the usable range |
| `CHAIN_UNAVAILABLE` | `503` | The RPC endpoint for your instance did not answer |
| `TX_TRACE_UNAVAILABLE` | `503` | A setup transaction was sent through a smart account and the network node could not trace it yet. Retry shortly |
| `CUSTODY_NOT_DEPLOYED` | `503` | No custody contract is deployed on your instance's network |
| `SERVICE_NOT_ENABLED` | `403` | The Trading service is not enabled on this instance |
