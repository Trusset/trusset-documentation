---
title: 'Get Position'
api: 'GET /lending-external-securities-v2/api/vaults/{vaultId}/position/{holderAddress}'
description: 'One wallet''s shares and their current value'
---

A compact answer for portfolio displays: the wallet's share balance, that balance at the current share price, and the share price itself. If you want the vault's full state alongside a position, use [Get Vault](/endpoints/vaults/get-vault) with `?address=`. Both calls run the same vault read, so a vault is visible here under the same rules.

## Path Parameters

<ParamField path="vaultId" type="string" required>Vault ID.</ParamField>
<ParamField path="holderAddress" type="string" required>Wallet to read. Must be a `0x` address of 40 hex characters. Anything else answers `VALIDATION_ERROR` without touching the chain.</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="vaultId" type="string">The vault read.</ResponseField>
    <ResponseField name="holder" type="object">`holderAddress`, `shares`, `sharesRaw`, `value`, `readFailed`. When `readFailed` is true, `shares`, `sharesRaw` and `value` are `null`, not zero. The whole block is `null` for a vault with no recorded address.</ResponseField>
    <ResponseField name="sharePrice" type="string">Current share price as an 18-decimal string, or `null` when the vault read failed.</ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/lending-external-securities-v2/api/vaults/cmssh8t2u0003cghxkx1w1fwd/position/0x6a6cba16dad34f7ea7ecbcdbf050f8146b942d6b" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/lending-external-securities-v2/api/vaults/${vaultId}/position/${wallet}`,
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { data } = await res.json();
if (data.holder && !data.holder.readFailed) {
  console.log(`${data.holder.shares} shares worth ${data.holder.value}`);
}
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `VALIDATION_ERROR` | `400` | `holderAddress` is not a `0x` address |
| `VAULT_NOT_FOUND` | `404` | No such vault, or it is not visible to your instance |
| `VAULT_STATE_UNAVAILABLE` | `503` | Whether your instance is a distributor of record in an unpublished vault could not be read from the chain. Retry shortly |
| `SERVICE_UNAVAILABLE` | `503` | The vault records or your instance's verified wallets could not be read. Retry shortly |
| `VAULT_READ_FAILED` | `500` | Unexpected failure. Retry, or contact support with the request ID |
