---
title: 'Get Vault'
api: 'GET /lending-external-securities-v2/api/vaults/{vaultId}'
description: 'Full vault record plus live chain state and an optional holder position'
---

Returns the vault record with its live state. `onChain` is the vault read from the chain in one aggregate. `holder` is the position of the wallet named in `address`, or `null` without one. On a vault your instance operates, `implementation` and `jitLiquidity` add the operator's view; on every other vault both are `null`.

The record fields are those of a [List Vaults](/endpoints/vaults/list-vaults) row, `depositorGate`, `depositorProfile`, `depositorAccessList` and `distributorView` included. A vault whose own register is the previous Trusset ID Register also carries `depositorRegisterRetired: true`, `currentRegistry` and `depositorRegisterNote`, as described there. A vault is visible here under the same rules as on that list.

## Path Parameters

<ParamField path="vaultId" type="string" required>Vault ID from [List Vaults](/endpoints/vaults/list-vaults).</ParamField>

## Query Parameters

<ParamField query="address" type="string">
  Wallet to read a position for. When it is a `0x` address, `holder` carries that wallet's shares and their current value. Any other value is ignored and `holder` is `null`.
</ParamField>

            <ResponseField name="delaySeconds" type="integer">The notice period the vault applies.</ResponseField>
            <ResponseField name="ready" type="boolean">Whether a collection could be taken now. Always `true` on a vault without the notice.</ResponseField>

            <ResponseField name="marketAvailableRaw" type="string">The same figure in base units.</ResponseField>
            <ResponseField name="utilizationBps" type="integer">The market's utilization. `null` when its metrics could not be read.</ResponseField>
            <ResponseField name="borrowRateBps" type="integer">The borrow rate that applies, a stamped fixed rate where the market's interest model sets one. These are the rates shown on that market's own page.</ResponseField>
            <ResponseField name="supplyRateBps" type="number">The rate liquidity providers earn there, after the fee split.</ResponseField>
            <ResponseField name="curveBorrowRateBps" type="integer">The rate the interest curve alone gives.</ResponseField>

            <ResponseField name="drawCapFormatted" type="string">The same cap formatted at the asset's decimals.</ResponseField>

            <ResponseField name="exitHorizon" type="object">This market's own `horizon`, `bounded` and `applies`, plus `basis` (`OPEN_LOANS` or `HIGH_WATER_MARK`) when it applies. `null` when unreadable. The vault-wide figure is `worstCaseHorizon`.</ResponseField>

            <ResponseField name="readFailed" type="boolean">Present and `true` when the position or the market's metrics could not be read. A metrics failure costs the rates only.</ResponseField>

            <ResponseField name="grossAnnual" type="string">Interest the current allocations would earn over a year at today's supply rates, before the performance fee. In the vault's asset.</ResponseField>
            <ResponseField name="netAnnual" type="string">The same figure after the operator's performance fee.</ResponseField>

            <ResponseField name="blendedNetApyBps" type="number">The same blended rate after the fee. This is the rate an investor earns.</ResponseField>
            <ResponseField name="performanceFeeBps" type="integer">The fee applied to get from gross to net.</ResponseField>

        <ResponseField name="sharesRaw" type="string">The same balance in base units.</ResponseField>
        <ResponseField name="value" type="string">Those shares at the current share price, in the vault's asset.</ResponseField>

    </ResponseField>
    <ResponseField name="jitLiquidity" type="object">

    </ResponseField>

<Warning>
  `readFailed: true` means the RPC could not answer, not that the vault is empty. A vault whose read failed still holds every deposit it held a minute ago. Show your last verified figures with a warning, retry, and never render zeros in their place.
</Warning>

<Note>
  `sharePrice` is an 18-decimal string regardless of the asset's own decimals. Every other amount in the block is formatted at `assetDecimals`. A healthy `onChain` read is cached for 20 seconds, so calls inside that window see the same figures.
</Note>

<Note>
  The `interest` block describes what the current allocations would earn at today's rates. Rates move with each market's utilization, so treat it as the present run rate rather than a forecast. It costs no extra call: the rates come from the same market read that produces the allocation legs.
</Note>

  -H "X-API-Key: trusset_your_key_here"

```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/lending-external-securities-v2/api/vaults/${vaultId}?address=${wallet}`,
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { data } = await res.json();
if (!data.onChain || data.onChain.readFailed) {
  scheduleRetry();
} else {
  console.log(`share price ${data.onChain.sharePrice}, ${data.onChain.idleAssets} ${data.assetSymbol} idle`);
}
```

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `VAULT_NOT_FOUND` | `404` | No such vault, or it is archived, on another network or environment, or an unpublished vault of another operator in which your instance is not a distributor of record |
| `VAULT_STATE_UNAVAILABLE` | `503` | Whether your instance is a distributor of record in an unpublished vault could not be read from the chain. Retry shortly |
| `SERVICE_UNAVAILABLE` | `503` | The vault records or your instance's verified wallets could not be read. Retry shortly |
| `VAULT_READ_FAILED` | `500` | Unexpected failure. Retry, or contact support with the request ID |
