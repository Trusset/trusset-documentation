---
title: 'Get Vault'
api: 'GET /lending-external-securities-v2/api/vaults/{vaultId}'
description: 'Full vault record plus live chain state and an optional holder position'
---

Returns the vault record with its live state. `onChain` is the vault read from the chain in one aggregate. `holder` is the position of the wallet named in `address`, or `null` without one. On a vault your instance operates, `implementation`, `jitLiquidity` and `roles` add the operator's view; on every other vault all three are `null`.

The record fields are those of a [List Vaults](/endpoints/vaults/list-vaults) row, `depositorGate`, `depositorProfile`, `depositorAccessList` and `distributorView` included. A vault whose own register is the previous Trusset ID Register also carries `depositorRegisterRetired: true`, `currentRegistry` and `depositorRegisterNote`, as described there. A vault is visible here under the same rules as on that list.

## Path Parameters

<ParamField path="vaultId" type="string" required>Vault ID from [List Vaults](/endpoints/vaults/list-vaults).</ParamField>

## Query Parameters

<ParamField query="address" type="string">
  Wallet to read a position for. When it is a `0x` address, `holder` carries that wallet's shares and their current value. Any other value is ignored and `holder` is `null`.
</ParamField>

<Warning>
  `readFailed: true` means the RPC could not answer, not that the vault is empty. A vault whose read failed still holds every deposit it held a minute ago. Show your last verified figures with a warning, retry, and never render zeros in their place.
</Warning>

<Note>
  `sharePrice` is an 18-decimal string regardless of the asset's own decimals. Every other amount in the block is formatted at `assetDecimals`. A healthy `onChain` read is cached for 20 seconds, so calls inside that window see the same figures.
</Note>

<Note>
  The `interest` block describes what the current allocations would earn at today's rates. Rates move with each market's utilization, so treat it as the present run rate rather than a forecast. It costs no extra call: the rates come from the same market read that produces the allocation legs. While a funded market is impaired, the headline figures still count its interest, and `excludingImpaired` gives the run rate without it.
</Note>

```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/lending-external-securities-v2/api/vaults/${vaultId}?address=${wallet}`,
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { data } = await res.json();
if (!data.onChain || data.onChain.readFailed) {
  scheduleRetry();
} else {
  console.log(`share price ${data.onChain.sharePrice}, ${data.onChain.idleAssets} ${data.assetSymbol} idle`);
}
```

| Code | HTTP | Cause |
|---|---|---|
| `VAULT_NOT_FOUND` | `404` | No such vault, or it is archived, on another network or environment, or an unpublished vault of another operator in which your instance is not a distributor of record |
| `VAULT_STATE_UNAVAILABLE` | `503` | Whether your instance is a distributor of record in an unpublished vault could not be read from the chain. Retry shortly |
| `SERVICE_UNAVAILABLE` | `503` | The vault records or your instance's verified wallets could not be read. Retry shortly |
| `VAULT_READ_FAILED` | `500` | Unexpected failure. Retry, or contact support with the request ID |
