---
title: 'Confirm Transaction'
api: 'POST /lending-external-securities/api/vaults/{vaultId}/confirm-tx'
description: 'Receipt-verified recording of a broadcast deposit or redemption'
---

Reports a broadcast transaction so the vault's ledger records it. The backend fetches the receipt, verifies it succeeded, verifies it called the function the type claims on this vault's address, and reads the amount from the transaction's events — nothing is taken from the request on trust.

This surface accepts investor types only: `DEPOSIT` and `REDEEM`. Operator transactions are confirmed by the operator in the Issuer Portal.

## Path Parameters

<ParamField path="vaultId" type="string" required>Vault ID.</ParamField>

## Body Parameters

<ParamField body="txHash" type="string" required>Hash of the broadcast transaction. For a deposit, the **deposit** step's hash, not the approval's.</ParamField>
<ParamField body="txType" type="string" required>`DEPOSIT` or `REDEEM`. Any other value answers `VALIDATION_ERROR`.</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="txHash" type="string">The verified hash.</ResponseField>
    <ResponseField name="signedBy" type="string">The wallet that actually signed, read from the receipt.</ResponseField>
    <ResponseField name="txType" type="string">The recorded type.</ResponseField>
    <ResponseField name="amount" type="string">Settlement-asset amount from the `Deposited` or `Redeemed` event. For a partial redemption this is what was actually paid.</ResponseField>
  </Expandable>
</ResponseField>

<Note>
  A failed confirmation does not undo the transaction — it is on-chain regardless. Retry the confirmation; the record reconciles. Never re-broadcast because a confirm call errored.
</Note>

<RequestExample>
```bash cURL
curl -X POST "https://api.trusset.org/lending-external-securities/api/vaults/{vaultId}/confirm-tx" \
  -H "X-API-Key: trusset_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{"txHash": "0x8f3b…89ab", "txType": "DEPOSIT"}'
```
```typescript TypeScript
await fetch(
  `https://api.trusset.org/lending-external-securities/api/vaults/${vaultId}/confirm-tx`,
  {
    method: 'POST',
    headers: { 'X-API-Key': 'trusset_your_key_here', 'Content-Type': 'application/json' },
    body: JSON.stringify({ txHash, txType: 'DEPOSIT' })
  }
);
```
</RequestExample>
