---
title: 'Remove Import'
api: 'DELETE /orderbooks/commodities/api/imports/{importId}'
description: 'Detach an imported commodity book from your venue'
---

Deactivates an import link. The book stops appearing in [List Order Books](/endpoints/commodity-trading/list-order-books) and stops resolving on the reads scoped to books you can reach.

Nothing is deleted. The link row is kept with `active: false`, so trade history stays intact and re-importing the same book reactivates this record rather than creating a new one.

## Path Parameters

<ParamField path="importId" type="string" required>
  Import ID, from [Import Order Book](/endpoints/commodity-trading/import-order-book) or the `_importId` field on an imported book. This is the import record's ID, not the order book's.
</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="id" type="string">Import ID.</ResponseField>
    <ResponseField name="instanceId" type="string">Your instance.</ResponseField>
    <ResponseField name="orderBookId" type="string">The book that was imported.</ResponseField>
    <ResponseField name="active" type="boolean">`false`.</ResponseField>
    <ResponseField name="updatedAt" type="string">ISO 8601 timestamp.</ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl -X DELETE "https://api.trusset.org/orderbooks/commodities/api/imports/clx_import_031" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/orderbooks/commodities/api/imports/${importId}`,

const { data } = await res.json();
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `INVALID_PARAM` | `400` | `importId` is missing or longer than 100 characters |
| `IMPORT_NOT_FOUND` | `404` | No import with that ID on your instance |
| `SERVICE_NOT_ENABLED` | `403` | The Trading service is not enabled on this instance |
