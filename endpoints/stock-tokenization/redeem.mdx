---
title: 'Redeem Tokens'
api: 'POST /stocks/api/tokenization/{tokenAddress}/redeem'
description: 'Burn tokens from a holder address'
---

Redeems (burns) tokens from a specified account. Typically used when a security is being delisted, a holder exercises a redemption right, or tokens need to be removed from circulation.

## Path Parameters

<ParamField path="tokenAddress" type="string" required>
  Address of the stock token contract.
</ParamField>

## Body Parameters

<ParamField body="account" type="string" required>
  Ethereum address from which tokens are burned.
</ParamField>

<ParamField body="amount" type="string" required>
  Number of tokens to redeem. Must be greater than zero.
</ParamField>

<ParamField body="reason" type="string">
  Optional reason for the redemption.
</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="success" type="boolean">Calldata was built successfully.</ResponseField>
    <ResponseField name="txData" type="object">
      The unsigned transaction. `to` is the token contract, `data` is the encoded `redeemFrom` call, and `value` is always `"0"`.
    </ResponseField>
  </Expandable>
</ResponseField>

<Note>
  Nothing is submitted on your behalf. Sign `txData` with a wallet holding the required role on the token and broadcast it yourself.
</Note>

<RequestExample>
```bash cURL
curl -X POST "https://api.trusset.org/stocks/api/tokenization/0x1234.../redeem" \
  -H "Content-Type: application/json" \
  -H "X-API-Key: trusset_abc123xy_secret..." \
  -d '{
    "account": "0xAbC123dEf456789012345678901234567890AbCd",
    "amount": "250",
    "reason": "Buyback program"
  }'
```
```typescript TypeScript
const response = await fetch(
  `https://api.trusset.org/stocks/api/tokenization/${tokenAddress}/redeem`,
  {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'X-API-Key': 'trusset_abc123xy_secret...'
    },
    body: JSON.stringify({
      account: '0xAbC123dEf456789012345678901234567890AbCd',
      amount: '250',
      reason: 'Buyback program'
    })
  }
);
const { data } = await response.json();
```
</RequestExample>
