---
title: 'Decline Market'
api: 'POST /asset-registers/api/markets/{marketAddress}/decline'
description: 'Take a market off the register queue without importing it'
---

Declines a market that names this instance as the asset register of its collateral token. The market leaves [List Register Queue](/endpoints/asset-register/list-register-queue), and the deployer reads `response: DECLINED` on [Get Market Register](/endpoints/asset-register/get-market-register). The Reject button of the Queue page in the Issuer Portal makes the same call.

A decline is a database write and it answers for one market only. The deployer's assignment for the token stays, so another market on the same token still reaches the queue. A decline is not final: [Import Market](/endpoints/asset-register/import-market) on the same address turns it into an import.

Declining an imported market removes the import. The market leaves [List Register Markets](/endpoints/asset-register/list-register-markets), its pledge record closes for this instance, and this instance's webhooks receive no further events for it.

Only an account Trusset approved as an asset register can decline, and only a market that names this instance.

## Path Parameters

<ParamField path="marketAddress" type="string" required>
  The market contract address, `0x` followed by 40 hex characters. Lowercase or correctly checksummed.
</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="marketAddress" type="string">The market, lowercased.</ResponseField>
    <ResponseField name="status" type="string">Always `DECLINED`.</ResponseField>
    <ResponseField name="decidedAt" type="string">When the decline was stored, ISO 8601.</ResponseField>
  </Expandable>
</ResponseField>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `VALIDATION_ERROR` | `400` | `marketAddress` is not `0x` followed by 40 hex characters |
| `INVALID_ADDRESS` | `400` | `marketAddress` is the zero address, or mixed case with a failing checksum |
| `AUTH_REQUIRED` | `401` | No `X-API-Key` header |
| `AUTH_FAILED` | `401` | The key is malformed, unknown, expired, or its instance is archived |
| `CREDIT_LIMIT_EXCEEDED` | `402` | The instance's monthly credit allowance is exhausted |
| `REGISTER_NOT_APPROVED` | `403` | Trusset has not approved this account as an asset register |
| `REGISTER_NOT_NAMED` | `403` | The deployer has not named this instance as the asset register of the token behind this market |
| `MARKET_NOT_FOUND` | `404` | No lending market with this address is recorded on the network and environment of this instance |
| `RATE_LIMIT_EXCEEDED` | `429` | More than 10 writes in the minute |
| `REGISTER_DECLINE_FAILED` | `500` | The decline could not be stored |
