---
title: 'Import Market'
api: 'POST /asset-registers/api/markets/import'
description: 'Take a lending market into this instance as the asset register of its collateral token'
---

Imports a lending market into this instance as the asset register of its collateral token and answers `201`. This is a database write: nothing is signed and nothing goes on chain.

The import is read-only. It does three things:

- The market appears in [List Register Markets](/endpoints/asset-register/list-register-markets) and on the Lending Markets page of the Issuer Portal.
- [List Pledges](/endpoints/asset-register/list-pledges) opens for the market with this instance's key.
- This instance's [pledge webhooks](/endpoints/asset-register/pledge-webhooks) start to receive the market's pledge events as they are indexed. Read the pledges that already stand once with List Pledges. A webhook never receives an event from before it was created. A webhook that existed before the import can still receive an event from between its creation and the import, when the market's index had not reached that event yet. Match pledges on `ref` and process each `idempotencyKey` once.

It gives the register no role on the market and no lending write.

<Note>
  A market can be imported only once its deployer has named this instance as the asset register of the collateral token behind it. Until then the call is refused with `403 REGISTER_NOT_NAMED`, also when the address is a real market. Every market the queue lists can be imported, including one its deployer took as lender of record itself.
</Note>

The address can come from [List Register Queue](/endpoints/asset-register/list-register-queue) or from the deployer directly. Importing a market that was declined earlier turns the answer into an import. Importing an imported market again answers `201` with a new `importedAt` and changes nothing else.

Only an account Trusset approved as an asset register can import. Any other account is refused with `403 REGISTER_NOT_APPROVED`.

## Body Parameters

<ParamField body="marketAddress" type="string" required>
  The market contract address, `0x` followed by 40 hex characters. Lowercase or correctly checksummed. The market must be recorded on the network and environment of this instance.
</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="market" type="object">

      <Expandable>
        <ResponseField name="importedAt" type="string">When this instance imported the market, ISO 8601.</ResponseField>
        <ResponseField name="activePledges" type="integer">Always `null` on this response. [List Register Markets](/endpoints/asset-register/list-register-markets) carries the count.</ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `VALIDATION_ERROR` | `400` | `marketAddress` is missing or not `0x` followed by 40 hex characters |
| `INVALID_ADDRESS` | `400` | `marketAddress` is the zero address, or mixed case with a failing checksum |
| `AUTH_REQUIRED` | `401` | No `X-API-Key` header |
| `AUTH_FAILED` | `401` | The key is malformed, unknown, expired, or its instance is archived |
| `CREDIT_LIMIT_EXCEEDED` | `402` | The instance's monthly credit allowance is exhausted |
| `ACCOUNT_FROZEN` | `403` | The account behind the key is suspended |
| `REGISTER_NOT_APPROVED` | `403` | Trusset has not approved this account as an asset register |
| `REGISTER_NOT_NAMED` | `403` | The deployer has not named this instance as the asset register of the token behind this market |
| `MARKET_NOT_FOUND` | `404` | No lending market with this address is recorded on the network and environment of this instance |
| `RATE_LIMIT_EXCEEDED` | `429` | More than 10 writes in the minute |
| `REGISTER_IMPORT_FAILED` | `500` | The import could not be stored |
