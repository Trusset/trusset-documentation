---
title: 'Get Market Register'
api: 'GET /asset-registers/api/markets/{marketAddress}/register'
description: 'The asset register named for the collateral token of a market, and its answer'
---

Returns the asset register the deployer named for the collateral token behind a market, and whether that register has imported the market.

The record opens to every instance that holds a record of the market: the instance that deployed it and the instance of its lender of record. `canEdit` says which of the two is calling. Only the deploying instance can change the register, with [Set Market Register](/endpoints/asset-register/set-market-register) and [Clear Market Register](/endpoints/asset-register/clear-market-register).

<Note>
  The asset register is recorded beside the market, not in it. `onChain` is always `false` and `appliesTo` is always `TOKEN`: the assignment covers every market of the same deployer on the same collateral token.
</Note>

A register provider does not read this endpoint for its own markets. It holds no record of the market, so the call answers `404 MARKET_NOT_FOUND`. It reads [List Register Markets](/endpoints/asset-register/list-register-markets) instead.

## Path Parameters

<ParamField path="marketAddress" type="string" required>
  The market contract address, `0x` followed by 40 hex characters. Lowercase or correctly checksummed.
</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="marketAddress" type="string">The market, lowercased.</ResponseField>
    <ResponseField name="tokenAddress" type="string">The collateral token the assignment belongs to, lowercased. `null` when the market records no collateral token.</ResponseField>
    <ResponseField name="canEdit" type="boolean">`true` for the instance that deployed the market. `false` for a lender of record, which reads the register and cannot change it. A change is checked on chain again when it is made.</ResponseField>
    <ResponseField name="appliesTo" type="string">Always `TOKEN`.</ResponseField>
    <ResponseField name="onChain" type="boolean">Always `false`. The assignment is not part of the lending contracts.</ResponseField>
    <ResponseField name="register" type="object">
      `null` while no register is named.
      <Expandable>
        <ResponseField name="instanceId" type="string">The named register instance.</ResponseField>
        <ResponseField name="instanceName" type="string">Its instance name.</ResponseField>
        <ResponseField name="companyName" type="string">The register provider's company name.</ResponseField>
        <ResponseField name="registerKind" type="string">`ON_CHAIN` or `OFF_CHAIN`, as the provider declared it.</ResponseField>
        <ResponseField name="registerKindLabel" type="string">`On-chain register` or `Off-chain register`.</ResponseField>
        <ResponseField name="response" type="string">`PENDING` until the register answers for this market, `IMPORTED` once it imported the market, `DECLINED` when it declined it. `IMPORTED` says the register took the market into its instance. It does not say that a register entry exists.</ResponseField>
        <ResponseField name="respondedAt" type="string">When the register last answered, ISO 8601. `null` while `response` is `PENDING`.</ResponseField>
        <ResponseField name="assignedAt" type="string">When the deployer named this register for the token, ISO 8601.</ResponseField>
        <ResponseField name="listed" type="boolean">`false` when the register has since taken its listing down, archived the instance or lost its approval. The assignment stays until the deployer clears it.</ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/asset-registers/api/markets/0x70a0e25c7b768b87e658348b3b577678a173e038/register" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/asset-registers/api/markets/${marketAddress}/register`,
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { data } = await res.json();
const imported = data.register?.response === 'IMPORTED';
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `VALIDATION_ERROR` | `400` | `marketAddress` is not `0x` followed by 40 hex characters |
| `INVALID_ADDRESS` | `400` | `marketAddress` is the zero address, or mixed case with a failing checksum |
| `AUTH_REQUIRED` | `401` | No `X-API-Key` header |
| `AUTH_FAILED` | `401` | The key is malformed, unknown, expired, or its instance is archived |
| `CREDIT_LIMIT_EXCEEDED` | `402` | The instance's monthly credit allowance is exhausted |
| `ACCOUNT_FROZEN` | `403` | The account behind the key is suspended |
| `MARKET_NOT_FOUND` | `404` | This instance holds no lending market with this address |
| `RATE_LIMIT_EXCEEDED` | `429` | More than 100 reads in the minute |
| `REGISTER_READ_FAILED` | `500` | The record could not be read |
| `DEPLOYER_UNREAD` | `503` | The deployment of the market could not be read from the chain, so its register cannot be decided. Retry shortly |
