---
title: 'Set Market Register'
api: 'PUT /asset-registers/api/markets/{marketAddress}/register'
description: 'Name the asset register of the collateral token behind a market'
---

Names a listed register provider as the asset register of the collateral token behind this market. This is a database write: nothing is signed and nothing goes on chain. The answer is the same record [Get Market Register](/endpoints/asset-register/get-market-register) returns.

Only the instance that deployed the market can name the register, because the register belongs to the token and not to the loan side. A lender of record is refused with `403 REGISTER_ISSUER_ONLY`.

The assignment is stored per collateral token. It covers every market this instance deployed on that token, including markets deployed later. Each of those markets appears in the register's [queue](/endpoints/asset-register/list-register-queue) until the register imports or declines it.

Naming the register that is already named changes nothing and answers `200`. Naming a different register replaces the assignment. The previous register loses its imports of these markets and its access to their pledge record. Its webhooks receive no further events for them.

## Path Parameters

<ParamField path="marketAddress" type="string" required>
  A market this instance deployed, `0x` followed by 40 hex characters. Lowercase or correctly checksummed.
</ParamField>

## Body Parameters

<ParamField body="registerInstanceId" type="string" required>
  The `instanceId` of a register from [List Asset Registers](/endpoints/asset-register/list-registers), 1 to 100 characters. A register that is not listed on the network and environment of this instance is refused with `404 REGISTER_NOT_LISTED`.
</ParamField>

## Response Fields

The response is the record of [Get Market Register](/endpoints/asset-register/get-market-register#response-fields), with `register.response` reading `PENDING` for a newly named register.

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `VALIDATION_ERROR` | `400` | `marketAddress` is not `0x` followed by 40 hex characters, or `registerInstanceId` is missing or longer than 100 characters |
| `INVALID_ADDRESS` | `400` | `marketAddress` is the zero address, or mixed case with a failing checksum |
| `AUTH_REQUIRED` | `401` | No `X-API-Key` header |
| `AUTH_FAILED` | `401` | The key is malformed, unknown, expired, or its instance is archived |
| `CREDIT_LIMIT_EXCEEDED` | `402` | The instance's monthly credit allowance is exhausted |
| `REGISTER_ISSUER_ONLY` | `403` | This instance holds the market as lender of record. Only the instance that deployed it names the register |
| `MARKET_NOT_FOUND` | `404` | This instance holds no lending market with this address |
| `REGISTER_NOT_LISTED` | `404` | The register is not published on the network and environment of this instance |
| `MARKET_TOKEN_UNKNOWN` | `409` | The market records no collateral token, so no register can be named for it |
| `RATE_LIMIT_EXCEEDED` | `429` | More than 10 writes in the minute |
| `REGISTER_ASSIGN_FAILED` | `500` | The assignment could not be stored |
