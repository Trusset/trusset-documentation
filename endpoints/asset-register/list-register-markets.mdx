---
title: 'List Register Markets'
api: 'GET /asset-registers/api/markets'
description: 'The lending markets this instance imported as asset register'
---

Returns the lending markets this instance imported as the asset register of their collateral token, most recently imported first. These are the markets whose pledge record this instance can read with [List Pledges](/endpoints/asset-register/list-pledges) and whose events reach its [pledge webhooks](/endpoints/asset-register/pledge-webhooks).

A market leaves this list when this instance declines it, and when its deployer clears or replaces the register for the token. The list holds at most 500 markets.

Only an account Trusset approved as an asset register can call this endpoint. Any other account is refused with `403 REGISTER_NOT_APPROVED`.

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="markets" type="array">
      The fields of a [queue item](/endpoints/asset-register/list-register-queue#response-fields) without `assignedAt`, plus the two below. `marketActive` can read `false` here: an imported market stays listed after it was deactivated.
      <Expandable>
        <ResponseField name="importedAt" type="string">When this instance imported the market, ISO 8601.</ResponseField>
        <ResponseField name="activePledges" type="integer">Pledges the index holds as standing for this market: not ended, with an amount above zero. The index advances when the market is scanned, so a new lock can take a few minutes to count. `null` when the market's pledge record has not been read from the chain yet, or when the count could not be read. Read [List Pledges](/endpoints/asset-register/list-pledges) for the market to start its record.</ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/asset-registers/api/markets" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch('https://api.trusset.org/asset-registers/api/markets', {
  headers: { 'X-API-Key': 'trusset_your_key_here' }
});
const { data } = await res.json();
const standing = data.markets.reduce((sum, market) => sum + (market.activePledges ?? 0), 0);
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `AUTH_REQUIRED` | `401` | No `X-API-Key` header |
| `AUTH_FAILED` | `401` | The key is malformed, unknown, expired, or its instance is archived |
| `CREDIT_LIMIT_EXCEEDED` | `402` | The instance's monthly credit allowance is exhausted |
| `ACCOUNT_FROZEN` | `403` | The account behind the key is suspended |
| `REGISTER_NOT_APPROVED` | `403` | Trusset has not approved this account as an asset register |
| `RATE_LIMIT_EXCEEDED` | `429` | More than 100 reads in the minute |
| `REGISTER_MARKETS_FAILED` | `500` | The list could not be read |
