---
title: 'List Asset Registers'
api: 'GET /asset-registers/api/directory'
description: 'The asset registers a deployer can name on the network and environment of this instance'
---

Returns the register providers that published a register profile on the network and environment of the calling instance. A deployer picks one of them with [Set Market Register](/endpoints/asset-register/set-market-register).

A production instance sees production listings only. Every other instance sees the listings of every non-production environment on its network. The calling instance itself is never in the list.

Only accounts Trusset approved as asset registers appear, one entry per account. An account that is frozen, not verified, or that has taken its listing down is left out. The list is sorted by `companyName` and holds at most 200 entries.

Any key can read the directory. It counts against the 100 per minute read budget of [Rate limits and credits](/endpoints/asset-register/introduction#rate-limits-and-credits).

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="registers" type="array">
      <Expandable>
        <ResponseField name="instanceId" type="string">The register's listed instance. Pass it as `registerInstanceId` to [Set Market Register](/endpoints/asset-register/set-market-register).</ResponseField>
        <ResponseField name="instanceName" type="string">The name of that instance.</ResponseField>
        <ResponseField name="companyName" type="string">The register provider's company name. The instance name when the account carries no company name.</ResponseField>
        <ResponseField name="registerKind" type="string">`ON_CHAIN` or `OFF_CHAIN`, as the provider declared it for its own register.</ResponseField>
        <ResponseField name="registerKindLabel" type="string">`On-chain register` or `Off-chain register`.</ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/asset-registers/api/directory" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch('https://api.trusset.org/asset-registers/api/directory', {
  headers: { 'X-API-Key': 'trusset_your_key_here' }
});
const { data } = await res.json();
const offChain = data.registers.filter((register) => register.registerKind === 'OFF_CHAIN');
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `AUTH_REQUIRED` | `401` | No `X-API-Key` header |
| `AUTH_FAILED` | `401` | The key is malformed, unknown, expired, or its instance is archived |
| `CREDIT_LIMIT_EXCEEDED` | `402` | The instance's monthly credit allowance is exhausted |
| `ACCOUNT_FROZEN` | `403` | The account behind the key is suspended |
| `RATE_LIMIT_EXCEEDED` | `429` | More than 100 reads in the minute |
