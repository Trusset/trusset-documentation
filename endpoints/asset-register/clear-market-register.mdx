---
title: 'Clear Market Register'
api: 'DELETE /asset-registers/api/markets/{marketAddress}/register'
description: 'Remove the asset register named for the collateral token behind a market'
---

Removes the asset register this instance named for the collateral token behind the market. This is a database write: nothing is signed and nothing goes on chain.

Only the instance that deployed the market can clear the register. A lender of record is refused with `403 REGISTER_ISSUER_ONLY`.

The assignment is stored per collateral token, so clearing it applies to every market this instance deployed on that token. The register loses its imports of those markets and its access to their pledge record, and its webhooks receive no further events for them. Events already queued for the register are still delivered.

Clearing a market that names no register changes nothing and answers `200` with `register: null`.

## Path Parameters

<ParamField path="marketAddress" type="string" required>
  A market this instance deployed, `0x` followed by 40 hex characters. Lowercase or correctly checksummed.
</ParamField>

## Response Fields

The response is the record of [Get Market Register](/endpoints/asset-register/get-market-register#response-fields), with `register` reading `null`.

<RequestExample>
```bash cURL

  -H "X-API-Key: trusset_your_key_here"
```

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `VALIDATION_ERROR` | `400` | `marketAddress` is not `0x` followed by 40 hex characters |
| `INVALID_ADDRESS` | `400` | `marketAddress` is the zero address, or mixed case with a failing checksum |
| `AUTH_REQUIRED` | `401` | No `X-API-Key` header |
| `AUTH_FAILED` | `401` | The key is malformed, unknown, expired, or its instance is archived |
| `CREDIT_LIMIT_EXCEEDED` | `402` | The instance's monthly credit allowance is exhausted |
| `REGISTER_ISSUER_ONLY` | `403` | This instance holds the market as lender of record. Only the instance that deployed it clears the register |
| `MARKET_NOT_FOUND` | `404` | This instance holds no lending market with this address |
| `MARKET_TOKEN_UNKNOWN` | `409` | The market records no collateral token |
| `RATE_LIMIT_EXCEEDED` | `429` | More than 10 writes in the minute |
| `REGISTER_CLEAR_FAILED` | `500` | The assignment could not be removed |
