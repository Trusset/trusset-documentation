---
title: 'List Register Queue'
api: 'GET /asset-registers/api/queue'
description: 'Markets that name this instance as asset register and still wait for its answer'
---

Returns the lending markets whose deployer named this instance as the asset register of their collateral token, and which this instance has neither imported nor declined yet. The Queue page of the Issuer Portal shows the same list.

A market enters the queue when the deployer names this instance for its collateral token, and when the deployer deploys another market on a token that already names it. Only active markets appear. A market leaves the queue with [Import Market](/endpoints/asset-register/import-market) or [Decline Market](/endpoints/asset-register/decline-market), and when the deployer clears or replaces the register.

Only an account Trusset approved as an asset register can call this endpoint. Any other account is refused with `403 REGISTER_NOT_APPROVED`.

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="items" type="array">
      Oldest market first.
      <Expandable>
        <ResponseField name="marketAddress" type="string">The market contract, lowercased. Pass it to [Import Market](/endpoints/asset-register/import-market).</ResponseField>
        <ResponseField name="tokenAddress" type="string">The collateral token this instance keeps the register for.</ResponseField>
        <ResponseField name="adapterAddress" type="string">The collateral adapter that holds every lock of the market. `null` when the record names none.</ResponseField>
        <ResponseField name="collateralTokenName" type="string">Token name, or `null`.</ResponseField>
        <ResponseField name="collateralTokenSymbol" type="string">Token symbol, or `null`.</ResponseField>
        <ResponseField name="collateralTokenIsin" type="string">ISIN of the token, or `null`.</ResponseField>
        <ResponseField name="collateralDecimals" type="integer">Decimals of the token, or `null`. Pledge amounts are base units of this token.</ResponseField>
        <ResponseField name="collateralMode" type="string">`FREEZE` or `CUSTODY`. See [Collateral mode changes what to record](/endpoints/asset-register/introduction#collateral-mode-changes-what-to-record).</ResponseField>
        <ResponseField name="borrowAssetSymbol" type="string">Symbol of the asset lent against the collateral, or `null`.</ResponseField>
        <ResponseField name="lenderOfRecord" type="string">Wallet of the lender of record, or `null` while the market has none.</ResponseField>
        <ResponseField name="seekingLender" type="boolean">`true` while the market still seeks a lender of record.</ResponseField>
        <ResponseField name="collateralAgent" type="string">The wallet named as pledgee on every lock, or `null` before the market is taken.</ResponseField>
        <ResponseField name="marketActive" type="boolean">Always `true` in the queue.</ResponseField>
        <ResponseField name="registerKind" type="string">`ON_CHAIN` or `OFF_CHAIN`, as this register declared itself when it was named.</ResponseField>
        <ResponseField name="registerKindLabel" type="string">`On-chain register` or `Off-chain register`.</ResponseField>
        <ResponseField name="issuer" type="object">The deployer that named this instance, as `companyName` and `instanceName`.</ResponseField>
        <ResponseField name="assignedAt" type="string">When the market entered the queue: the later of the assignment and the market's creation. ISO 8601.</ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="truncated" type="boolean">`true` when the tokens that name this instance carry more than 500 active markets. Only the oldest 500 are considered then, so answer what is listed and read the queue again.</ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/asset-registers/api/queue" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch('https://api.trusset.org/asset-registers/api/queue', {
  headers: { 'X-API-Key': 'trusset_your_key_here' }
});
const { data } = await res.json();
for (const market of data.items) console.log(market.marketAddress, market.issuer.companyName);
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `AUTH_REQUIRED` | `401` | No `X-API-Key` header |
| `AUTH_FAILED` | `401` | The key is malformed, unknown, expired, or its instance is archived |
| `CREDIT_LIMIT_EXCEEDED` | `402` | The instance's monthly credit allowance is exhausted |
| `ACCOUNT_FROZEN` | `403` | The account behind the key is suspended |
| `REGISTER_NOT_APPROVED` | `403` | Trusset has not approved this account as an asset register |
| `RATE_LIMIT_EXCEEDED` | `429` | More than 100 reads in the minute |
| `REGISTER_QUEUE_FAILED` | `500` | The queue could not be read |
