---
title: 'Get Role Audit'
api: 'GET /seller-financing/api/markets/{marketId}/role-audit'
description: 'The role assignments of a market''s deployment, today''s role holders and every later change, verified live'
---

<Note>
  Seller Financing is in beta and runs on Ethereum Sepolia instances only for now (`DEVELOPMENT` instances on Ethereum). A `PRODUCTION` instance, or one on another network, answers `503 SELLER_FINANCING_UNAVAILABLE`. See [Seller Financing](/endpoints/seller-financing/introduction).
</Note>

Returns the record of who received which role when the market was deployed, who holds each role now, and what changed in between. It is rebuilt on every call:

- **At deployment.** Each `RoleGranted` event the market emitted in the deployment transaction, the signer, and the market's initial parameters, read from the receipt.
- **Since.** Every `RoleGranted`, `RoleRevoked`, `IdentityRegistryUpdated` and `Upgraded` event the market emitted after the deployment transaction, read from its event log, and the implementation its ERC-1967 slot names now.
- **Now.** Every role checked live with `hasRole`: the grants of the deployment, the admin and operator named at deployment, and every account a later `RoleGranted` named. Neither the factory nor its owner may hold the admin or operator role, and that is checked too.

[Record Deployment](/endpoints/seller-financing/confirm-deployment) returns the same record as `auditDocument`. [Get Role Certificate](/endpoints/seller-financing/get-role-certificate) renders it as a PDF certificate under the same `docRef`, on the API key and in the Issuer Portal.

## Path Parameters

<ParamField path="marketId" type="string" required>The market's record ID, as `id` on [List Markets](/endpoints/seller-financing/list-markets).</ParamField>

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="docRef" type="string">`SF-` followed by 12 hex characters, derived from the chain, the market and the deployment transaction. The same market always has the same reference.</ResponseField>
    <ResponseField name="title" type="string">`Seller Financing market deployment: role assignments`.</ResponseField>
    <ResponseField name="chainId" type="integer">The chain.</ResponseField>
    <ResponseField name="market" type="string">The market contract.</ResponseField>
    <ResponseField name="adapter" type="string">Its collateral adapter.</ResponseField>
    <ResponseField name="factory" type="string">The factory that deployed it.</ResponseField>
    <ResponseField name="assetToken" type="string">The asset token.</ResponseField>
    <ResponseField name="paymentToken" type="string">The payment token.</ResponseField>
    <ResponseField name="mode" type="string">`FREEZE` or `CUSTODY`.</ResponseField>
    <ResponseField name="collateralAgent" type="string">The collateral agent.</ResponseField>
    <ResponseField name="identityRegistry" type="string">The market identity register the deployment set, or `null`.</ResponseField>
    <ResponseField name="currentIdentityRegistry" type="string">The market identity register in force now, read live, or `null` when the market names none. Absent when it could not be read. `registerChanges` lists each change in between.</ResponseField>
    <ResponseField name="repayFee" type="string">The repay fee the factory stamped, in the payment token's smallest unit.</ResponseField>
    <ResponseField name="transaction" type="object">
      <Expandable>
        <ResponseField name="hash" type="string">The deployment transaction.</ResponseField>
        <ResponseField name="blockNumber" type="integer">Its block.</ResponseField>
        <ResponseField name="blockHash" type="string">The block hash.</ResponseField>
        <ResponseField name="timestamp" type="integer">The block time, in unix seconds.</ResponseField>
        <ResponseField name="signer" type="string">The wallet that signed the deployment. For a smart-account deployment, the smart account.</ResponseField>
        <ResponseField name="outerSender" type="string">For a smart-account deployment, the wallet that broadcast the outer transaction. `null` for a direct one.</ResponseField>
        <ResponseField name="outerTarget" type="string">For a smart-account deployment, the contract the outer transaction called, such as the Safe or the ERC-4337 entry point. `null` for a direct one.</ResponseField>
        <ResponseField name="status" type="integer">`1` for a successful transaction.</ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="assignments" type="array">Each role the market granted in the deployment transaction: `{ role, roleHash, account, grantedBy, logIndex }`. `role` is `DEFAULT_ADMIN_ROLE` or `OPERATOR_ROLE`, or the raw hash of any other role.</ResponseField>
    <ResponseField name="atomic" type="boolean">`true` when the deployment transaction granted roles and the factory made every one of those grants. `false` when it granted none, or another account made one.</ResponseField>
    <ResponseField name="liveVerification" type="object">
      The live check.
      <Expandable>
        <ResponseField name="checkedAtBlock" type="integer">The block the check ran against.</ResponseField>
        <ResponseField name="checkedAt" type="string">ISO 8601 time of the check.</ResponseField>
        <ResponseField name="assignments" type="array">The same grants with `holdsNow`: `true` when the account still holds the role, `false` when it was revoked or renounced, `null` when unread.</ResponseField>
        <ResponseField name="noRoleFor" type="array">`{ account, label, holdsAdmin, holdsOperator }` for the factory (`label: "factory"`), its owner (`label: "factory owner"`) and the Trusset fee wallet the market names in `TRUSSET_WALLET()` (`label: "fee wallet"`). All read `false` on a market where Trusset holds no role. `null` means unread. When the factory's owner or the fee wallet cannot be read, its row carries `account: null` and `null` verdicts, and the certificate says the check could not be read.</ResponseField>
        <ResponseField name="trussetFees" type="object">The infrastructure fees the market books for Trusset: `{ feeWallet, accrued, accruedFormatted, note }`, `accrued` in the payment token's smallest unit, `null` when unread. They stay in the market until any wallet calls `sweepInfrastructureFees()`, which pays them only to `feeWallet`.</ResponseField>
        <ResponseField name="currentHolders" type="array">Today's role holders, as `{ role, roleHash, account, holdsNow }`. `holdsNow` is `true`, or `null` when that account's role could not be read; an account the chain answers `false` for is left out. `role` is `DEFAULT_ADMIN_ROLE`, `OPERATOR_ROLE` or the raw hash of another role. `null` when the holders could not be read at all.</ResponseField>
        <ResponseField name="roleChanges" type="array">Each `RoleGranted` and `RoleRevoked` after the deployment transaction, oldest first, as `{ event, blockNumber, transactionHash, logIndex, role, roleHash, account, sender }`. `sender` is the wallet that granted or revoked.</ResponseField>
        <ResponseField name="registerChanges" type="array">Each `IdentityRegistryUpdated`, as `{ event, blockNumber, transactionHash, logIndex, previousRegistry, newRegistry }`. A register removed or never set reads `null`.</ResponseField>
        <ResponseField name="upgrades" type="array">Each `Upgraded` after the deployment transaction, as `{ event, blockNumber, transactionHash, logIndex, implementation, generation }`. `generation` is `2` for a delivery-against-payment implementation, `1` otherwise, `null` when unread. An upgraded implementation is not bound by the rules of the deployed one.</ResponseField>
        <ResponseField name="implementation" type="string">The implementation the market's ERC-1967 slot names now. `null` when unread.</ResponseField>
        <ResponseField name="implementationGeneration" type="integer">Its generation, `null` when unread. See [Market generations](/endpoints/seller-financing/introduction#market-generations).</ResponseField>
        <ResponseField name="settlementModel" type="string">`CREDIT_AT_PAYOFF` or `DELIVERY_AGAINST_PAYMENT`, `null` when unread.</ResponseField>
        <ResponseField name="migrationPending" type="boolean">`true` when the market runs delivery against payment without the recount of its live sales. `null` when unread.</ResponseField>
        <ResponseField name="history" type="object">How far the event log was read: `{ complete, fromBlock, scannedToBlock }`. `fromBlock` is the deployment block. The log is read in chunks of 10,000 blocks, at most 40 per call. `complete` is `false` when the read stopped short of the chain head or a chunk failed, so a later change may be missing from the three lists and an account granted a role there from `currentHolders`. `scannedToBlock` is `null` when nothing could be read.</ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<Note>
  `assignments` covers the grants of the deployment transaction only. A role revoked later shows there as `holdsNow: false`. A role the admin granted later is in `roleChanges` and, while held, in `currentHolders`. Check `history.complete` before you rely on either list being exhaustive.
</Note>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/seller-financing/api/markets/cmsg4x7k20003sf9q1d8v6b2e/role-audit" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/seller-financing/api/markets/${marketId}/role-audit`,
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { data } = await res.json();
const trussetFree = data.liveVerification.noRoleFor.every(
  (r: { holdsAdmin: boolean | null; holdsOperator: boolean | null }) => r.holdsAdmin === false && r.holdsOperator === false
);
const operators = (data.liveVerification.currentHolders ?? [])
  .filter((h: { role: string; holdsNow: boolean | null }) => h.role === 'OPERATOR_ROLE' && h.holdsNow === true)
  .map((h: { account: string }) => h.account);
if (!data.liveVerification.history.complete) console.log('Role history read in part; call again');
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `MISSING_MARKET_ID` | `400` | `marketId` is longer than 100 characters |
| `MARKET_NOT_FOUND` | `404` | No market with this ID that your instance reaches on its network |
| `TX_NOT_FOUND` | `404` | The deployment transaction could not be loaded from the chain |
| `CHAIN_UNAVAILABLE` | `503` | The chain could not be read. Retry shortly |
| `SELLER_FINANCING_UNAVAILABLE` | `503` | The instance is a `PRODUCTION` instance or not on Ethereum |
| `ROLE_AUDIT_FAILED` | `500` | Unexpected failure. Retry, or contact support with the request ID |
