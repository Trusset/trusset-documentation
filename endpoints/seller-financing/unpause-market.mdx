---
title: 'Unpause Market'
api: 'POST /seller-financing/api/markets/{marketId}/unpause'
description: 'Calldata that resumes new listings, purchases and liquidations'
---

<Note>
  Seller Financing is in beta and runs on testnet instances only (Sepolia, `DEVELOPMENT`). A `PRODUCTION` instance answers `503 SELLER_FINANCING_UNAVAILABLE`. See [Seller Financing](/endpoints/seller-financing/introduction).
</Note>

Builds `unpause` on the market for a holder of the operator role to sign. Once mined, the market takes new listings and purchases again, and sellers can liquidate loans in default again. A loan that fell into default during the pause can be liquidated at once.

## Path Parameters

<ParamField path="marketId" type="string" required>The market's record ID, as `id` on [List Markets](/endpoints/seller-financing/list-markets).</ParamField>

## Body Parameters

<ParamField body="from" type="string" required>The wallet that signs. It must hold the operator role, or the request answers `409 TX_WOULD_REVERT` with `AccessControlUnauthorizedAccount`.</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="action" type="string">`SIGN_TRANSACTIONS`.</ResponseField>
    <ResponseField name="chainId" type="integer">The chain the step is built for.</ResponseField>
    <ResponseField name="steps" type="array">One step, `unpause` on the market, with `gasLimit`.</ResponseField>
    <ResponseField name="confirmStepIndex" type="integer">`0`.</ResponseField>
    <ResponseField name="preflight" type="object">`{ simulated: true, gasEstimate }`.</ResponseField>
  </Expandable>
</ResponseField>

```bash cURL
  -H "Content-Type: application/json" \

```
```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/seller-financing/api/markets/${marketId}/unpause`,
  {
    method: 'POST',
    headers: { 'X-API-Key': 'trusset_your_key_here', 'Content-Type': 'application/json' },
    body: JSON.stringify({ from: await operator.getAddress() })
  }
);
const { data } = await res.json();
const step = data.steps[0];
await (await operator.sendTransaction({ to: step.to, data: step.data, value: 0, gasLimit: step.gasLimit })).wait();
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `VALIDATION_ERROR` | `400` | `from` is missing or malformed, or the body carries another field |
| `MARKET_NOT_FOUND` | `404` | No market with this ID on your instance and network |
| `TX_WOULD_REVERT` | `409` | `ExpectedPause` when the market is not paused, or `AccessControlUnauthorizedAccount` when `from` lacks the operator role |
| `CHAIN_UNAVAILABLE` | `503` | The chain could not be read. Nothing was built. Retry shortly |
| `SELLER_FINANCING_UNAVAILABLE` | `503` | The instance is a `PRODUCTION` instance or not on Ethereum |
| `UNPAUSE_BUILD_FAILED` | `500` | Unexpected failure. Nothing was built. Retry, or contact support with the request ID |
