---
title: 'Get Market'
api: 'GET /seller-financing/api/markets/{marketId}'
description: 'One market with its configuration, repay fee, counters and token-side setup'
---

<Note>
  Seller Financing is in beta and runs on testnet instances only (Sepolia, `DEVELOPMENT`). A `PRODUCTION` instance answers `503 SELLER_FINANCING_UNAVAILABLE`. See [Seller Financing](/endpoints/seller-financing/introduction).
</Note>

Returns one market: the record stored at deployment, and its configuration, repay fee, identity register, counters and token-side setup read live from the market contract.

The configuration is what new listings are checked against and stamped with. A listing already created keeps the terms it was stamped with, whatever the configuration says now.

## Path Parameters

<ParamField path="marketId" type="string" required>The market's record ID, as `id` on [List Markets](/endpoints/seller-financing/list-markets), not its contract address.</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="id" type="string">The market's record ID.</ResponseField>
    <ResponseField name="chainId" type="integer">`11155111` on Sepolia.</ResponseField>
    <ResponseField name="address" type="string">The market contract.</ResponseField>
    <ResponseField name="adapter" type="string">The market's collateral adapter.</ResponseField>
    <ResponseField name="assetToken" type="string">The token being sold.</ResponseField>
    <ResponseField name="paymentToken" type="string">The token the buyer pays in.</ResponseField>
    <ResponseField name="mode" type="string">`FREEZE` or `CUSTODY`.</ResponseField>
    <ResponseField name="admin" type="string">The admin named at deployment.</ResponseField>
    <ResponseField name="operator" type="string">The operator named at deployment, or the admin when none was named.</ResponseField>
    <ResponseField name="collateralAgent" type="string">The pledgee named on every lock. Immutable.</ResponseField>
    <ResponseField name="deployTxHash" type="string">The deployment transaction, lowercased.</ResponseField>
    <ResponseField name="deployBlock" type="integer">The block it was mined in.</ResponseField>
    <ResponseField name="signer" type="string">The wallet that signed the deployment.</ResponseField>
    <ResponseField name="factory" type="string">The factory the market contract names, read live. `null` when unread.</ResponseField>
    <ResponseField name="createdAt" type="string">ISO 8601 time the market was recorded.</ResponseField>
    <ResponseField name="asset" type="object">`{ address, symbol, name, decimals }` of the asset token, `address` lowercased. `null` when the read failed.</ResponseField>
    <ResponseField name="payment" type="object">The same for the payment token.</ResponseField>
    <ResponseField name="config" type="object">
      The configuration new listings are checked against. `null` when unread.
      <Expandable>
        <ResponseField name="minDownpaymentBps" type="integer">Smallest downpayment, in basis points of the price.</ResponseField>
        <ResponseField name="maxDownpaymentBps" type="integer">Largest downpayment, in basis points of the price.</ResponseField>
        <ResponseField name="minDurationDays" type="number">Shortest runtime, in days.</ResponseField>
        <ResponseField name="maxDurationDays" type="number">Longest runtime, in days.</ResponseField>
        <ResponseField name="minInterestPeriodDays" type="number">Shortest interest period, in days.</ResponseField>
        <ResponseField name="maxInterestPeriodDays" type="number">Longest interest period, in days.</ResponseField>
        <ResponseField name="maxGracePeriodDays" type="number">Longest grace period, in days.</ResponseField>
        <ResponseField name="fixedEnabled" type="boolean">Whether listings can take `FIXED` interest.</ResponseField>
        <ResponseField name="derivedEnabled" type="boolean">Whether listings can take `DERIVED` interest.</ResponseField>
        <ResponseField name="sellerSetsFixedRate" type="boolean">`true` when a `FIXED` listing carries the seller's own rate, up to `maxFixedRateBps`. `false` when the operator's `fixedRateBps` applies.</ResponseField>
        <ResponseField name="fixedRateBps" type="integer">The operator's fixed annual rate, in basis points.</ResponseField>
        <ResponseField name="maxFixedRateBps" type="integer">The ceiling on a seller's fixed rate, in basis points.</ResponseField>
        <ResponseField name="baseRateBps" type="integer">The annual base rate of `DERIVED` interest, in basis points.</ResponseField>
        <ResponseField name="volatilityBps" type="integer">The annual volatility input that prices the walk-away premium of `DERIVED` interest, in basis points.</ResponseField>
        <ResponseField name="raw" type="object">The same values as the contract holds them: durations in seconds, rates and volatility as 18-decimal fixed-point fractions per year.</ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="paused" type="boolean">Whether the market is paused for new business. `null` when unread.</ResponseField>
    <ResponseField name="repayFee" type="string">The repay fee stamped at deployment, in the payment token's smallest unit. Each repayment carries the smaller of this and 0.5 percent of the amount applied. See [Fees](/endpoints/seller-financing/introduction#fees).</ResponseField>
    <ResponseField name="repayFeeFormatted" type="string">`repayFee` in whole units.</ResponseField>
    <ResponseField name="identityRegistry" type="string">The market identity register that examines sellers and buyers, read live. `null` when the market names none.</ResponseField>
    <ResponseField name="paymentDecimals" type="integer">The payment token's decimals as the market recorded them.</ResponseField>
    <ResponseField name="stats" type="object">
      <Expandable>
        <ResponseField name="listings" type="string">Listings ever created. Also the highest listing ID.</ResponseField>
        <ResponseField name="openListings" type="string">Listings waiting for a buyer.</ResponseField>
        <ResponseField name="activeLoans" type="string">Loans running.</ResponseField>
        <ResponseField name="totalEscrowed" type="string">Downpayments and principal payments held for active loans, in smallest units.</ResponseField>
        <ResponseField name="totalEscrowedFormatted" type="string">`totalEscrowed` in whole units.</ResponseField>
        <ResponseField name="totalClaimable" type="string">What all wallets together can withdraw now, in smallest units. `null` when unread.</ResponseField>
        <ResponseField name="trussetFeesPayable" type="string">Fees the market owes Trusset and has not paid out yet, in smallest units. `null` when unread.</ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="tokenSetup" type="object">Where the adapter stands on the asset token: `{ ready, mode, requirement, authorizedVia, identityRegistry, reason }`. See [Setup status](/endpoints/seller-financing/token-setup#setup-status).</ResponseField>
  </Expandable>
</ResponseField>

<Warning>
  The counters must be readable for this endpoint to answer. When they are not, it answers `503 CHAIN_UNAVAILABLE` rather than a market without figures. Every other block falls back on its own to `null`.
</Warning>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/seller-financing/api/markets/cmsg4x7k20003sf9q1d8v6b2e" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/seller-financing/api/markets/${marketId}`,
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { data } = await res.json();
console.log(`${data.mode} market, repay fee ${data.repayFeeFormatted} ${data.payment?.symbol}`);
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `MISSING_MARKET_ID` | `400` | `marketId` is longer than 100 characters |
| `MARKET_NOT_FOUND` | `404` | No market with this ID on your instance and network. A contract address sent as the ID answers the same |
| `CHAIN_UNAVAILABLE` | `503` | The market's counters could not be read. Nothing was changed. Retry shortly |
| `SELLER_FINANCING_UNAVAILABLE` | `503` | The instance is a `PRODUCTION` instance or not on Ethereum |
| `MARKET_READ_FAILED` | `500` | Unexpected failure. Nothing was changed. Retry, or contact support with the request ID |
