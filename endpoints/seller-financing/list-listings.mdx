---
title: 'List Listings'
api: 'GET /seller-financing/api/markets/{marketId}/listings'
description: 'A page of a market''s listings with their loans, read from the chain'
---

<Note>
  Seller Financing is in beta and runs on testnet instances only (Sepolia, `DEVELOPMENT`). A `PRODUCTION` instance answers `503 SELLER_FINANCING_UNAVAILABLE`. See [Seller Financing](/endpoints/seller-financing/introduction).
</Note>

Returns a page of the market's listings in ID order, each with its loan once a buyer has purchased it. Everything is read from the market contract. Listing IDs count up from 1, so a page starting at `offset` begins with listing `offset + 1`.

Each item is a listing as [Get Listing](/endpoints/seller-financing/get-listing) returns it, without the live loan status. Read [Get Loan Status](/endpoints/seller-financing/get-loan-status) for what an active loan owes.

<Warning>
  `status` filters the page after it is read. A page can therefore hold fewer items than `limit`, or none, while more listings follow. Keep paging with `nextOffset` until it is `null`.
</Warning>

## Path Parameters

<ParamField path="marketId" type="string" required>The market's record ID, as `id` on [List Markets](/endpoints/seller-financing/list-markets).</ParamField>

## Query Parameters

<ParamField query="offset" type="integer" default="0">Number of listings to skip. The page starts at listing `offset + 1`.</ParamField>

<ParamField query="limit" type="integer" default="50">Listings to read, 1 to 50.</ParamField>

<ParamField query="status" type="string">Keep only listings in this status: `OPEN`, `CANCELLED`, `ACTIVE`, `REPAID`, `COMPLETED` or `LIQUIDATED`.</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="items" type="array">The listings of the page that match `status`. For the fields see [Get Listing](/endpoints/seller-financing/get-listing#response-fields). `loan` is `null` before a purchase, and also when the loan could not be read.</ResponseField>
    <ResponseField name="total" type="integer">Listings on the market. Also the highest listing ID.</ResponseField>
    <ResponseField name="offset" type="integer">The `offset` of this page.</ResponseField>
    <ResponseField name="limit" type="integer">The `limit` of this page.</ResponseField>
    <ResponseField name="nextOffset" type="integer">The `offset` of the next page, counted before the `status` filter. `null` on the last page.</ResponseField>
    <ResponseField name="statusFilter" type="string">The `status` you sent, or `null`.</ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/seller-financing/api/markets/cmsg4x7k20003sf9q1d8v6b2e/listings?limit=2" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const base = `https://api.trusset.org/seller-financing/api/markets/${marketId}/listings`;
const open = [];
let offset: number | null = 0;
while (offset !== null) {
  const res = await fetch(`${base}?status=OPEN&offset=${offset}`, {
    headers: { 'X-API-Key': 'trusset_your_key_here' }
  });
  const { data } = await res.json();
  open.push(...data.items);
  offset = data.nextOffset;
}
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `VALIDATION_ERROR` | `400` | `offset` is negative, `limit` is outside 1 to 50, or `status` is not a listing status. `error.details` names the parameter |
| `MARKET_NOT_FOUND` | `404` | No market with this ID on your instance and network |
| `CHAIN_UNAVAILABLE` | `503` | The market could not be read. Retry shortly |
| `SELLER_FINANCING_UNAVAILABLE` | `503` | The instance is a `PRODUCTION` instance or not on Ethereum |
| `LISTINGS_READ_FAILED` | `500` | Unexpected failure. Retry, or contact support with the request ID |
