---
title: 'Get Deployment Options'
api: 'GET /seller-financing/api/markets/options'
description: 'The factory, collateral modes, default configuration, bounds and payment tokens of your network'
---

<Note>
  Seller Financing is in beta and runs on testnet instances only (Sepolia, `DEVELOPMENT`). A `PRODUCTION` instance answers `503 SELLER_FINANCING_UNAVAILABLE`. See [Seller Financing](/endpoints/seller-financing/introduction).
</Note>

Returns what [Build Deployment](/endpoints/seller-financing/deploy-market) works with on your network: the factory that deploys markets, the two collateral modes, the configuration a market gets for every field you leave out, the bounds each field must stay within, and the payment tokens the platform curates. Nothing is read from the chain.

`bounds` are the API's limits. Every configuration field you send and every listing term is checked against them first, then against the market's own configuration and the contract. A configuration also needs each minimum at or below its maximum, the shortest interest period at or below the longest runtime, and at least one interest strategy enabled.

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="available" type="boolean">`true`. An instance where Seller Financing is not available answers `503 SELLER_FINANCING_UNAVAILABLE` instead.</ResponseField>
    <ResponseField name="message" type="string">`null`.</ResponseField>
    <ResponseField name="chainId" type="integer">The chain your instance resolves to, `11155111` on Sepolia.</ResponseField>
    <ResponseField name="factory" type="string">The Seller Financing factory. Every deployment step is sent to it.</ResponseField>
    <ResponseField name="modes" type="array">`{ mode, default, summary }` for `FREEZE`, the default, and `CUSTODY`. See [Collateral modes](/endpoints/seller-financing/introduction#collateral-modes).</ResponseField>
    <ResponseField name="defaults" type="object">The configuration a market is deployed with for every field you omit from `config`. The fields are those of `config` on [Build Deployment](/endpoints/seller-financing/deploy-market#body-parameters).</ResponseField>
    <ResponseField name="bounds" type="object">`{ min, max }` per field family, in the units of the field: `downpaymentBps`, `durationDays`, `interestPeriodDays`, `gracePeriodDays`, `rateBps` (every rate field), `volatilityBps`, and `listingExpiryDays` with `max` only.</ResponseField>
    <ResponseField name="paymentTokens" type="array">`{ address, symbol, name, decimals, isDefault }` for each payment token curated on your network. USDC is the default. A deployment can also name another payment token with 6 to 18 decimals.</ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/seller-financing/api/markets/options" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch('https://api.trusset.org/seller-financing/api/markets/options', {
  headers: { 'X-API-Key': 'trusset_your_key_here' }
});
const { data } = await res.json();
const usdc = data.paymentTokens.find((t: { isDefault: boolean }) => t.isDefault);
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `SELLER_FINANCING_UNAVAILABLE` | `503` | The instance is a `PRODUCTION` instance or not on Ethereum |
| `OPTIONS_READ_FAILED` | `500` | Unexpected failure. Retry, or contact support with the request ID |
