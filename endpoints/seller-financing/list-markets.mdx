---
title: 'List Markets'
api: 'GET /seller-financing/api/markets'
description: 'List your instance''s Seller Financing markets with live counters and token-side setup'
---

<Note>
  Seller Financing is in beta and runs on testnet instances only (Sepolia, `DEVELOPMENT`). A `PRODUCTION` instance answers `503 SELLER_FINANCING_UNAVAILABLE`. See [Seller Financing](/endpoints/seller-financing/introduction).
</Note>

Returns the Seller Financing markets your instance recorded on its network, newest first, at most 100. Each record carries the deployment facts stored when [Record Deployment](/endpoints/seller-financing/confirm-deployment) verified the deployment, plus three blocks read live from the chain: the token metadata, the token-side setup and the market counters.

Use `id` as the `marketId` of every other endpoint. A market deployed through the factory but never recorded on your instance does not appear.

<Warning>
  The counters of every market are read in one batch. A market whose counters could not be read carries `state.readable: false` and `null` figures. When the whole batch fails, `state` holds only `readable: false` and `totalEscrowedFormatted: null`. A `null` figure is unread, not zero. Retry before acting on it.
</Warning>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="markets" type="array">
      Your instance's markets, newest first.
      <Expandable>
        <ResponseField name="id" type="string">The market's record ID. Pass it as `marketId`.</ResponseField>
        <ResponseField name="chainId" type="integer">`11155111` on Sepolia.</ResponseField>
        <ResponseField name="address" type="string">The market contract.</ResponseField>
        <ResponseField name="adapter" type="string">The market's collateral adapter: the freeze adapter or the custody adapter.</ResponseField>
        <ResponseField name="assetToken" type="string">The token being sold.</ResponseField>
        <ResponseField name="paymentToken" type="string">The token the buyer pays in, a stablecoin such as USDC.</ResponseField>
        <ResponseField name="mode" type="string">`FREEZE` or `CUSTODY`. See [Collateral modes](/endpoints/seller-financing/introduction#collateral-modes).</ResponseField>
        <ResponseField name="admin" type="string">The admin named at deployment.</ResponseField>
        <ResponseField name="operator" type="string">The operator named at deployment, or the admin when none was named.</ResponseField>
        <ResponseField name="collateralAgent" type="string">The pledgee named on every lock. Immutable.</ResponseField>
        <ResponseField name="deployTxHash" type="string">The deployment transaction, lowercased.</ResponseField>
        <ResponseField name="deployBlock" type="integer">The block it was mined in.</ResponseField>
        <ResponseField name="signer" type="string">The wallet that signed the deployment. For a deployment sent through a smart account, the smart account.</ResponseField>
        <ResponseField name="factory" type="string">The factory that deployed the market.</ResponseField>
        <ResponseField name="createdAt" type="string">ISO 8601 time the market was recorded.</ResponseField>
        <ResponseField name="asset" type="object">`{ address, symbol, name, decimals }` of the asset token, read from the token, with `address` lowercased. A field the token does not answer is `null`, and the whole block is `null` when the read failed.</ResponseField>
        <ResponseField name="payment" type="object">The same for the payment token.</ResponseField>
        <ResponseField name="tokenSetup" type="object">Where the adapter stands on the asset token: `{ ready, mode, requirement, authorizedVia, identityRegistry, reason }`. `ready` is `true` once the token accepts the adapter, and `null` when that could not be read. See [Setup status](/endpoints/seller-financing/token-setup#setup-status).</ResponseField>
        <ResponseField name="state" type="object">
          Live counters of the market contract.
          <Expandable>
            <ResponseField name="readable" type="boolean">`false` when the counters could not be read. The figures beside it are then `null`.</ResponseField>
            <ResponseField name="listings" type="string">Listings ever created. Also the highest listing ID.</ResponseField>
            <ResponseField name="openListings" type="string">Listings waiting for a buyer.</ResponseField>
            <ResponseField name="activeLoans" type="string">Loans running.</ResponseField>
            <ResponseField name="totalEscrowed" type="string">Downpayments and principal payments held for active loans, in the payment token's smallest unit.</ResponseField>
            <ResponseField name="paused" type="boolean">Whether the market is paused for new business. `null` when unread.</ResponseField>
            <ResponseField name="paymentDecimals" type="integer">The payment token's decimals as the market recorded them at deployment.</ResponseField>
            <ResponseField name="trussetFeesPayable" type="string">Fees the market owes Trusset and has not paid out yet, in smallest units.</ResponseField>
            <ResponseField name="totalEscrowedFormatted" type="string">`totalEscrowed` in whole units.</ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<Note>
  `admin` and `operator` are the parties named at deployment. Roles the admin grants or revokes later do not change them. [Get Role Audit](/endpoints/seller-financing/get-role-audit) checks on-chain who holds each role now.
</Note>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/seller-financing/api/markets" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch('https://api.trusset.org/seller-financing/api/markets', {
  headers: { 'X-API-Key': 'trusset_your_key_here' }
});
const { data } = await res.json();
for (const market of data.markets) {
  if (market.tokenSetup.ready !== true) console.log(`${market.id}: token-side setup outstanding`);
}
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `SELLER_FINANCING_UNAVAILABLE` | `503` | The instance is a `PRODUCTION` instance or not on Ethereum. Seller Financing runs on testnet instances only |
| `MARKETS_READ_FAILED` | `500` | Unexpected failure. Nothing was changed. Retry, or contact support with the request ID |

Authentication, credit and rate-limit codes are listed under [Errors](/endpoints/seller-financing/introduction#errors).
