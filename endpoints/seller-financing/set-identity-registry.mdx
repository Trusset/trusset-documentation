---
title: 'Set Identity Register'
api: 'POST /seller-financing/api/markets/{marketId}/identity-registry'
description: 'Calldata that changes or removes the market identity register'
---

<Note>
  Financing is in beta and runs on Ethereum Sepolia instances only for now (`DEVELOPMENT` instances on Ethereum). A `PRODUCTION` instance, or one on another network, answers `503 SELLER_FINANCING_UNAVAILABLE`. See [Financing](/endpoints/seller-financing/introduction).
</Note>

Builds `setIdentityRegistry` on the market for a holder of `OPERATOR_ROLE` to sign. The market identity register screens the seller at listing and the buyer at purchase. Name a new register, or send `null` to remove it, so that listings and purchases are screened by the asset token only.

Use it to repair a market whose register refuses everyone: one deployed with the asset token or a contract that does not answer `isVerified(address)` as its register, or one still reading the retired Trusset ID Register. [Get Market](/endpoints/seller-financing/get-market) reports such a market with `identityGate.usable: false`, and [Build Deployment](/endpoints/seller-financing/deploy-market) names this route in `details.repair` when you try to deploy the same market again.

A new register is probed before any calldata exists, with the checks a deployment runs:

- It must not be the market's asset token or payment token: `422 IDENTITY_REGISTRY_INCOMPATIBLE`.
- It must have contract code: `400 INVALID_IDENTITY_REGISTRY`.
- It must not be the previous Trusset ID Register, which takes no new identities: `422 IDENTITY_REGISTRY_RETIRED`, with the current register in `details.currentRegistry`.
- It must answer `isVerified(address)`, probed for `from`: `422 IDENTITY_REGISTRY_INCOMPATIBLE` when it does not, `503 IDENTITY_REGISTRY_UNREADABLE` when it could not be reached.

The API then simulates the change from `from`. The change stays open while the market is paused.

<Warning>
  The register applies to new business only. Listings and loans that exist already keep running under the new register, and a seller or buyer it refuses can no longer list or buy. Open listings of a seller the new register refuses stay open and can still be bought, because a purchase checks the buyer against the register, not the seller. The operator withdraws them with [Cancel Listing](/endpoints/seller-financing/cancel-listing).
</Warning>

## Path Parameters

<ParamField path="marketId" type="string" required>The market's record ID, as `id` on [List Markets](/endpoints/seller-financing/list-markets), not its contract address.</ParamField>

## Body Parameters

<ParamField body="identityRegistry" type="string" required>
  The register the market should read from now on: an ERC-3643 identity registry or the Trusset ID Register, anything that answers `isVerified(address)`. Send `null` or `""` to remove the register. The key must be present: a body without it answers `400 VALIDATION_ERROR` with the message "Pass identityRegistry: the register address, or null to remove the market register." and `details[0].field` set to `identityRegistry`. The register the market already reads answers `409 IDENTITY_REGISTRY_UNCHANGED`.
</ParamField>

<ParamField body="from" type="string" required>
  The wallet that signs: a holder of `OPERATOR_ROLE` on the market, the operator named at deployment unless the admin moved the role. Without it the answer is `400 FROM_REQUIRED`. Any other wallet answers `409 TX_WOULD_REVERT` with `AccessControlUnauthorizedAccount`, `details.requiredRole` and `details.roleHolders`.
</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="action" type="string">`SIGN_TRANSACTIONS`.</ResponseField>
    <ResponseField name="chainId" type="integer">The chain the step is built for.</ResponseField>
    <ResponseField name="steps" type="array">One step, `setIdentityRegistry` on the market, with `gasLimit`.</ResponseField>
    <ResponseField name="confirmStepIndex" type="integer">`0`.</ResponseField>
    <ResponseField name="preflight" type="object">`{ simulated: true, gasEstimate }`.</ResponseField>
    <ResponseField name="identityRegistry" type="object">`{ current, next }`: the register the market reads now and the one it will read once the step is mined. `null` stands for no register.</ResponseField>
    <ResponseField name="note" type="string">What the change reaches, in words: the register screens the seller at listing and the buyer at purchase, and existing listings and loans keep running.</ResponseField>
    <ResponseField name="signer" type="object">`{ role, holders, holdersComplete }`. `role` is `OPERATOR_ROLE`. `holders` lists the wallets that hold it now, `null` when they could not be read. `holdersComplete` is `false` when the market's role history was read in part, so a holder may be missing.</ResponseField>
  </Expandable>
</ResponseField>

```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/seller-financing/api/markets/${marketId}/identity-registry`,
  {
    method: 'POST',
    headers: { 'X-API-Key': 'trusset_your_key_here', 'Content-Type': 'application/json' },
    body: JSON.stringify({ identityRegistry: null, from: await operator.getAddress() })
  }
);
const { success, data, error } = await res.json();
if (!success) throw new Error(`${error.code}: ${error.message}`);
const step = data.steps[0];
await (await operator.sendTransaction({ to: step.to, data: step.data, value: 0, gasLimit: step.gasLimit })).wait();
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `VALIDATION_ERROR` | `400` | The body has no `identityRegistry` key ("Pass identityRegistry: the register address, or null to remove the market register."), an address is malformed, or the body carries a field this page does not list. `error.details` names each field |
| `FROM_REQUIRED` | `400` | `from` is missing. The message names who signs: a wallet that holds `OPERATOR_ROLE` on the market |
| `INVALID_IDENTITY_REGISTRY` | `400` | `identityRegistry` has no contract code on your network. `details` carries `field` and `registry` |
| `MARKET_NOT_FOUND` | `404` | No market with this ID that your instance reaches on its network |
| `IDENTITY_REGISTRY_UNCHANGED` | `409` | The market already reads this register, or already runs without one. `details.identityRegistry` names it. Nothing was built |
| `TX_WOULD_REVERT` | `409` | The change would revert: `AccessControlUnauthorizedAccount` when `from` lacks `OPERATOR_ROLE`, with `details.requiredRole` and `details.roleHolders` |
| `IDENTITY_REGISTRY_INCOMPATIBLE` | `422` | `identityRegistry` is the market's asset or payment token, or a contract that does not answer `isVerified(address)`. `details` carries `field` and `registry` |
| `IDENTITY_REGISTRY_RETIRED` | `422` | `identityRegistry` is the previous Trusset ID Register. `details` carries `field`, `registry` and `currentRegistry` |
| `CHAIN_UNAVAILABLE` | `503` | The market's current register, or the chain, could not be read. Nothing was built. Retry shortly |
| `IDENTITY_REGISTRY_UNREADABLE` | `503` | `identityRegistry` could not be reached to probe it. Nothing was built. Retry shortly |
| `SELLER_FINANCING_UNAVAILABLE` | `503` | The instance is a `PRODUCTION` instance or not on Ethereum |
| `IDENTITY_REGISTRY_BUILD_FAILED` | `500` | Unexpected failure. Nothing was built. Retry, or contact support with the request ID |
