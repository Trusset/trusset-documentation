---
title: 'List Liquidity Providers'
api: 'GET /lending-external-securities-v2/api/positions/{marketId}/providers'
description: 'List active liquidity providers for a market'
---

Returns the market's active liquidity providers, newest first. Before reading, the endpoint reconciles the stored records against the market contract, so share balances and deposits reflect the chain where they can be read. The reconciliation runs at most once a minute per market, so a record can trail the chain by up to a minute. If the chain cannot be read, the reconciliation is skipped and stored values are returned. A market with no stored providers then answers with an empty list, so an empty list does not prove the market has none.

On current markets only the operator wallet and the vaults the market admin registered can deposit directly. A wallet that deposited before its market moved to that rule keeps its shares and can still redeem them, so it can still appear here.

For an authoritative single-provider balance, use [Get Provider Balance](/endpoints/lending/get-provider-balance), which reads the market contract directly.

## Path Parameters

<ParamField path="marketId" type="string" required>The market's record ID, as `id` on [List Markets](/endpoints/lending/list-markets), not its contract address. See [Market IDs](/endpoints/lending/list-markets#market-ids).</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="providers" type="array">
      Active provider records ordered by `depositedAt` descending.
      <Expandable>
        <ResponseField name="id" type="string">Record ID.</ResponseField>
        <ResponseField name="marketId" type="string">Market ID.</ResponseField>
        <ResponseField name="provider" type="string">Provider address, lowercased.</ResponseField>
        <ResponseField name="amountDeposited" type="string">Total the provider has deposited, in borrow asset units, as the market contract records it. Withdrawals do not reduce it, so it is not the provider's current stake.</ResponseField>
        <ResponseField name="sharesOwned" type="string">LP shares held, at 18 decimals.</ResponseField>
        <ResponseField name="active" type="boolean">Always `true` in this response. Fully withdrawn providers are excluded.</ResponseField>
        <ResponseField name="depositedAt" type="string">ISO 8601 timestamp of when Trusset first recorded the provider, reset when the reconciliation finds that a fully withdrawn provider has deposited again. It is the recording time, not the block time.</ResponseField>
        <ResponseField name="withdrawnAt" type="string">`null` for every provider in this response, because fully withdrawn providers are excluded.</ResponseField>
        <ResponseField name="source" type="string">`vault` when the provider address is a vault registered with Trusset, funding the market on its depositors' behalf. `wallet` otherwise.</ResponseField>
        <ResponseField name="vault" type="object">Present when `source` is `vault`. Carries the vault's `id`, and its `name` and `symbol` when the vault belongs to your instance. On another institution's vault both are `null`: the funding is visible, the vault's own identity is not.</ResponseField>
        <ResponseField name="vaultGroupName" type="string">Present when the vault is a pocket of a [vault group](/endpoints/vaults/get-vault-group). The group's name when the vault belongs to your instance, `null` on another institution's.</ResponseField>
        <ResponseField name="vaultSettlementCurrency" type="string">Present with `vaultGroupName`. The pocket's settlement currency, such as `USD` or `EUR`, or `null` when its asset is not a known settlement token (stablecoin) on its network.</ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/lending-external-securities-v2/api/positions/{marketId}/providers" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/lending-external-securities-v2/api/positions/${marketId}/providers`,
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { data } = await res.json();
const vaultFunded = data.providers.filter((p) => p.source === 'vault');
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `MISSING_MARKET_ID` | `400` | `marketId` is longer than 100 characters |
| `MARKET_NOT_FOUND` | `404` | No market with this ID on your instance |
