---
title: 'List Terms Versions'
api: 'GET /lending-external-securities-v2/api/markets/{marketId}/terms/versions'
description: 'List every saved version of the terms of use for a market'
---

Returns the version history of the market's terms of use, newest first. Every save that changes the document writes a version, and the current one is listed with the rest. The terms a market presented at any point stay recoverable and auditable.

Version bodies are not included here. This endpoint answers what changed and when. Read one version in full with [Get Terms Version](/endpoints/lending/get-terms-version).

Drafts are listed too, whatever their publication state. Unpublishing writes no version. After [Unpublish Terms](/endpoints/lending/unpublish-terms), `current` is `null` and no entry is `live`, matching the `TERMS_NOT_PUBLISHED` that [Get Terms](/endpoints/lending/get-terms) answers. Each entry keeps `published` as the record of how it was saved.

## Path Parameters

<ParamField path="marketId" type="string" required>The market's record ID, as `id` on [List Markets](/endpoints/lending/list-markets), not its contract address. See [Market IDs](/endpoints/lending/list-markets#market-ids).</ParamField>

## Query Parameters

<ParamField query="limit" type="integer" default="25">
  Versions to return. Clamped to between 1 and 100 rather than refused. `0` or a value that is not a number falls back to 25.
</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="versions" type="array">
      Versions ordered by `version` descending, newest first. A draft staged beside published terms comes before the current version. Empty when the market has no terms.
      <Expandable>
        <ResponseField name="id" type="string">Version record ID.</ResponseField>
        <ResponseField name="version" type="integer">Version number.</ResponseField>
        <ResponseField name="title" type="string">Document title at that version. `null` when none was set.</ResponseField>
        <ResponseField name="contentHash" type="string">keccak256 over the UTF-8 bytes of the markdown at that version.</ResponseField>
        <ResponseField name="curatorAddress" type="string">The wallet that saved it: the lender of record, or a wallet holding the market's admin or issuer role.</ResponseField>
        <ResponseField name="published" type="boolean">Whether that save published the document or kept it as a draft.</ResponseField>
        <ResponseField name="live" type="boolean">Whether this version is the one served now. Only the current version of published terms is.</ResponseField>
        <ResponseField name="createdAt" type="string">ISO 8601 time of the save.</ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="current" type="integer">The version served now, or `null` when no terms exist or they are unpublished.</ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/lending-external-securities-v2/api/markets/{marketId}/terms/versions?limit=10" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/lending-external-securities-v2/api/markets/${marketId}/terms/versions?limit=10`,
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { data } = await res.json();
const drafts = data.versions.filter((v: { published: boolean }) => !v.published);
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `MISSING_MARKET_ID` | `400` | The market ID is longer than 100 characters |
| `NO_MARKET_ADDRESS` | `400` | The market has no on-chain address |
| `MARKET_NOT_FOUND` | `404` | No market with this ID on your instance |
