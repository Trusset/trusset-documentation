---
title: 'Create Identity Terms'
api: 'POST /lending-external-securities-v2/api/identity-terms'
description: 'Open a new identity terms document with a draft'
---

Creates an [identity terms](/endpoints/lending/identity-terms) document and saves its first draft. The draft may be as incomplete as you like: nothing is validated against the schema until you publish. The answer lists the draft's validation problems in `draftProblems`.

Saving refuses only what must never be stored, even in a draft:

- a text in the draft longer than 612 characters, or a draft nested deeper than 8 levels: `422 IDENTITY_TERMS_FIELD_INVALID`;
- a control or invisible character in a text: `422 IDENTITY_TERMS_TEXT_INVALID`;
- a text that looks like an e-mail address, a phone number or an IBAN: `422 IDENTITY_TERMS_PERSONAL_DATA`;
- a draft larger than 64 KB: `413 IDENTITY_TERMS_FIELD_INVALID`.

The platform fills in `schema` and your instance's `chainId`. Keep editing with [Update Identity Terms](/endpoints/lending/update-identity-terms), then publish with [Publish Identity Terms](/endpoints/lending/publish-identity-terms).

An instance keeps at most 50 documents. Revise an existing document rather than creating a new one for each change.

## Body Parameters

<ParamField body="name" type="string">
  Required unless `draft.name` is set, which then names the document. The name of the document, at most 200 characters, for example after the platform and the KYC provider. When both are sent, `name` counts and replaces `draft.name`. Control characters, invisible characters, mixed alphabets and personal data are refused.
</ParamField>

<ParamField body="draft" type="object">
  The terms as far as they are written, in the shape of the [schema](/endpoints/lending/identity-terms#schema). At most 64 KB. Leave it out to start empty. `requirementsExt` cannot be set here: create the document first, then upload the extension as `requirementsExtJson` with Update Identity Terms.
</ParamField>

## Response Fields

Answers `201` with the document.

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="terms" type="object">The summary, as [List Identity Terms](/endpoints/lending/list-identity-terms) returns it. `status` is `DRAFT`.</ResponseField>
    <ResponseField name="draft" type="object">The draft as saved, with `schema` and `chainId` filled in.</ResponseField>
    <ResponseField name="draftProblems" type="array">The validation problems of the draft, each `{ code, field, message, remedy }`. Empty when the draft is complete. Publishing refuses each of them, and in addition a claim no gate can back (`IDENTITY_TERMS_CLAIM_NOT_BACKED`) and a draft that states exactly what the latest version states (`IDENTITY_TERMS_UNCHANGED`).</ResponseField>
    <ResponseField name="versions" type="array">Empty: nothing is published yet.</ResponseField>
  </Expandable>
</ResponseField>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `VALIDATION_ERROR` | `400` | The body carries a field other than `name` and `draft`, `name` is longer than 400 characters, or `draft` is not an object |
| `IDENTITY_TERMS_FIELD_REQUIRED` | `400` | Neither `name` nor `draft.name` names the document |
| `IDENTITY_TERMS_FIELD_INVALID` | `400`, `413`, `422` | The name is longer than 200 characters (`400`), a text in the draft is longer than 612 characters or the draft is nested deeper than 8 levels (`422`), or the draft is larger than 64 KB (`413`) |
| `IDENTITY_TERMS_TEXT_INVALID` | `400`, `422` | The name (`400`) or a text in the draft (`422`) holds a control or invisible character. The name is also refused when it mixes alphabets |
| `IDENTITY_TERMS_PERSONAL_DATA` | `400`, `422` | The name (`400`) or a text in the draft (`422`) looks like an e-mail address, a phone number or an IBAN |
| `IDENTITY_TERMS_EXT_INVALID` | `400` | The draft sets `requirementsExt`. Upload the extension with Update Identity Terms |
| `IDENTITY_TERMS_LIMIT_REACHED` | `409` | The instance already keeps 50 documents. Withdraw one you no longer use, or revise an existing one |
| `RATE_LIMIT_EXCEEDED` | `429` | More than 10 writes in a minute. Retry after the interval in `Retry-After` |
| `IDENTITY_TERMS_CREATE_FAILED` | `500` | The document could not be created for a reason that carries no code of its own. Retry, or contact support with the request ID |
