---
title: 'Get Loan Auction'
api: 'GET /lending-external-securities-v2/api/liquidations/{marketId}/loan-auction/{loanId}'
description: 'Find the auction currently open against a loan'
---

Looks up the Dutch auction the market's auction venue holds open against a specific loan. Use it to show a borrower that their collateral is being auctioned, or to check a loan before liquidating it again.

A loan carries at most one open auction at a time. While it is open, the market refuses `liquidate`, `addCollateral`, `withdrawCollateral` and `borrowMore` on that loan, and an expired auction keeps blocking them until it is settled through [Settle Expired Auction](/endpoints/lending/settle-expired-auction). Repayment stays available.

## Path Parameters

<ParamField path="marketId" type="string" required>Market ID.</ParamField>
<ParamField path="loanId" type="integer" required>On-chain loan ID. Must be a positive integer.</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="loanId" type="string">The loan ID from the path, echoed back.</ResponseField>
    <ResponseField name="auction" type="object">
      The open auction, with the same fields as [Get Auction](/endpoints/lending/get-auction) including `phase` and `venueAddress`, or `null` when there is none.
    </ResponseField>
  </Expandable>
</ResponseField>

<Warning>
  This is a live lookup, not a history. The venue unlinks a loan from its auction when the last unit sells or when the expired auction is settled, so a loan auctioned yesterday returns `auction: null` today. An auction that has passed its end time without settlement is still linked and comes back with `phase: "EXPIRED"`. To inspect a finished auction, query it by ID through [Get Auction](/endpoints/lending/get-auction).
</Warning>

<Note>
  `auction: null` also answers a market with no auction venue wired and a venue that could not be read. Confirm the venue through [Get Auction Module](/endpoints/lending/get-auction-module) before treating `null` as proof that no auction exists.
</Note>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/lending-external-securities-v2/api/liquidations/{marketId}/loan-auction/7" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/lending-external-securities-v2/api/liquidations/${marketId}/loan-auction/${loanId}`,
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { data } = await res.json();
const auctionOpen = data.auction !== null;
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `MISSING_MARKET_ID` | `400` | The market ID is longer than 100 characters |
| `NO_MARKET_ADDRESS` | `400` | The market has no on-chain address recorded |
| `INVALID_LOAN_ID` | `400` | `loanId` is not a positive integer |
| `MARKET_NOT_FOUND` | `404` | No market with this ID on your instance |
