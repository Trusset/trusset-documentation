---
title: 'Get Identity Terms'
api: 'GET /lending-external-securities-v2/api/identity-terms/{id}'
description: 'Read an identity terms document with its draft, every version, the signatures and the signing links'
---

Returns one [identity terms](/endpoints/lending/identity-terms) document of your instance: its summary, the open draft with its validation problems, and every published version, newest first. Each version carries its core, its core hash, the typed-data domain members sign under, where each member stands, and the signing links created for it.

A terms id of another instance answers `404 IDENTITY_TERMS_NOT_FOUND`.

## Path Parameters

<ParamField path="id" type="string" required>
  The terms id, 20 to 40 lower-case letters and digits.
</ParamField>

## Response Fields

This shape is the document. The write routes of the group answer with it too.

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="terms" type="object">The summary: `id`, `name`, `status`, `latestVersion`, `latestCoreHash`, `publishedAt`, `hasDraft`, `draftUpdatedAt`, `createdAt` and `updatedAt`. See [List Identity Terms](/endpoints/lending/list-identity-terms#response-fields).</ResponseField>
    <ResponseField name="draft" type="object">The open draft as saved, or `null` when none is open.</ResponseField>
    <ResponseField name="draftProblems" type="array">The validation problems of the draft, each `{ code, field, message, remedy }`. Empty when the draft is complete or none is open. Publishing refuses each of them, and in addition a claim no gate can back (`IDENTITY_TERMS_CLAIM_NOT_BACKED`) and a draft that states exactly what the latest version states (`IDENTITY_TERMS_UNCHANGED`).</ResponseField>
    <ResponseField name="versions" type="array">
      Every published version, newest first.
      <Expandable>
        <ResponseField name="version" type="integer">The version number.</ResponseField>
        <ResponseField name="chainId" type="integer">The chain the version names.</ResponseField>
        <ResponseField name="coreHash" type="string">The [core hash](/endpoints/lending/identity-terms#core-hash).</ResponseField>
        <ResponseField name="supersedesHash" type="string">The core hash of the version it replaced, or `null` for version 1.</ResponseField>
        <ResponseField name="publishedAt" type="string">When it was published.</ResponseField>
        <ResponseField name="core" type="object">The published core, exactly as hashed.</ResponseField>
        <ResponseField name="typedDataDomain" type="object">`{ name: "Trusset Identity Terms", version: "1", chainId }`, the EIP-712 domain members sign under.</ResponseField>
        <ResponseField name="members" type="array">One entry per member: `index`, `legalName`, `roles`, `wallet`, `author` and `state`. `state` is `SIGNED`, `DECLINED`, `INVITED` (an open link waits) or `NONE`. A signed member adds `kind` (`EOA` or `ERC1271`), `signature` and `signedAt`. A member that declined adds `declinedAt` and `declineReason`.</ResponseField>
        <ResponseField name="invites" type="array">The signing links of this version, newest first, at most 50: `id`, `member`, `createdAt`, `expiresAt`, `usedAt`, `revokedAt` and `state` (`OPEN`, `USED`, `REVOKED` or `EXPIRED`). The link itself is never returned again.</ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/lending-external-securities-v2/api/identity-terms/cmx9t4k2p0007lq0cz3h8w1rd" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/lending-external-securities-v2/api/identity-terms/${termsId}`,
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { success, data, error } = await res.json();
if (!success) throw new Error(`${error.code}: ${error.message}`);
const latest = data.versions[0];
const unsigned = latest?.members.filter(m => m.state !== 'SIGNED') ?? [];
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `VALIDATION_ERROR` | `400` | `id` is not 20 to 40 lower-case letters and digits |
| `IDENTITY_TERMS_NOT_FOUND` | `404` | No terms with this id exist in your instance |
| `RATE_LIMIT_EXCEEDED` | `429` | More than 100 reads in a minute. Retry after the interval in `Retry-After` |
| `IDENTITY_TERMS_READ_FAILED` | `500` | The document could not be read for a reason that carries no code of its own. Retry, or contact support with the request ID |
