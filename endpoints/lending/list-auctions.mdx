---
title: 'List Active Auctions'
api: 'GET /lending-external-securities-v2/api/liquidations/{marketId}/auctions'
description: 'List the Dutch auctions still open on a market, running or awaiting settlement'
---

Returns every auction the market's auction venue still holds open, with its live declining price. That covers auctions that are running and auctions past their end time that nobody has settled yet. Check `phase` before acting: only a `RUNNING` auction takes bids, and an `EXPIRED` one waits for [Settle Expired Auction](/endpoints/lending/settle-expired-auction).

Auctions do not run on the market contract. They run on a per-market auction venue, which the market admin binds after adoption, and a market without one has no auctions. Liquidation opens an auction only while the market's `useDutchAuction` switch is on, and that switch cannot be turned on before a venue is wired. See [Get Auction Module](/endpoints/lending/get-auction-module).

## Path Parameters

<ParamField path="marketId" type="string" required>Market ID.</ParamField>

        <ResponseField name="collateralRemaining" type="string">Collateral still for sale, in collateral token units. Falls as bids fill.</ResponseField>
        <ResponseField name="debtRemaining" type="string">Debt the auction has not yet discharged, in borrow asset units. Each fill discharges debt in proportion to the collateral it buys.</ResponseField>
        <ResponseField name="currentPrice" type="string">Price per whole collateral unit, in borrow asset units, read from the venue on this request. After the end time it is the floor price.</ResponseField>
        <ResponseField name="endTime" type="integer">Unix seconds when bidding closes.</ResponseField>
        <ResponseField name="active" type="boolean">Always `true` in this list. The venue clears it when the last unit sells or when the auction is settled after expiry.</ResponseField>
        <ResponseField name="expired" type="boolean">`true` once `endTime` has passed.</ResponseField>
        <ResponseField name="biddable" type="boolean">`true` while the auction is running. A bid on an auction where this is `false` is refused.</ResponseField>
        <ResponseField name="settleable" type="boolean">`true` once the auction has expired, which is when [Settle Expired Auction](/endpoints/lending/settle-expired-auction) accepts it.</ResponseField>
        <ResponseField name="phase" type="string">`RUNNING` or `EXPIRED`. Closed auctions never appear here; read one by ID through [Get Auction](/endpoints/lending/get-auction).</ResponseField>
      </Expandable>

## How the Price Moves

The venue fixes the schedule once, when the auction opens, from the oracle price the liquidation was priced at. The price then falls linearly from that price times `auctionStartPremium` to that price times `auctionMinPremium`, across `auctionDuration`. A market configured at 13000 and 9500 basis points opens at 1.3 times that price and reaches 0.95 times at the end time. Oracle updates after the auction opens do not move its schedule.

`currentPrice` reflects the moment of the request. Quote it fresh, since what a bid costs changes between reading and submitting.

`expired`, `biddable`, `settleable` and `phase` are computed against the API server's clock, while the venue judges by the block timestamp. Within seconds of `endTime` the two can disagree, so a bid sent at the last moment can still revert.

<Note>
  An empty array is also what a market with no auction venue returns, and what a failed read of the venue returns. An auction whose own read fails is left out without an error. If a market has known auctions and this returns nothing, check two things. [Get Auction Module](/endpoints/lending/get-auction-module) says whether a venue is `wired`, and [Get Market Metrics](/endpoints/lending/get-metrics) carries an `activeAuctions` counter.
</Note>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/lending-external-securities-v2/api/liquidations/{marketId}/auctions" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/lending-external-securities-v2/api/liquidations/${marketId}/auctions`,
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { data } = await res.json();
const biddable = data.auctions.filter((auction) => auction.biddable);
const toSettle = data.auctions.filter((auction) => auction.settleable);
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `MISSING_MARKET_ID` | `400` | The market ID is longer than 100 characters |
| `NO_MARKET_ADDRESS` | `400` | The market has no on-chain address recorded |
| `MARKET_NOT_FOUND` | `404` | No market with this ID on your instance |
