---
title: 'Get Deployment Options'
api: 'GET /lending-external-securities-v2/api/markets/deployment-options'
description: 'Read the choices and limits that apply before deploying a market'
---

Returns what a deployment on this instance can choose and what the factory fixes, before any calldata is built. Read it before [Deploy Market](/endpoints/lending/deploy-market). It carries the factory's live rate ceiling and the fixed fee shares. It also carries the ranges the term offering accepts, the identity register this instance resolves to, the verification profiles and whitelists a market can gate on, and whether vault groups can be created.

Most of the answer is fixed by the contracts and the backend, and is returned so a deployment form does not hard-code it. `creatorRateCeilingBps`, the two share `bps` figures, `priceSources.fixedSupported` and `vaultGroups.supported` are read live from the chain. A contract that cannot be read answers `null` in those fields rather than failing the request, and `priceSources.options` then leaves `FIXED` out.

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="factory" type="object">
      The lending factory this instance deploys to.
      <Expandable>
        <ResponseField name="address" type="string">Factory address, lowercased. `null` when no factory is configured for this network.</ResponseField>
        <ResponseField name="openToAnyCurator" type="boolean">Whether the factory accepts markets offered beyond their named candidates. `null` when no factory is configured.</ResponseField>
        <ResponseField name="creatorRateCeilingBps" type="integer">The highest floor, cap or fixed rate a deployment may carry, in basis points. `null` when the factory could not be read.</ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="priceSources" type="object">
      <Expandable>
        <ResponseField name="options" type="array">`NAV`, `MARKET`, `ORACLE` and `FIXED`. `FIXED` is listed only when `fixedSupported` is `true`.</ResponseField>
        <ResponseField name="default" type="string">`NAV`.</ResponseField>
        <ResponseField name="marketRequiresIdentityRegistry" type="boolean">`true`. A `MARKET` market must carry a borrower register. The deployment installs it, unless it nominates `candidates` and is not open to any curator: the nominated lender of record then brings it with its adoption terms. See `professionalBorrowerGate`.</ResponseField>
        <ResponseField name="identityRegistryAlwaysOptional" type="boolean">`false`, for the same reason.</ResponseField>
        <ResponseField name="oracleRequiresFeedAddress" type="boolean">`true`. An `ORACLE` deployment must name its feed in `oracleAddress`.</ResponseField>
        <ResponseField name="oracleInitialPriceFromFeed" type="boolean">`true`. An `ORACLE` market takes its first price from the feed, so it takes no `initialPrice`.</ResponseField>
        <ResponseField name="fixedSupported" type="boolean">Whether the factory creates oracles that can hold a fixed price. `null` when no factory is configured or it could not be read.</ResponseField>
        <ResponseField name="fixedRequiresInitialPrice" type="boolean">`true`. A `FIXED` deployment states its price in `initialPrice`.</ResponseField>
        <ResponseField name="fixedRefusesOracleAddress" type="boolean">`true`. A `FIXED` deployment takes no `oracleAddress`.</ResponseField>
        <ResponseField name="fixedNeverStale" type="boolean">`true`. A fixed price never goes stale.</ResponseField>
        <ResponseField name="fixedMarkDownOnly" type="boolean">`true`. A price update can only lower a fixed price.</ResponseField>
        <ResponseField name="fixedCurrencyMustMatchSettlement" type="boolean">`true`. The token's currency must be the currency of the settlement token (stablecoin).</ResponseField>
        <ResponseField name="fixedNominalCheck" type="object">`{ formula, override }`: the price is compared with `nominal per token x redemption percent / 100`, and `acknowledgeFixedPriceMismatch` overrides a mismatch.</ResponseField>
        <ResponseField name="fixedOracleOwnerCanUpgrade" type="boolean">`true`. Whoever owns the oracle could replace its implementation, and with it the fixed price.</ResponseField>
        <ResponseField name="fixedNote" type="string">The same in words, for display beside the choice.</ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="identityGates" type="object">
      How the market's two registers behave. See [Get Identity Gates](/endpoints/lending/get-identity-gates).
      <Expandable>
        <ResponseField name="borrowerGateRequiredFor" type="array">Price sources that require a borrower register: `["MARKET"]`.</ResponseField>
        <ResponseField name="providerGateOpensPool" type="boolean">`false`. A provider register admits nobody to deposit directly into the market.</ResponseField>
        <ResponseField name="providerGateReadByVaults" type="boolean">`true`. Every vault registered on the market examines its depositors against the provider register before it routes their money in.</ResponseField>
        <ResponseField name="poolClosedWithoutProviderGate" type="boolean">`true`.</ResponseField>
        <ResponseField name="adjustableByAdmin" type="boolean">`true`. The market admin can change both registers after adoption.</ResponseField>
        <ResponseField name="acceptedShapes" type="array">The answers to `isVerified(address)` a register may give: `bool` or `tuple`.</ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="rateOffering" type="object">
      <Expandable>
        <ResponseField name="modes" type="array">`CURVE`, `CLAMPED` and `FIXED`.</ResponseField>
        <ResponseField name="default" type="string">`CURVE`.</ResponseField>
        <ResponseField name="creatorRateCeilingBps" type="integer">The same ceiling as under `factory`.</ResponseField>
        <ResponseField name="fixedRequiresTerms" type="boolean">`true`. A `FIXED` deployment needs `maxLoanDurationDays`.</ResponseField>
        <ResponseField name="capSuspendsBorrows" type="boolean">`false`. A binding `CLAMPED` cap holds the rate at the cap and blocks nothing.</ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="operatorShare" type="object">
      The share of repaid interest paid to the wallet that takes the lender-of-record role.
      <Expandable>
        <ResponseField name="fixed" type="boolean">`true`. The factory holds it as a constant.</ResponseField>
        <ResponseField name="bps" type="integer">The share in basis points, read from the factory. `null` when it could not be read.</ResponseField>
        <ResponseField name="afterInfrastructureFee" type="boolean">`true`. The share is taken from the interest left after the Trusset infrastructure fee.</ResponseField>
        <ResponseField name="acceptedAtDeployment" type="boolean">`false`. A deployment that sends `operatorShareBps` is refused.</ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="distributorShare" type="object">
      The share of repaid interest paid to distributors.
      <Expandable>
        <ResponseField name="fixed" type="boolean">`true`.</ResponseField>
        <ResponseField name="bps" type="integer">The share in basis points, read from the factory. `null` when it could not be read.</ResponseField>
        <ResponseField name="afterInfrastructureFee" type="boolean">`true`.</ResponseField>
        <ResponseField name="paidTo" type="string">Who receives it: the distributors behind each vault depositor, and the operator for liquidity no distributor brought.</ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="liquidity" type="object">
      <Expandable>
        <ResponseField name="directDepositors" type="array">`OPERATOR_WALLET` and `REGISTERED_VAULTS`. A current market accepts direct deposits from these two alone.</ResponseField>
        <ResponseField name="thirdPartiesThroughVaults" type="boolean">`true`. Everyone else provides liquidity through a vault.</ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="termOffering" type="object">
      <Expandable>
        <ResponseField name="maxLoanDurationDaysRange" type="array">`[1, 3650]`.</ResponseField>
        <ResponseField name="termGracePeriodDaysRange" type="array">`[1, 30]`.</ResponseField>
        <ResponseField name="graceDefaultDays" type="integer">`3`, applied when terms are on and no grace period is named.</ResponseField>
        <ResponseField name="newLoansOnly" type="boolean">`true`. A term change reaches loans opened afterwards only.</ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="identityRegistry" type="object">
      The identity register this instance resolves to. Nothing installs it on a market by default. A deployment or an adoption uses it only when it names it.
      <Expandable>
        <ResponseField name="mode" type="string">`TRUSSET` when the instance uses the Trusset register, `OWN` when it configured its own.</ResponseField>
        <ResponseField name="instanceRegister" type="string">That register's address, lowercased. `null` when it could not be resolved.</ResponseField>
        <ResponseField name="unavailableReason" type="string">Why the register could not be resolved, for example an `OWN` mode with no address configured. `null` otherwise.</ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="eligibilityProfiles" type="array">
      This instance's verification profiles that carry an eligibility register, as on [List Eligibility Profiles](/endpoints/customers/list-eligibility-profiles). A deployment, an adoption or a gate change can name one by `key` instead of an address. Empty when none has a register, or when the profiles could not be read.
      <Expandable>
        <ResponseField name="key" type="string">The profile key, for `identityRegistryProfile` and `providerRegistryProfile`.</ResponseField>
        <ResponseField name="name" type="string">Display name.</ResponseField>
        <ResponseField name="entityType" type="string">`INDIVIDUAL` or `COMPANY`.</ResponseField>
        <ResponseField name="professionalOnly" type="boolean">Whether the profile is limited to professional clients. Only the register of such a profile, in the `REGISTER` mode, can be the borrower gate of a `MARKET` market.</ResponseField>
        <ResponseField name="requirementsHash" type="string">The hash of the profile's current requirements.</ResponseField>
        <ResponseField name="registryAddress" type="string">The eligibility register, checksummed.</ResponseField>
        <ResponseField name="admissionMode" type="string">`REGISTER`, `INSTANCE_REGISTER` or `EXTERNAL`, recorded when the register was bound. See [Which registers can be signed here](/endpoints/customers/introduction#which-registers-can-be-signed-here).</ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="gateProfiles" type="array">
      Every enabled verification profile of this instance, with or without an eligibility register, so a form can show which can be chosen as a gate and which cannot yet. Empty when the profiles could not be read.
      <Expandable>
        <ResponseField name="key" type="string">Profile key.</ResponseField>
        <ResponseField name="name" type="string">Display name.</ResponseField>
        <ResponseField name="entityType" type="string">`INDIVIDUAL` or `COMPANY`.</ResponseField>
        <ResponseField name="professionalOnly" type="boolean">Whether the profile is limited to professional clients.</ResponseField>
        <ResponseField name="requirementsHash" type="string">The hash of the profile's current requirements.</ResponseField>
        <ResponseField name="registryAddress" type="string">The eligibility register, checksummed, or `null` when the profile has none yet.</ResponseField>
        <ResponseField name="admissionMode" type="string">`REGISTER`, `INSTANCE_REGISTER` or `EXTERNAL`, or `null` without a register.</ResponseField>
        <ResponseField name="registerAvailable" type="boolean">Whether this instance can deploy or bind a register for a profile, which needs an identity register of its own (`identityRegistry.mode: OWN`).</ResponseField>
        <ResponseField name="marketBorrowerGateEligible" type="boolean">`true` when the profile can be the borrower gate of a `MARKET` market: limited to professional clients, with a register in the `REGISTER` mode.</ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="accessLists" type="object">
      Whether whitelists can gate a market on this network. See [Whitelists](/endpoints/lending/list-access-lists).
      <Expandable>
        <ResponseField name="available" type="boolean">Whether the whitelist factory is configured on this network.</ResponseField>
        <ResponseField name="factory" type="string">The whitelist factory, lowercased, or `null`.</ResponseField>
        <ResponseField name="maxBatch" type="integer">`200`, the most wallets one transaction lists or removes.</ResponseField>
        <ResponseField name="refusedOn" type="array">Where a whitelist is refused as a gate: `MARKET_PRICE_BORROWER_GATE` (the borrower gate of a `MARKET` market) and `SINGLE_REGISTER_MARKET` (a market on the earlier single-register implementation).</ResponseField>
        <ResponseField name="lists" type="array">This instance's whitelists that are not archived, as on [List Whitelists](/endpoints/lending/list-access-lists). Empty when `available` is `false`.</ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="vaultGroups" type="object">
      <Expandable>
        <ResponseField name="supported" type="boolean">Whether the vault factory on this network creates vault groups. `null` when it could not be read.</ResponseField>
        <ResponseField name="maxPockets" type="integer">`4`, the most currency pockets a group holds on Trusset.</ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="professionalBorrowerGate" type="object">
      The rule a `MARKET` market's borrower gate follows. See [Professional borrowers](/endpoints/lending/set-identity-gates#professional-borrowers).
      <Expandable>
        <ResponseField name="requiredFor" type="array">`["MARKET"]`.</ResponseField>
        <ResponseField name="rule" type="string">The rule in words: the borrower gate must be the eligibility register of a verification profile limited to professional clients.</ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/lending-external-securities-v2/api/markets/deployment-options" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(
  'https://api.trusset.org/lending-external-securities-v2/api/markets/deployment-options',
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { data } = await res.json();
const ceiling = data.rateOffering.creatorRateCeilingBps;
```
</RequestExample>

## Error Codes

This endpoint has no refusals of its own beyond authentication, rate limiting and credits. Unreadable factory values come back as `null` instead of an error.
