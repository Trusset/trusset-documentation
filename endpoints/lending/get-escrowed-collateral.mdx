---
title: 'Get Escrowed Collateral'
api: 'GET /lending-external-securities-v2/api/positions/{marketId}/escrowed-collateral/{holderAddress}'
description: 'Read collateral the custody adapter holds in escrow for a holder'
---

Returns the collateral tokens a `CUSTODY` market's adapter holds in escrow for one address. The figure is per holder, not per loan. Every blocked return to that address on this market adds to the same balance.

Escrow is a fail-safe rather than a failure. The adapter returns collateral when a repaid loan closes, when the borrower withdraws collateral, and when a liquidation releases the part it did not seize. If the collateral token refuses that transfer, the adapter escrows the amount instead of reverting the whole operation. The holder reclaims it through [Claim Escrowed Collateral](/endpoints/lending/claim-escrowed-collateral) once the restriction is lifted.

<Note>
  Custody-mode markets only. A `FREEZE` market never escrows, because collateral never leaves the borrower's wallet, and the call is refused with `NOT_CUSTODY_MODE`.
</Note>

This is collateral escrow, held by the custody adapter in the collateral token. A realization surplus is a different balance: the market holds it in the settlement token (stablecoin) after a liquidation paid out more than the debt. Read that one with [Get Escrowed Surplus](/endpoints/lending/get-escrowed-surplus).

## Path Parameters

<ParamField path="marketId" type="string" required>Market ID.</ParamField>

<ParamField path="holderAddress" type="string" required>Address to read the escrow for, `0x` followed by 40 hex characters.</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="holderAddress" type="string">The address queried, lowercased.</ResponseField>
    <ResponseField name="adapterAddress" type="string">Custody adapter holding the escrow, as recorded on the market.</ResponseField>
    <ResponseField name="escrowedCollateral" type="string">Escrowed amount as a decimal string in collateral token units. `"0.0"` when nothing is held.</ResponseField>
    <ResponseField name="escrowedCollateralRaw" type="string">The same amount in the token's smallest unit. `"0"` when nothing is held.</ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL

  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(

const { data } = await res.json();
const claimable = data.escrowedCollateralRaw !== '0';
```

</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `VALIDATION_ERROR` | `400` | `holderAddress` is not `0x` followed by 40 hex characters |
| `NOT_CUSTODY_MODE` | `400` | The market runs in `FREEZE` mode |
| `ESCROW_UNREADABLE` | `400` | The market records no custody adapter, or the adapter could not be read from the network. Retry shortly |
| `MISSING_MARKET_ID` | `400` | The market ID is longer than 100 characters |
| `MARKET_NOT_FOUND` | `404` | No market with this ID on your instance |
