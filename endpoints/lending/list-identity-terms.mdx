---
title: 'List Identity Terms'
api: 'GET /lending-external-securities-v2/api/identity-terms'
description: 'List the identity terms documents of your instance'
---

Returns every [identity terms](/endpoints/lending/identity-terms) document of your instance, most recently changed first. Each row summarizes one document: its status, its latest published version and whether a draft is open. Read a document in full with [Get Identity Terms](/endpoints/lending/get-identity-terms).

An instance keeps at most 50 documents, so the list is never paged.

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="terms" type="array">
      One summary per document.
      <Expandable>
        <ResponseField name="id" type="string">The terms id.</ResponseField>
        <ResponseField name="name" type="string">The name of the document. After a publish, the name of the latest version.</ResponseField>
        <ResponseField name="status" type="string">`DRAFT` before the first publish, then `PUBLISHED`, or `WITHDRAWN` for good.</ResponseField>
        <ResponseField name="latestVersion" type="integer">The latest published version. `0` before the first publish.</ResponseField>
        <ResponseField name="latestCoreHash" type="string">The core hash of the latest version, or `null`.</ResponseField>
        <ResponseField name="publishedAt" type="string">When the latest version was published, or `null`.</ResponseField>
        <ResponseField name="hasDraft" type="boolean">Whether a draft is open.</ResponseField>
        <ResponseField name="draftUpdatedAt" type="string">When the draft was last saved, or `null`.</ResponseField>
        <ResponseField name="createdAt" type="string">When the document was created.</ResponseField>
        <ResponseField name="updatedAt" type="string">When the document last changed. Send it as `expectedUpdatedAt` on [Update Identity Terms](/endpoints/lending/update-identity-terms).</ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/lending-external-securities-v2/api/identity-terms" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(
  'https://api.trusset.org/lending-external-securities-v2/api/identity-terms',
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { success, data, error } = await res.json();
if (!success) throw new Error(`${error.code}: ${error.message}`);
const attachable = data.terms.filter(t => t.status === 'PUBLISHED');
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `RATE_LIMIT_EXCEEDED` | `429` | More than 100 reads in a minute. Retry after the interval in `Retry-After` |
| `IDENTITY_TERMS_LIST_FAILED` | `500` | The list could not be read for a reason that carries no code of its own. Retry, or contact support with the request ID |
