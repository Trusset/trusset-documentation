---
title: 'Get Auction'
api: 'GET /lending-external-securities-v2/api/liquidations/{marketId}/auctions/{auctionId}'
description: 'Retrieve one Dutch auction by ID from the market auction venue'
---

Returns a single auction with its live price, read from the market's auction venue. Unlike [List Active Auctions](/endpoints/lending/list-auctions), this also returns closed auctions, which carry `active: false` and `phase: "CLOSED"`. An auction past its end time that nobody has settled is not closed: it keeps `active: true` with `phase: "EXPIRED"`.

Auction IDs count from `1` on each venue. This reads only the venue the market names now, so after the market admin replaces a venue, the old venue's auctions are no longer reachable here.

## Path Parameters

<ParamField path="marketId" type="string" required>The market's record ID, as `id` on [List Markets](/endpoints/lending/list-markets), not its contract address. See [Market IDs](/endpoints/lending/list-markets#market-ids).</ParamField>
<ParamField path="auctionId" type="string" required>Auction ID on the market's venue. A positive integer.</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="auctionId" type="string">Auction ID, echoed from the path.</ResponseField>
    <ResponseField name="loanId" type="string">Loan whose collateral is on sale.</ResponseField>
    <ResponseField name="borrower" type="string">Borrower whose collateral is on sale, in the checksummed form the chain returns.</ResponseField>
    <ResponseField name="collateralRemaining" type="string">Collateral still for sale, in collateral token units. Zero once the auction is closed.</ResponseField>
    <ResponseField name="debtRemaining" type="string">Debt the auction has not yet discharged, in borrow asset units.</ResponseField>
    <ResponseField name="currentPrice" type="string">Price per whole collateral unit, in borrow asset units, read on this request. The floor price after the end time, and `0.0` once the auction is closed.</ResponseField>
    <ResponseField name="endTime" type="integer">Unix seconds when bidding closes.</ResponseField>
    <ResponseField name="active" type="boolean">Whether the venue still holds the auction open. It turns `false` when the last unit sells or when the auction is settled after expiry.</ResponseField>
    <ResponseField name="expired" type="boolean">`true` while the auction is open and `endTime` has passed.</ResponseField>
    <ResponseField name="biddable" type="boolean">`true` while the auction is open and running.</ResponseField>
    <ResponseField name="settleable" type="boolean">`true` when [Settle Expired Auction](/endpoints/lending/settle-expired-auction) accepts the auction.</ResponseField>
    <ResponseField name="phase" type="string">`RUNNING`, `EXPIRED` or `CLOSED`. Computed against the API server's clock, while the venue judges by the block timestamp.</ResponseField>
    <ResponseField name="venueAddress" type="string">The market's auction venue, lowercased. This is the contract the auction lives on, and the one a bid or a settlement targets.</ResponseField>
  </Expandable>
</ResponseField>

<Warning>
  `AUCTION_NOT_FOUND` does not prove the auction never existed. The same `404` answers an ID above the number of auctions the venue has created, a market with no venue wired, and a venue that could not be read. Check [Get Auction Module](/endpoints/lending/get-auction-module) before concluding an ID is wrong.
</Warning>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `MISSING_MARKET_ID` | `400` | The market ID is longer than 100 characters |
| `NO_MARKET_ADDRESS` | `400` | The market has no on-chain address recorded |
| `AUCTION_NOT_FOUND` | `404` | The ID is not a positive integer within the number of auctions the venue has created, the market has no venue wired, or the venue could not be read |
| `MARKET_NOT_FOUND` | `404` | No market with this ID on your instance |
