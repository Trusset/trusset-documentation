---
title: 'Get Terms Template'
api: 'GET /lending-external-securities-v2/api/markets/terms-library/{templateId}'
description: 'Read one terms library template with its text, its versions and the markets bound to it'
---

Returns one template of this instance's terms library in full: the current text, the version history and every market whose terms are bound to it. Archived templates are returned too. See [List Terms Templates](/endpoints/lending/list-terms-templates) for how the library works.

Any key of the instance can read a template. Only templates of this instance are found.

## Path Parameters

<ParamField path="templateId" type="string" required>
  Template ID from [List Terms Templates](/endpoints/lending/list-terms-templates), 1 to 100 characters.
</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="template" type="object">
      The template with the fields of a row on [List Terms Templates](/endpoints/lending/list-terms-templates#response-fields), `usage` included, plus the fields below.
      <Expandable>
        <ResponseField name="content" type="string">The current text as markdown.</ResponseField>
        <ResponseField name="versions" type="array">
          Every version of the template, newest first, at most 100. The text of an older version is not returned.
          <Expandable>
            <ResponseField name="id" type="string">Version record ID.</ResponseField>
            <ResponseField name="version" type="integer">Version number.</ResponseField>
            <ResponseField name="title" type="string">Title at that version.</ResponseField>
            <ResponseField name="contentHash" type="string">keccak256 over the UTF-8 bytes of the text at that version.</ResponseField>
            <ResponseField name="createdBy" type="string">The issuer account that wrote the version, or `null`.</ResponseField>
            <ResponseField name="createdAt" type="string">ISO 8601.</ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="markets" type="array">
          Every market whose terms of use are bound to the template.
          <Expandable>
            <ResponseField name="generation" type="string">`v2` for a market of the current lending factory, `v1` for one of the earlier generation.</ResponseField>
            <ResponseField name="marketAddress" type="string">Market contract address.</ResponseField>
            <ResponseField name="templateVersion" type="integer">The template version the market's terms were bound at.</ResponseField>
            <ResponseField name="status" type="string">One of `NONE` (no terms), `UNPUBLISHED` (the terms are a draft or offline), `CUSTOM` (terms written without a template), `TEMPLATE_ARCHIVED` (the template is archived), `CUSTOMISED` (the text was edited after binding), `TEMPLATE_OUTDATED` (the template has a newer version than the market published) or `TEMPLATE` (the market serves the current version). The same statuses as `binding.status` on [Get Terms](/endpoints/lending/get-terms).</ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/lending-external-securities-v2/api/markets/terms-library/cmwh2t9e10002l80d7s3k5m8c" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/lending-external-securities-v2/api/markets/terms-library/${templateId}`,
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { success, data, error } = await res.json();
if (!success) throw new Error(`${error.code}: ${error.message}`);
const behind = data.template.markets.filter((market) => market.status === 'TEMPLATE_OUTDATED');
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `VALIDATION_ERROR` | `400` | `templateId` is longer than 100 characters |
| `TEMPLATE_READ_FAILED` | `400` | The template could not be read for a reason that carries no code of its own |
| `TEMPLATE_NOT_FOUND` | `404` | No template with this ID exists on this instance |
