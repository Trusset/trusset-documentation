---
title: 'Get Oracle Status'
api: 'GET /lending-external-securities-v2/api/markets/{marketId}/oracle-status'
description: 'Read the current price, staleness, and signer authorization'
---

Returns the market oracle's current state. Check this before any borrow or liquidation flow, since the contract rejects actions priced against a stale oracle.

A stale price makes opening a loan, borrowing more, liquidating, and withdrawing collateral against outstanding debt revert, unless the transaction carries a fresh [signed price](/endpoints/lending/sign-price). Repaying never reads a price, so a stale oracle never blocks a repayment.

## Path Parameters

<ParamField path="marketId" type="string" required>Market ID.</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="configured" type="boolean">Whether the oracle was readable. When `false`, the fields marked conditional below are absent and an `error` field is present instead.</ResponseField>
    <ResponseField name="price" type="string">Current price as a decimal string, in borrow asset units.</ResponseField>
    <ResponseField name="priceRaw" type="string">Same price in base units.</ResponseField>
    <ResponseField name="timestamp" type="integer">Unix seconds the current price is dated at. A pushed price carries its block time and a signed price its signed `timestamp`. On an `ORACLE`-priced market it is the external feed's own date.</ResponseField>
    <ResponseField name="lastUpdate" type="string">The same instant as an ISO 8601 string. `null` only when `configured` is `false`.</ResponseField>
    <ResponseField name="isStale" type="boolean">Whether the price is older than `maxPriceAge`. An external feed that cannot answer reads as stale.</ResponseField>
    <ResponseField name="priceAge" type="integer">Seconds since the price's date. Conditional on `configured`.</ResponseField>
    <ResponseField name="maxPriceAge" type="integer">Staleness threshold in seconds, read from the oracle. It is an oracle setting and is not part of the market config struct. It defaults to 24 hours, and the oracle owner can set it between 1 minute and 30 days. Conditional on `configured`.</ResponseField>
    <ResponseField name="maxDeviationBps" type="integer">Circuit breaker limit in basis points. A price push differing from the current price by more than this is rejected, and the same limit bounds the total movement within any one-hour window. Reported as `5000` when the oracle does not expose the value. It does not apply to an external feed. Conditional on `configured`.</ResponseField>
    <ResponseField name="owner" type="string">Oracle owner address. The owner is implicitly an authorized signer. Conditional on `configured`.</ResponseField>
    <ResponseField name="ownerIsInstanceWallet" type="boolean">Whether that owner is a verified wallet of your instance. When `false`, the oracle belongs to another party and no wallet of this instance can authorize signers on it. Conditional on `configured`.</ResponseField>
    <ResponseField name="signerAddress" type="string">This instance's first verified wallet, primary wallet first, or `null` when none is verified. Conditional on `configured`.</ResponseField>
    <ResponseField name="signerAuthorized" type="boolean">Whether that wallet can push and sign prices for this oracle, as an authorized signer or as the owner. `false` when no wallet is verified.</ResponseField>
    <ResponseField name="priceSigner" type="string">The wallet the lender of record declared as this market's price authority when it took the role, or `null`. It is not necessarily your registered wallet. It is the address [Sync Oracle Price](/endpoints/lending/sync-oracle) and [Sign Price](/endpoints/lending/sign-price) resolve to when you name none.</ResponseField>
    <ResponseField name="priceSignerAuthorized" type="boolean">Whether that declared signer is an authorized signer on the oracle. `null` when no signer is declared or the read failed.</ResponseField>
    <ResponseField name="error" type="string">Present only when `configured` is `false`.</ResponseField>
  </Expandable>
</ResponseField>

<Warning>
  The failure response is a different shape, not an error status. When `configured` is `false` the endpoint still returns `200` with `price: "0"`, `isStale: true`, and no `priceAge`, `maxPriceAge`, `maxDeviationBps`, `owner`, `ownerIsInstanceWallet` or `signerAddress`. Guard on `configured` before reading those fields.
</Warning>

A healthy answer is held for up to 15 seconds per market and instance. Any successful write through this API clears it, so a read right after a confirmed price push reaches the chain.

## Price Decimals

Oracle prices carry the market's borrow asset decimals, not a fixed precision. The price is per whole collateral token, in the smallest unit of the settlement token (stablecoin): a 6-decimal token prices at 6 decimals, an 18-decimal one at 18. Read `borrowAssetDecimals` from [Get Market](/endpoints/lending/get-market) rather than assuming.

## External Feed Markets

A market deployed with the `ORACLE` price source reads an external feed. Its oracle takes no pushed or signed price, so `price` and `timestamp` are the feed's live answer rescaled to the borrow asset's decimals. When the feed cannot answer, `isStale` reads `true` and the price read fails. Read `priceSource` from [Get Market](/endpoints/lending/get-market) to tell the two kinds apart.

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `NO_ORACLE` | `400` | The market records no oracle address |
| `MISSING_MARKET_ID` | `400` | `marketId` is longer than 100 characters |
| `MARKET_NOT_FOUND` | `404` | No market with this ID on your instance |
