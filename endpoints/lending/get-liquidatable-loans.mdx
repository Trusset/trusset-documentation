---
title: 'Get Liquidatable Loans'
api: 'GET /lending-external-securities-v2/api/liquidations/{marketId}/liquidatable-loans'
description: 'List loans that can be liquidated now, on health or on an expired term'
---

Scans the market's active loans and returns every loan that [Liquidate Loan](/endpoints/lending/liquidate) would accept now. A loan qualifies on either of two triggers. Its health factor is below `1.0`, or its term has run past its effective due date plus the grace period, however healthy its collateral is. A market that makes open-ended loans has only the first trigger.

The first scan reads every loan the market has ever opened. Later scans read only the loans still known to be active plus any opened since, so the cost grows with the active book. Poll it on a schedule rather than per page view.

<Warning>
  A failed chain read is not reported as an error. If the market's loan counter cannot be read, the response carries `totalActiveLoans: 0` and empty lists. A loan whose own read fails is left out, and when the term reads fail, loans that qualify only on their term are missing too. An empty `liquidatableLoans` is therefore not proof that the book is healthy. `onChainError` appears only when composing the response fails after the reads.
</Warning>

## Path Parameters

<ParamField path="marketId" type="string" required>Market ID. At most 100 characters.</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="totalActiveLoans" type="integer">Active loans scanned.</ResponseField>
    <ResponseField name="liquidatableLoans" type="array">
      Loans that qualify now on either trigger. A loan with an open auction, running or expired but not yet settled, is listed under `auctionedLoans` instead.
      <Expandable>
        <ResponseField name="loanId" type="string">On-chain loan ID. Pass this to [Liquidate Loan](/endpoints/lending/liquidate).</ResponseField>
        <ResponseField name="borrower" type="string">Borrower address.</ResponseField>
        <ResponseField name="collateralAmount" type="string">Collateral pledged, in collateral token units.</ResponseField>
        <ResponseField name="principal" type="string">Outstanding principal, in borrow asset units.</ResponseField>
        <ResponseField name="accruedInterest" type="string">Accrued unpaid interest, in borrow asset units.</ResponseField>
        <ResponseField name="healthFactor" type="string">Health factor at 18 decimal places. At or above `1.0` when the loan qualifies on its term alone.</ResponseField>
        <ResponseField name="trigger" type="string">`HEALTH`, `TERM` or `HEALTH_AND_TERM`. A loan realized on its term, whatever its health, is realized whole at the term penalty.</ResponseField>
        <ResponseField name="term" type="object">The loan's term, present when it carries one. Same fields as the entries of `termedLoans`.</ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="termedLoans" type="array">
      Every active loan that carries a term, enforceable or not. Empty on a market that runs no loan terms.
      <Expandable>
        <ResponseField name="loanId" type="string">On-chain loan ID.</ResponseField>
        <ResponseField name="borrower" type="string">Borrower address.</ResponseField>
        <ResponseField name="dueAt" type="string">Unix seconds the loan falls due under its own term.</ResponseField>
        <ResponseField name="effectiveDueAt" type="string">Unix seconds of the effective due date: `dueAt`, or the market's due floor when that is later.</ResponseField>
        <ResponseField name="graceEnd" type="string">Unix seconds the grace period ends. After this the loan is liquidatable whatever its health.</ResponseField>
        <ResponseField name="enforceable" type="boolean">Whether the term can be enforced now.</ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="auctionedLoans" type="array">
      Active loans with a Dutch auction still open on the market's auction venue. `liquidate` refuses these until the auction clears or is settled after expiry.
      <Expandable>
        <ResponseField name="loanId" type="string">On-chain loan ID.</ResponseField>
        <ResponseField name="borrower" type="string">Borrower address.</ResponseField>
        <ResponseField name="auctionId" type="string">The auction realizing this loan.</ResponseField>
        <ResponseField name="endTime" type="integer">Unix seconds when bidding closes.</ResponseField>
        <ResponseField name="expired" type="boolean">`true` once `endTime` has passed. Such an auction waits for [Settle Expired Auction](/endpoints/lending/settle-expired-auction).</ResponseField>
        <ResponseField name="collateralRemaining" type="string">Collateral still for sale, in collateral token units.</ResponseField>
        <ResponseField name="debtRemaining" type="string">Debt the auction has not yet discharged, in borrow asset units.</ResponseField>
        <ResponseField name="healthFactor" type="string">The loan's health factor at 18 decimal places.</ResponseField>
        <ResponseField name="reason" type="string">Why the loan is not offered for liquidation, in words.</ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="onChainError" type="string">Present only when composing the response failed. The counter then reads `0` and `liquidatableLoans` is empty. See the warning above.</ResponseField>
  </Expandable>
</ResponseField>

<Note>
  Health factors are computed against the oracle's stored price, and term enforceability against the time of the read. If the price is stale the health figures are stale too, and [Liquidate Loan](/endpoints/lending/liquidate) refuses every loan with `PRICE_STALE` until a fresh price is on the oracle. Push a current NAV with [Sync Oracle Price](/endpoints/lending/sync-oracle) before acting on this list.
</Note>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/lending-external-securities-v2/api/liquidations/{marketId}/liquidatable-loans" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/lending-external-securities-v2/api/liquidations/${marketId}/liquidatable-loans`,
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { data } = await res.json();
if (data.onChainError) throw new Error(`Scan failed: ${data.onChainError}`);
const onTerm = data.liquidatableLoans.filter((loan) => loan.trigger !== 'HEALTH');
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `MISSING_MARKET_ID` | `400` | `marketId` is longer than 100 characters |
| `NO_MARKET_ADDRESS` | `400` | The market has no on-chain address recorded |
| `MARKET_NOT_FOUND` | `404` | No market with this ID on your instance |
