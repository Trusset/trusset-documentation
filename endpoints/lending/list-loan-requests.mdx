---
title: 'List Loan Requests'
api: 'GET /lending-external-securities-v2/api/markets/{marketId}/loan-requests'
description: 'List the loan requests of a market'
---

Lists the market's loan requests. The lender of record sees every request of the market. Any other instance sees the requests it made and those naming one of its verified wallets.

The list is paged with `limit` and `offset`. Without a `status` filter, open requests come first: `REQUESTED`, then `APPROVED`, then the rest, each with the newest change first. A waiting request is never cut off by newer history. With a `status` filter, the newest change comes first.

## Path Parameters

<ParamField path="marketId" type="string" required>
  The market's record ID on your instance.
</ParamField>

## Query Parameters

<ParamField query="status" type="string">
  One status: `REQUESTED`, `APPROVED`, `USED`, `DECLINED`, `WITHDRAWN`, `REVOKED`, `EXPIRED` or `CLOSED`. Any other value answers `400 INVALID_STATUS`.
</ParamField>

<ParamField query="borrower" type="string">
  Only this wallet's requests.
</ParamField>

<ParamField query="limit" type="number" default="200">
  How many requests to return, from 1 to 200.
</ParamField>

<ParamField query="offset" type="number" default="0">
  How many matching requests to skip.
</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="requests" type="object[]">Each as [Get Loan Request](/endpoints/lending/get-loan-request#response-fields) returns it.</ResponseField>
    <ResponseField name="total" type="number">How many requests match, across all pages.</ResponseField>
    <ResponseField name="limit" type="number">The page size that was applied.</ResponseField>
    <ResponseField name="offset" type="number">The offset that was applied.</ResponseField>
    <ResponseField name="truncated" type="boolean">`true` when more requests match beyond this page. Read the next page with `offset`.</ResponseField>
    <ResponseField name="waiting" type="number">How many requests your instance sees that are still `REQUESTED`, whatever the page and the `status` filter. A `borrower` filter narrows it.</ResponseField>
    <ResponseField name="mode" type="object">The market's mode. See [Get Loan Approvals](/endpoints/lending/get-loan-approvals#response-fields).</ResponseField>
    <ResponseField name="viewer.isBank" type="boolean">Whether your instance sees every request as the lender of record.</ResponseField>
    <ResponseField name="marketId" type="string">The market's record ID on your instance.</ResponseField>
  </Expandable>
</ResponseField>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `INVALID_STATUS` | `400` | `status` is not one of the eight statuses |
| `INVALID_WALLET` | `400` | `borrower` is not an address |
| `VALIDATION_ERROR` | `400` | `limit` is not a whole number from 1 to 200, or `offset` is not a whole number from 0 to 1000000 |
