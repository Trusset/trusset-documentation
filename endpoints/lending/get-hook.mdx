---
title: 'Get Hook'
api: 'GET /lending-external-securities-v2/api/hooks/{marketId}/{hookId}'
description: 'Retrieve a single hook by ID'
---

Returns one hook record, with the fields [List Hooks](/endpoints/lending/list-hooks) documents. The hook must belong to the market named in the path. A hook on another market returns `HOOK_NOT_FOUND`, as an unknown ID does.

## Path Parameters

<ParamField path="marketId" type="string" required>Market ID.</ParamField>
<ParamField path="hookId" type="string" required>Hook ID.</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  The hook record. See [List Hooks](/endpoints/lending/list-hooks) for each field.
</ResponseField>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/lending-external-securities-v2/api/hooks/{marketId}/{hookId}" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/lending-external-securities-v2/api/hooks/${marketId}/${hookId}`,
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { data: hook } = await res.json();
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `MISSING_MARKET_ID` | `400` | `marketId` is longer than 100 characters |
| `MISSING_HOOK_ID` | `400` | `hookId` is longer than 100 characters |
| `MARKET_NOT_FOUND` | `404` | No market with this ID belongs to your instance |
| `HOOK_NOT_FOUND` | `404` | No hook with this ID exists on this market |
