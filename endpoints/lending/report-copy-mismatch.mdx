---
title: 'Report Copy Mismatch'
api: 'POST /lending-external-securities-v2/api/markets/{marketId}/loan-agreements/{ref}/copy-mismatch'
description: 'Tell the bank that the borrower copy does not match the reported commitment'
---

Tells the bank that the borrower's own copy, checked with the salt, does not match the reported commitment. It sends no file and no hash, changes no status, and delivers `loan.agreement.copy_mismatch` to the bank's hooks. Signing tools can produce a new file on each download, so the bank can send its original file or report again. The borrower may also accept with `copyVerified: false`.

## Who can call

The borrower side.

## Path Parameters

<ParamField path="marketId" type="string" required>
  The market's record ID on your instance.
</ParamField>

<ParamField path="ref" type="string" required>
  The agreement reference: `agr_` followed by 20 characters.
</ParamField>

## Body Parameters

None. Send an empty object.

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `DOCUMENT_CONTENT_REFUSED` | `400` | The body carries file content. Keep the file with you and send only the salted commitment |
| `PLAIN_HASH_REFUSED` | `400` | The body carries the plain hash of a file (`contentHash`, `sha256` and similar). Send the salted commitment instead |
| `PERSONAL_DATA_REFUSED` | `400` | The body carries a personal data field such as `name` or `email`. Use wallet addresses and `externalReference` only |
| `VALIDATION_ERROR` | `400` | A field is missing, has the wrong type, or is not part of this route |
| `AGREEMENT_BORROWER_ONLY` | `403` | Your instance did not request the agreement and does not hold the borrower wallet |
| `AGREEMENT_STATE` | `409` | The agreement is in a status that does not allow this. `details.status` names it; read the agreement for its next step |
| `AGREEMENT_NOT_FOUND` | `404` | No agreement with this reference on this market, or your instance is not a party to it. List the agreements to find it |
| `MARKET_NOT_FOUND` | `404` | No market with this ID on your instance |
| `CHAIN_UNAVAILABLE`, `SERVICE_UNAVAILABLE` | `503` | The market or your instance's wallets could not be read just now. Nothing was decided. Retry shortly |
