---
title: 'Read Signing Link'
api: 'GET /public/identity-terms/sign/{token}'
authMethod: 'none'
description: 'Read the identity terms version a signing link asks a member to sign'
---

Returns what a signing link asks its member to sign: the published version of the [identity terms](/endpoints/lending/identity-terms) in full, who the member is, who wrote the terms, which KYC provider they name, and the EIP-712 typed data the member's wallet signs. Show all of it to the member before it signs.

This route is public. It takes no API key: the token in the link is the authority. It answers with `Cache-Control: no-store` and `Referrer-Policy: no-referrer`, and allows 20 reads per minute from one address. Reading does not use up the link.

Then sign with [Sign Identity Terms](/endpoints/lending/sign-identity-terms), or decline with [Decline Identity Terms](/endpoints/lending/decline-identity-terms).

## Path Parameters

<ParamField path="token" type="string" required>
  The token of the link: the 64 hex characters after `/sign/identity-terms/`.
</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="terms" type="object">`{ name, version, chainId, coreHash, core }`. `core` is the whole published version, exactly as hashed.</ResponseField>
    <ResponseField name="member" type="object">`{ index, legalName, roles, wallet }` of the member this link is for. Only `wallet` can sign.</ResponseField>
    <ResponseField name="author" type="object">`{ legalName }` of the organisation that published the terms.</ResponseField>
    <ResponseField name="kycProvider" type="object">`{ legalName, lei, registerId }` of the obliged entity the terms name. `lei` and `registerId` read `null` when not given.</ResponseField>
    <ResponseField name="typedData" type="object">`{ domain, types, primaryType, message }`, ready for `eth_signTypedData_v4`. `message` is `{ coreHash, member, wallet }`. See [Signing](/endpoints/lending/identity-terms#signing).</ResponseField>
    <ResponseField name="expiresAt" type="string">When the link expires.</ResponseField>
    <ResponseField name="declineReasons" type="array">`NOT_OUR_ROLE`, `WRONG_DATA` and `NOT_AGREED`.</ResponseField>
  </Expandable>
</ResponseField>

import { utils } from 'ethers';

function prune(value: unknown): unknown {
  if (Array.isArray(value)) return value.map(prune).filter(v => !isEmpty(v));
  if (value && typeof value === 'object') {
    const out: Record<string, unknown> = {};
    for (const [key, item] of Object.entries(value)) {
      const pruned = prune(item);
      if (!isEmpty(pruned)) out[key] = pruned;
    }
    return out;
  }
  return value;
}

function isEmpty(value: unknown): boolean {
  if (value === null || value === undefined || value === '') return true;
  if (Array.isArray(value)) return value.length === 0;
  return typeof value === 'object' && Object.keys(value as object).length === 0;
}

function canonical(value: unknown): string {
  if (Array.isArray(value)) return `[${value.map(canonical).join(',')}]`;
  if (value && typeof value === 'object') {
    const entries = Object.entries(value as Record<string, unknown>).sort(([a], [b]) => (a < b ? -1 : a > b ? 1 : 0));
    return `{${entries.map(([key, item]) => `${JSON.stringify(key)}:${canonical(item)}`).join(',')}}`;
  }
  return JSON.stringify(value);
}

const res = await fetch(`https://api.trusset.org/public/identity-terms/sign/${token}`);
const { success, data, error } = await res.json();
if (!success) throw new Error(`${error.code}: ${error.message}`);

const recomputed = utils.keccak256(utils.toUtf8Bytes(canonical(prune(data.terms.core))));
if (recomputed !== data.terms.coreHash) throw new Error('The core does not match its hash');

## Error Codes

A refusal on the public routes carries `error.code`, `error.message` and, where there is one, `error.remedy` and `error.field`.

| Code | HTTP | Cause |
|---|---|---|
| `IDENTITY_TERMS_INVITE_INVALID` | `400` | The token is not 64 lower-case hex characters. Open the link exactly as you received it |
| `IDENTITY_TERMS_INVITE_NOT_FOUND` | `404` | No link with this token exists. Ask the author for a new one |
| `IDENTITY_TERMS_INVITE_EXPIRED` | `410` | The link is older than 14 days. Ask the author for a new one |
| `IDENTITY_TERMS_INVITE_REVOKED` | `410` | The link was revoked, the terms were withdrawn, or a newer version was published. Ask the author for a link to the current version |
| `IDENTITY_TERMS_INVITE_USED` | `410` | The member already answered through this link |
| `RATE_LIMIT_EXCEEDED` | `429` | More than 20 reads in a minute from one address. Wait a minute |
| `IDENTITY_TERMS_SIGNING_FAILED` | `500` | The request could not be completed. Retry in a moment |
