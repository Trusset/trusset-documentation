---
title: 'List Positions'
api: 'GET /lending-external-securities-v2/api/positions/{marketId}/positions'
description: 'List every borrowing position recorded for a market'
---

Returns every position recorded for a market, newest first, each with its five most recent transactions. There is no pagination: the whole book comes back in one response.

The endpoint reconciles against the chain in two steps before it answers. First, an event sweep records loans opened by any wallet and writes terminal statuses from the `LoanClosed` and `LoanLiquidated` events and auction starts it finds. The sweep runs at most once a minute per market.

Second, a live read of the open positions pulls collateral, principal, interest, health factor, due date and stamped rate from the market contract and writes them back to the records. If the chain is unreachable, both steps are skipped and stored values are returned unchanged.

Live state is fetched for the first 50 open positions only. Beyond that the stored values are served, so a market with more than 50 open loans returns a mix. The `compliance` block is attached to those open positions for at most 25 distinct borrowers.

`status` is never inferred from the live read. A terminal label is written only by the confirm calls and the event sweep that can attest to it. A loan the chain reports as closed therefore keeps its recorded status until its evidence arrives.

## Path Parameters

<ParamField path="marketId" type="string" required>Market ID.</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="positions" type="array">
      Position records ordered by `openedAt` descending.
      <Expandable>
        <ResponseField name="id" type="string">Position ID. Use it with [Get Position](/endpoints/lending/get-position) and [Get Position Statement](/endpoints/lending/get-position-statement).</ResponseField>
        <ResponseField name="marketId" type="string">Market ID.</ResponseField>
        <ResponseField name="onChainLoanId" type="string">Numeric loan ID on the market contract. Null when the position was recorded without a linked chain loan.</ResponseField>
        <ResponseField name="userAddress" type="string">Borrower address, lowercased.</ResponseField>
        <ResponseField name="customerId" type="string">The [customer](/endpoints/customers/get) this loan is attributed to, set when [Open Loan](/endpoints/lending/open-loan) was confirmed with a `clientReference`. Null when the loan is unattributed.</ResponseField>
        <ResponseField name="customerAttributedAt" type="string">ISO 8601 timestamp the attribution was made or last moved. Null when the loan is unattributed.</ResponseField>
        <ResponseField name="collateralAmount" type="string">Collateral posted, in collateral token units.</ResponseField>
        <ResponseField name="borrowedAmount" type="string">Outstanding principal, in borrow asset units.</ResponseField>
        <ResponseField name="interestAccrued" type="string">Interest accrued and unpaid, in borrow asset units.</ResponseField>
        <ResponseField name="healthFactor" type="string">Health factor as a decimal string. At or above `1.0` the loan is healthy, below `1.0` it is liquidatable on health. Null once the status is not `ACTIVE`, and for an open loan with no debt.</ResponseField>
        <ResponseField name="priceAtBorrow" type="string">Collateral price recorded when the loan was opened, in borrow asset units.</ResponseField>
        <ResponseField name="dueAt" type="string">Unix seconds this loan falls due, as last read from the chain. Null on an open-ended loan, and until a live read has recorded it.</ResponseField>
        <ResponseField name="fixedRate" type="string">The stamped rate in basis points as stored on the record. Null until a live read has recorded it.</ResponseField>
        <ResponseField name="status" type="string">One of `ACTIVE`, `REPAID`, `LIQUIDATED`.</ResponseField>
        <ResponseField name="liquidated" type="boolean">Whether any collateral was seized from this position. A partial liquidation sets it while `status` stays `ACTIVE`.</ResponseField>
        <ResponseField name="liquidatedAt" type="string">ISO 8601 timestamp of the first seizure, or null.</ResponseField>
        <ResponseField name="closedAt" type="string">ISO 8601 timestamp of closure, or null.</ResponseField>
        <ResponseField name="openedAt" type="string">ISO 8601 timestamp the loan opened. It is the block time of the opening transaction where known, otherwise the time the record was written.</ResponseField>
        <ResponseField name="lastUpdated" type="string">ISO 8601 timestamp of the last write.</ResponseField>
        <ResponseField name="transactions" type="array">The five most recent transactions on this position, newest first. Each carries `id`, `marketId`, `positionId`, `txType`, `userAddress`, `amount`, `txHash` and `timestamp`.</ResponseField>
        <ResponseField name="term" type="object">
          The loan's term state, with the same fields as `term` on [Get Loan](/endpoints/lending/get-loan): `dueAt`, `effectiveDueAt`, `graceEnd`, `enforceable`, `termGracePeriod`, `termPenaltyBps`, `stamped` and `termSource`. Present only when this response read the loan from the chain, which covers at most the first 50 open and the first 50 closed positions. Absent or null on an open-ended loan. `enforceable` is the term trigger: `true` once the grace period after the effective due date has run out, whatever the health factor.
        </ResponseField>
        <ResponseField name="fixedRateBps" type="integer">The rate stamped on this loan when it opened, in basis points. `0` when the market's rate model was not in `FIXED` mode at signing. Present under the same condition as `term`.</ResponseField>
        <ResponseField name="compliance" type="object">What the collateral token would currently permit for this borrower, in the shape described on [Get Loan](/endpoints/lending/get-loan#compliance). Open positions only, within the limits above.</ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<Note>
  Positions are recorded when a loan is opened through this API on confirm, and are backfilled from chain events by the sweep. A loan opened by a wallet signing calldata directly is picked up by the next sweep, rather than at broadcast time.
</Note>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/lending-external-securities-v2/api/positions/{marketId}/positions" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/lending-external-securities-v2/api/positions/${marketId}/positions`,
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { data } = await res.json();
const atRisk = data.positions.filter(
  p => (p.healthFactor !== null && parseFloat(p.healthFactor) < 1.1) || p.term?.enforceable === true
);
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `MISSING_MARKET_ID` | `400` | The market ID is longer than 100 characters |
| `MARKET_NOT_FOUND` | `404` | No market with this ID on your instance |
