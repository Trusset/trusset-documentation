---
title: 'List Hook Deliveries'
api: 'GET /lending-external-securities-v2/api/hooks/{marketId}/{hookId}/deliveries'
description: 'List the signed webhook deliveries of a hook with their status and attempts'
---

Returns the hook's webhook deliveries, newest first, with pagination counters. Each one is an event queued for the hook's `webhookUrl`: a liquidation announced to an `inform` hook, an [Execute Hook](/endpoints/lending/execute-hook) call on one, or a monitor's breach. Every field of a delivery is read from Trusset's queue, and nothing is sent or retried by this call.

Only an `inform` action queues deliveries, so a hook that never ran one returns an empty list. [Signed deliveries](/endpoints/lending/create-hook#signed-deliveries) describes the request each attempt sends.

Delivered and failed deliveries are kept for at least 30 days after they were queued and removed after that, and `total` counts only what is kept. [Delete Hook](/endpoints/lending/delete-hook) removes all of the hook's deliveries at once.

## Path Parameters

<ParamField path="marketId" type="string" required>The market's record ID, as `id` on [List Markets](/endpoints/lending/list-markets), not its contract address. See [Market IDs](/endpoints/lending/list-markets#market-ids).</ParamField>
<ParamField path="hookId" type="string" required>Hook ID.</ParamField>

## Query Parameters

<ParamField query="limit" type="integer" default="50">
  Records to return, 1 to 200. Out-of-range values are clamped rather than refused: above 200 returns 200, a negative value returns 1, and `0` or a non-number falls back to 50.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Records to skip. A negative value or a non-number counts as 0.
</ParamField>

## Delivery status

| `status` | Meaning |
|---|---|
| `PENDING` | Queued, and no attempt has failed yet. An attempt may be under way |
| `RETRYING` | An attempt failed in a way that is retried. The next one is due at `nextAttemptAt` |
| `DELIVERED` | The endpoint answered `2xx`. Final |
| `FAILED` | An attempt failed in a way that is not retried, or the eighth attempt failed. Final |

A delivery that reaches `DELIVERED` or `FAILED` also writes one entry to [Get Hook Executions](/endpoints/lending/get-hook-executions) and counts as a run in the hook's `executionCount`. Nothing re-sends a `FAILED` delivery.

## Retries

Each attempt waits up to 15 seconds for an answer. A retried failure makes the next attempt due a set time after the failed one started: 10 seconds after the first attempt, then 30 seconds, 1 minute, 5, 15 and 30 minutes, and 1 hour after the seventh. The eighth attempt is the last.

| `error` | Retried |
|---|---|
| `HTTP` and the status, for a `5xx`, `408`, `425` or `429` answer | Yes |
| `HTTP` and the status, for any other `4xx` answer | No |
| `Endpoint answered with a redirect (HTTP 3xx); redirects are not followed`, with the actual status | No |
| `No answer within 15 seconds` | Yes |
| `Endpoint host could not be resolved` | Yes |
| `Could not connect to the endpoint`, with the network error code in parentheses when there is one | Yes |
| `Endpoint must be a public host` | No |
| `Endpoint answered with a body larger than 64 KB` | No |

Each attempt goes to the `webhookUrl` the hook holds when it is sent, signed with the secret the hook holds at that moment.

<RequestExample>
```bash cURL
curl "https://api.trusset.org/lending-external-securities-v2/api/hooks/{marketId}/{hookId}/deliveries?limit=10" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/lending-external-securities-v2/api/hooks/${marketId}/${hookId}/deliveries?limit=10&offset=0`,
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { data } = await res.json();
const failed = data.deliveries.filter((d) => d.status === 'FAILED');
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `MISSING_MARKET_ID` | `400` | `marketId` is longer than 100 characters |
| `MISSING_HOOK_ID` | `400` | `hookId` is longer than 100 characters |
| `MARKET_NOT_FOUND` | `404` | No market with this ID belongs to your instance |
| `HOOK_NOT_FOUND` | `404` | No hook with this ID exists on this market |
