---
title: 'Get Upgrade Status'
api: 'GET /lending-external-securities-v2/api/markets/{marketId}/upgrade'
description: 'Compare the implementations a market runs with the ones the factory serves'
---

Reports, for the market and each of its four upgradeable satellites, which implementation it runs, which one the factory serves today, whether an upgrade is available, and what is announced. The market, its interest rate model, its liquidation router, its price oracle and its insurance fund are separate proxies with separate authorities, and each entry names who must sign its upgrade. [Upgrade Market](/endpoints/lending/upgrade-market) builds the transactions.

Each entry carries a `notice`. Every upgrade is announced 7 days before it can execute, and the notice says which implementation is announced and when it becomes `ready`.

An upgrade is offered only to a market the factory deployed and recorded. When the address is not a market of the lending factory this instance deploys to, `inFactory` is `false` and no entry offers an upgrade.

The read never fails outright. When the factory or the chain cannot be reached, it answers with `readable: false` and empty entries.

## Path Parameters

<ParamField path="marketId" type="string" required>The market's record ID, as `id` on [List Markets](/endpoints/lending/list-markets), not its contract address. See [Market IDs](/endpoints/lending/list-markets#market-ids).</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="marketId" type="string">Market ID.</ResponseField>
    <ResponseField name="marketAddress" type="string">Market contract address.</ResponseField>
    <ResponseField name="readable" type="boolean">Whether the market's implementation pointer could be read.</ResponseField>
    <ResponseField name="roleModel" type="boolean">`true`: the market runs the guardian role, upgrade notice, admin guard, threshold cooldown and the 20 percent infrastructure fee. `null` when unreadable.</ResponseField>
    <ResponseField name="notice" type="object">
      The market's upgrade notice. `null` when it could not be read.
      <Expandable>
        <ResponseField name="address" type="string">The proxy, lowercased.</ResponseField>
        <ResponseField name="supported" type="boolean">`true`: the proxy announces every upgrade. `null` when unreadable.</ResponseField>
        <ResponseField name="readable" type="boolean">Present when `supported` is `true`. `false` when the announced values could not be read.</ResponseField>
        <ResponseField name="pendingImplementation" type="string">The announced implementation, lowercased, or `null` when nothing is announced.</ResponseField>
        <ResponseField name="activatesAt" type="integer">Unix seconds from which the announced upgrade can execute, or `null`. `activatesAtIso` is the same as ISO 8601.</ResponseField>
        <ResponseField name="ready" type="boolean">`true` when an announced upgrade can execute now.</ResponseField>
        <ResponseField name="secondsUntilReady" type="integer">Seconds until `activatesAt`, or `0`.</ResponseField>
        <ResponseField name="delaySeconds" type="integer">`604800`, the 7-day notice.</ResponseField>
        <ResponseField name="authority" type="object">Who announces and executes. `kind` is `role`, with `role`, `contract` and `requiredRole`, or `owner`, with `owner`, `ownedByMarket` and `requiredRole`, plus a `label` in words. On the rate model a `note` says the owner keeps the parameters.</ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="currentImplementation" type="string">The implementation the market runs, or `null`.</ResponseField>
    <ResponseField name="targetImplementation" type="string">The market implementation the factory serves, or `null` when it serves none or the market is not in the factory.</ResponseField>
    <ResponseField name="upgradeAvailable" type="boolean">Whether the two differ, so an upgrade can be built.</ResponseField>
    <ResponseField name="description" type="string">What the upgrade changes, in words, when one is available. It names only what the target implementation adds over the one the market runs. Otherwise `null`.</ResponseField>
    <ResponseField name="instrumented" type="boolean">Whether the market's implementation can emit an on-demand history snapshot.</ResponseField>
    <ResponseField name="stampsLoanTerms" type="boolean">`true`: the market stamps the grace period and term penalty onto each loan at signing. `null` when unreadable.</ResponseField>
    <ResponseField name="feeShareGeneration" type="string">Always `FIXED_SHARES`: the market pays the fixed 8 percent operator and 5 percent distributor shares. `null` when unreadable.</ResponseField>
    <ResponseField name="perimeter" type="object">Always `null`. Every market already runs separate borrower and provider registers.</ResponseField>
    <ResponseField name="feeModel" type="object">Always `null`. Every market already pays the fixed fee shares.</ResponseField>
    <ResponseField name="inFactory" type="boolean">Whether the factory holds a deployment record for this market. `null` when the factory could not be read.</ResponseField>
    <ResponseField name="reason" type="string">`MARKET_NOT_IN_FACTORY` when `inFactory` is `false`, with the explanation in `reasonMessage`. Absent otherwise.</ResponseField>
    <ResponseField name="requiredRole" type="string">`DEFAULT_ADMIN_ROLE`: the market admin signs the market's upgrade.</ResponseField>
    <ResponseField name="walletAddress" type="string">The instance's registered wallet, or `null`.</ResponseField>
    <ResponseField name="walletIsAdmin" type="boolean">Whether that wallet holds `DEFAULT_ADMIN_ROLE` on the market.</ResponseField>
    <ResponseField name="relayerAddress" type="string">Deprecated. The same value as `walletAddress`.</ResponseField>
    <ResponseField name="relayerIsAdmin" type="boolean">Deprecated. The same value as `walletIsAdmin`.</ResponseField>
    <ResponseField name="rateModel" type="object">
      The interest rate model. `null` when it could not be resolved.
      <Expandable>
        <ResponseField name="address" type="string">The model's proxy address.</ResponseField>
        <ResponseField name="readable" type="boolean">Whether its implementation pointer could be read.</ResponseField>
        <ResponseField name="currentImplementation" type="string">The implementation it runs.</ResponseField>
        <ResponseField name="targetImplementation" type="string">The implementation the factory serves, or `null`.</ResponseField>
        <ResponseField name="upgradeAvailable" type="boolean">Whether an upgrade can be built.</ResponseField>
        <ResponseField name="owner" type="string">Its owner, who signs the upgrade.</ResponseField>
        <ResponseField name="pendingOwner" type="string">The owner nominated by the lender of record and not yet accepted, or `null`.</ResponseField>
        <ResponseField name="ownedByMarket" type="boolean">`true` while the market or the factory still owns it, which is the case until a lender of record takes the market. No wallet can upgrade it in that state.</ResponseField>
        <ResponseField name="requiredRole" type="string">`DEFAULT_ADMIN_ROLE`: the market admin announces and executes its upgrade, while `owner` keeps the curve parameters, the rate mode and the ceiling.</ResponseField>
        <ResponseField name="notice" type="object">The model's upgrade notice, shaped like the market's. When the model cannot be resolved it is `{ address: null, supported: null, reason }`.</ResponseField>
        <ResponseField name="description" type="string">What the upgrade changes, when one is available.</ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="router" type="object">The liquidation router: `routerAddress`, `currentImplementation`, `targetImplementation`, `upgradeAvailable`, `notice`, and `description` when an upgrade is available, naming only what the target adds over the implementation the router runs. The router admin signs its upgrade. `null` when it could not be resolved.</ResponseField>
    <ResponseField name="insuranceFund" type="object">The insurance fund, with the same fields as `rateModel` plus `heldByFactory`, `true` while the deploying factory still owns it, and `carriesTopUp`, always `true` because the fund takes permissionless top-ups. Its `requiredRole` is always `owner`. `null` when it could not be resolved.</ResponseField>
    <ResponseField name="oracle" type="object">The price oracle: `address`, `readable`, `currentImplementation`, `targetImplementation`, `upgradeAvailable`, `owner`, `pendingOwner`, `ownedByMarket`, `requiredRole` (`owner`), `notice`, and `description` when an upgrade is available. `null` when it could not be resolved.</ResponseField>
  </Expandable>
</ResponseField>

When `inFactory` is `false`, `rateModel`, `router`, `insuranceFund` and `oracle` each carry `upgradeAvailable: false`, `targetImplementation: null` and `reason: "MARKET_NOT_IN_FACTORY"`.

<RequestExample>
```bash cURL
curl "https://api.trusset.org/lending-external-securities-v2/api/markets/{marketId}/upgrade" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/lending-external-securities-v2/api/markets/${marketId}/upgrade`,
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { data } = await res.json();
const pending = [
  data.upgradeAvailable && 'market',
  data.rateModel?.upgradeAvailable && 'rateModel',
  data.router?.upgradeAvailable && 'router',
  data.insuranceFund?.upgradeAvailable && 'insuranceFund',
  data.oracle?.upgradeAvailable && 'oracle'
].filter(Boolean);
if (data.notice?.ready) {
  console.log(`The announced market upgrade to ${data.notice.pendingImplementation} can execute now`);
}
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `NO_MARKET_ADDRESS` | `400` | The market has no on-chain address recorded |
| `MISSING_MARKET_ID` | `400` | `marketId` is longer than 100 characters |
| `MARKET_NOT_FOUND` | `404` | No market with this ID on your instance |
