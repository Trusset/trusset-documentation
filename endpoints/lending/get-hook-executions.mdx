---
title: 'Get Hook Executions'
api: 'GET /lending-external-securities-v2/api/hooks/{marketId}/{hookId}/executions'
description: 'Retrieve the execution log of a hook'
---

Returns the hook's execution log, newest first, with pagination counters. Scheduled runs, chained runs and calls to [Execute Hook](/endpoints/lending/execute-hook) all write to it.

The log is not the same count as the hook's `executionCount`. An unmet trigger, a skipped bid and a short wallet balance add a log entry without counting as a run, and a refusal before anything is evaluated adds neither.

## Path Parameters

<ParamField path="marketId" type="string" required>Market ID.</ParamField>
<ParamField path="hookId" type="string" required>Hook ID.</ParamField>

## Query Parameters

<ParamField query="limit" type="integer" default="50">
  Records to return, 1 to 200. Out-of-range values are clamped rather than refused: above 200 returns 200, a negative value returns 1, and `0` or a non-number falls back to 50.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Records to skip. A negative value or a non-number counts as 0.
</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="executions" type="array">
      Log entries ordered by `executedAt`, newest first.
      <Expandable>
        <ResponseField name="id" type="string">Entry ID.</ResponseField>
        <ResponseField name="hookId" type="string">Hook that ran.</ResponseField>
        <ResponseField name="marketId" type="string">Market the hook belongs to.</ResponseField>
        <ResponseField name="loanId" type="string | null">Loan ID from the data the run was given, or `null`.</ResponseField>
        <ResponseField name="executionType" type="string">The hook type: `monitorRisk`, `beforeLiquidation` or `afterLiquidation`.</ResponseField>
        <ResponseField name="result" type="boolean">Outcome. A `buy` run that returned steps is logged as `false`, because nothing was bought.</ResponseField>
        <ResponseField name="data" type="object | null">What the run saw or did. Shapes are listed below.</ResponseField>
        <ResponseField name="error" type="string | null">Error message when the run failed.</ResponseField>
        <ResponseField name="executedAt" type="string">Time of the run.</ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="total" type="integer">Total log entries for this hook.</ResponseField>
    <ResponseField name="hasMore" type="boolean">Whether more entries exist beyond this page.</ResponseField>
  </Expandable>
</ResponseField>

## What `data` holds

A `monitorRisk` entry holds `{ fields }`, one `{ path, operator, threshold, value, pass }` per field evaluated. It is `null` when the fetch failed, and `error` says why.

A `beforeLiquidation` entry holds `{ loanData, results }`: the data sent and one `{ parameter, value, pass }` per check.

An `afterLiquidation` entry holds one of these, or `null` when the run raised an error:

- `{ action: "inform", status }` after a webhook answered.
- `{ action: "buy", reason: "requires_wallet_signature", auctionId, currentPrice }` after bid steps were returned.
- `{ reason: "Price exceeds max", currentPrice }` when the price was above `maxBuyPrice`.
- `{ reason: "Insufficient USDC" }` when the registered wallet held too little of the borrow asset, named by its symbol.
- `{ reason: "Trigger condition not met" }`, with `triggerId` when a listed hook's last result was not `false`.

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `MISSING_MARKET_ID` | `400` | `marketId` is longer than 100 characters |
| `MISSING_HOOK_ID` | `400` | `hookId` is longer than 100 characters |
| `MARKET_NOT_FOUND` | `404` | No market with this ID belongs to your instance |
| `HOOK_NOT_FOUND` | `404` | No hook with this ID exists on this market |
