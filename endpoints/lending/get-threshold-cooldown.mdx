---
title: 'Get Threshold Cooldown'
api: 'GET /lending-external-securities-v2/api/markets/{marketId}/threshold-cooldown'
description: 'When the liquidation threshold may next move while the market carries debt'
---

Reports whether the market's liquidation threshold may move now and, if not, when it may. While debt is outstanding the market refuses a second threshold move inside 24 hours of the previous one, on top of the 10 percentage point step per update that [Update Market Config](/endpoints/lending/update-config) describes. Read this before building a threshold change.

The clock starts at the last configuration write that changed the threshold. A write that leaves the threshold where it is never counts. A debt-free market is not held to the cooldown, but the move it makes starts the clock all the same, so a threshold set just before the first loan opens cannot move again for a day once that loan exists.

The last move and the debt are both read from the chain: the market stamps the time of every write that changes the threshold, and the cooldown counts from that stamp, exactly as the contract does. The lending index only adds the transaction and the threshold that write set.

## Path Parameters

<ParamField path="marketId" type="string" required>The market's record ID, as `id` on [List Markets](/endpoints/lending/list-markets), not its contract address. See [Market IDs](/endpoints/lending/list-markets#market-ids).</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="supported" type="boolean">`true`: the market enforces the cooldown. `null` when it could not be read.</ResponseField>
    <ResponseField name="cooldownSeconds" type="integer">`86400`.</ResponseField>
    <ResponseField name="debtOutstanding" type="boolean">Whether the market has a borrowed amount or pending liquidation debt. `null` when the chain read failed.</ResponseField>
    <ResponseField name="stampRead" type="boolean">Whether the market's own record of its last threshold move was read. `null` when it could not be read.</ResponseField>
    <ResponseField name="indexed" type="boolean">Whether the lending index answered for the transaction details of the last move. `null` when there is no move to describe. The cooldown never depends on it.</ResponseField>
    <ResponseField name="lastMovedAt" type="integer">Unix seconds of the last configuration write that changed the threshold, as the market recorded it, or `null` when it has recorded none. `lastMovedAtIso` is the same as ISO 8601.</ResponseField>
    <ResponseField name="lastMovedTxHash" type="string">That transaction, or `null` when the index does not have it yet.</ResponseField>
    <ResponseField name="lastThresholdBps" type="integer">The threshold that write set, in basis points, or `null` when the index does not have it yet.</ResponseField>
    <ResponseField name="nextAllowedAt" type="integer">Unix seconds from which the threshold may move again: `lastMovedAt` plus 24 hours. `null` when no move is known. `nextAllowedAtIso` is the same as ISO 8601.</ResponseField>
    <ResponseField name="cooldownRunning" type="boolean">`true` when the market carries debt and `nextAllowedAt` is still ahead.</ResponseField>
    <ResponseField name="canMoveNow" type="boolean">The opposite of `cooldownRunning`. `null` when the stamp, the debt or the chain time could not be read, so the answer is unknown.</ResponseField>
    <ResponseField name="secondsUntilAllowed" type="integer">Seconds until `nextAllowedAt` while the cooldown runs, otherwise `0`.</ResponseField>
    <ResponseField name="note" type="string">The rule in words. `null` when `supported` could not be read.</ResponseField>
  </Expandable>
</ResponseField>

<Warning>
  When `canMoveNow` is `null`, a chain read failed and `cooldownRunning` reads `false`. The contract still refuses a move inside the day, so a configuration write built then can revert `ConfigChangeTooSoon`. Read again before building.
</Warning>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/lending-external-securities-v2/api/markets/{marketId}/threshold-cooldown" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/lending-external-securities-v2/api/markets/${marketId}/threshold-cooldown`,
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { data } = await res.json();
if (!data.canMoveNow) {
  console.log(`The threshold may move again at ${data.nextAllowedAtIso}`);
}
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `NO_MARKET_ADDRESS` | `400` | The market has no on-chain address recorded |
| `CHAIN_UNAVAILABLE` | `503` | The chain could not be read just now. Retry shortly |
| `THRESHOLD_COOLDOWN_READ_FAILED` | `500` | The cooldown could not be read for a reason no other code covers |
| `MISSING_MARKET_ID` | `400` | `marketId` is longer than 100 characters |
| `MARKET_NOT_FOUND` | `404` | No market with this ID on your instance |
