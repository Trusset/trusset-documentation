---
title: 'Get Index Status'
api: 'GET /lending-external-securities-v2/api/markets/{marketId}/index-status'
description: 'Check how far the historical index trails the chain'
---

Reports whether the market has indexed history and how far behind the chain the index currently sits. Use it to decide whether [Get Market History](/endpoints/lending/get-history) is trustworthy before charting it, and to tell "no activity" apart from "not indexed yet". The answer is cached for up to a minute.

Like the history endpoint, an indexing outage returns `200` with `available: false` rather than an error.

## Path Parameters

<ParamField path="marketId" type="string" required>The market's record ID, as `id` on [List Markets](/endpoints/lending/list-markets), not its contract address. See [Market IDs](/endpoints/lending/list-markets#market-ids).</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="marketId" type="string">Market ID.</ResponseField>
    <ResponseField name="available" type="boolean">Whether the index could be reached. When `false`, only `reason` and `message` accompany it.</ResponseField>
    <ResponseField name="indexed" type="boolean">Whether this market has at least one snapshot.</ResponseField>
    <ResponseField name="snapshotCount" type="integer">Snapshots recorded for this market.</ResponseField>
    <ResponseField name="lastSnapshotBlock" type="integer">Block of the most recent snapshot, or `0`.</ResponseField>
    <ResponseField name="lastSnapshotAt" type="string">ISO 8601 timestamp of the most recent snapshot, or null.</ResponseField>
    <ResponseField name="indexedBlock" type="integer">Latest block the indexer has processed, or null.</ResponseField>
    <ResponseField name="indexedAt" type="string">ISO 8601 timestamp of that block, or null.</ResponseField>
    <ResponseField name="hasIndexingErrors" type="boolean">Whether the indexer reports errors on this deployment.</ResponseField>
    <ResponseField name="lagSeconds" type="integer">How many seconds the indexed block trailed the clock when the status was read, which can be up to a minute before this response. `null` when the index reported no block time.</ResponseField>
    <ResponseField name="stale" type="boolean">`true` when `lagSeconds` exceeds `staleThresholdSeconds`. `null` when the lag is unknown.</ResponseField>
    <ResponseField name="staleThresholdSeconds" type="integer">The lag beyond which the index counts as stale: `300`. [Get Lifecycle Statement](/endpoints/lending/get-lifecycle-statement) refuses to generate past it unless told otherwise.</ResponseField>
    <ResponseField name="reason" type="string">Present when `available` is false. One of `NOT_CONFIGURED`, `NO_MARKET_ADDRESS`, `INDEX_NOT_DEPLOYED`, `UPSTREAM_ERROR`, `QUERY_ERROR`, `EMPTY_RESPONSE`, `TIMEOUT`, `NETWORK_ERROR`.</ResponseField>
    <ResponseField name="message" type="string">Human-readable explanation accompanying `reason`.</ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/lending-external-securities-v2/api/markets/{marketId}/index-status" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/lending-external-securities-v2/api/markets/${marketId}/index-status`,
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { data } = await res.json();
const trustworthy = data.available && data.indexed && data.stale === false && !data.hasIndexingErrors;
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `MISSING_MARKET_ID` | `400` | `marketId` is longer than 100 characters |
| `MARKET_NOT_FOUND` | `404` | No market with this ID on your instance |
