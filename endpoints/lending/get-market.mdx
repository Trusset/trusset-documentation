---
title: 'Get Market'
api: 'GET /lending-external-securities-v2/api/markets/{marketId}'
description: 'Retrieve full detail for a single market'
---

Returns the complete market record plus five enrichment blocks read live from the chain: `onChain`, `oracleStatus`, `configurationStatus`, `identityGate`, and `liquidationStats`. The lender-of-record fields are reconciled against the factory on the same call, so `curator`, `seekingCurator`, `realizationMode`, `liquidityCommitment` and `collateralAgent` are the chain's answer when the factory can be read. A failed factory read serves the stored values, and `errors` does not name it. `saleRecipient` is read from the market's liquidation router, which holds the recipient in force.

[List Markets](/endpoints/lending/list-markets) returns a fixed projection. This endpoint returns every stored field on the market, including the settlement asset triple and the decimals the backend uses when parsing your amounts.

<Warning>
  Each block falls back on its own. One failed read leaves that block `null` or marked unreadable and does not empty the others.

  `errors` names every section that could not be read, as `{ section, message }`, where `section` is `onChain`, `configurationStatus`, `liquidationStats` or `oracle`. It is empty on a clean read. Branch on it rather than inferring an outage from a `null`, because some blocks are legitimately `null` on a market that has no address or no oracle yet.
</Warning>

## Path Parameters

<ParamField path="marketId" type="string" required>Market ID.</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="collateralDecimals" type="integer">Decimals of the collateral token. Every collateral amount you send is parsed at this precision, and every collateral amount returned is formatted with it.</ResponseField>
    <ResponseField name="borrowAssetAddress" type="string">Settlement token (stablecoin) address.</ResponseField>
    <ResponseField name="borrowAssetSymbol" type="string">Its symbol, for example `USDC`.</ResponseField>
    <ResponseField name="borrowAssetDecimals" type="integer">Its decimals. Every borrow, repay, and liquidity amount is parsed at this precision.</ResponseField>
    <ResponseField name="interestModelAddress" type="string">The market's interest rate model contract.</ResponseField>
    <ResponseField name="identityRegistryAddress" type="string">The borrower identity register recorded for the market, lowercased. The zero address or `null` means the market has no borrower register. `identityGate` below is read from the contract itself.</ResponseField>
    <ResponseField name="liquidationBonus" type="string">The market's liquidation penalty in basis points, as last recorded.</ResponseField>
    <ResponseField name="operatorShare" type="string">The lender of record's share of repaid interest after the infrastructure fee, in basis points. When the factory's figure differs from the stored one, the factory's is served. On current markets it is `800`.</ResponseField>
    <ResponseField name="signerAuthorized" type="boolean">Recorded oracle signer authorization for the instance's wallet, healed from the chain whenever the oracle is read. `oracleStatus.signerAuthorized` is the live value.</ResponseField>
    <ResponseField name="lastOracleUpdate" type="string">ISO 8601 timestamp of the latest price update the record knows of, moved forward from the oracle whenever it is read.</ResponseField>
    <ResponseField name="controllerImported" type="boolean">True when this market was deployed under another instance and imported here by proving on-chain admin control.</ResponseField>
    <ResponseField name="onChain" type="object">Live market metrics, or `null` for a market without an address. See [Get Market Metrics](/endpoints/lending/get-metrics).</ResponseField>
    <ResponseField name="oracleStatus" type="object">Live oracle state, or `null` when the market has no oracle. A failed read carries `configured: false` and an `error` message. See [Get Oracle Status](/endpoints/lending/get-oracle-status).</ResponseField>
    <ResponseField name="configurationStatus" type="object">
      The readiness verdict, or `null` for a market without an address.
      <Expandable>
        <ResponseField name="liquidationContract" type="string">Liquidation router the market is wired to.</ResponseField>
        <ResponseField name="insuranceFund" type="string">Insurance fund the market is wired to.</ResponseField>
        <ResponseField name="adapter" type="string">Collateral adapter the market is wired to.</ResponseField>
        <ResponseField name="liquidationConfigured" type="boolean">A router address is set on the market.</ResponseField>
        <ResponseField name="insuranceFundConfigured" type="boolean">An insurance fund address is set on the market.</ResponseField>
        <ResponseField name="adapterConfigured" type="boolean">An adapter address is set on the market.</ResponseField>
        <ResponseField name="routerAuthorized" type="boolean">The router accepts liquidations from this market.</ResponseField>
        <ResponseField name="routerHolderAuthorized" type="boolean">The router is an eligible holder of the collateral token.</ResponseField>
        <ResponseField name="oracleSignerAuthorized" type="boolean">The instance's wallet may sign prices on the market's oracle.</ResponseField>
        <ResponseField name="liquidatorRoleGranted" type="boolean">The instance's wallet holds `LIQUIDATOR_ROLE` on the market.</ResponseField>
        <ResponseField name="pendingCurator" type="boolean">The market has no lender of record yet.</ResponseField>
        <ResponseField name="fullyConfigured" type="boolean">The same verdict [Get Configuration Status](/endpoints/lending/get-configuration-status) gives, including the adapter's authorization on the collateral token.</ResponseField>
        <ResponseField name="readFailed" type="boolean">Present and `true` when a wiring read failed. The figures beside it are then not a statement about the market.</ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="liquidationStats" type="object">`totalLiquidations`, `pendingLiquidationDebt` and `totalAuctions`, plus `readFailed: true` when a counter could not be read.</ResponseField>
    <ResponseField name="identityGate" type="object">
      What the market's borrower register answers, and what that means for the market. `null` when the register could not be reached.
      <Expandable>
        <ResponseField name="shape" type="string">`none` when no register is installed, `tuple` when it answers `isVerified(address)` with `(bool, uint8)`, `bool` when it answers with a single boolean, `unknown` when it does not answer `isVerified(address)` at all.</ResponseField>
        <ResponseField name="usable" type="boolean">`true` in every current case. The `note` says what, if anything, stands in the way.</ResponseField>
        <ResponseField name="note" type="string">What the answer means and who can act on it. `null` when there is nothing to do.</ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="errors" type="array">Sections that could not be read, each `{ section, message }`. Empty on a clean read.</ResponseField>
  </Expandable>
</ResponseField>

<Warning>
  A register that answers with a bare `bool` works on the current market implementation, which reads either shape. A market still on the earlier implementation reads `(bool, uint8)` only. There every deposit and every borrow reverts until the market admin moves it on with [Upgrade Market](/endpoints/lending/upgrade-market). A register that answers neither shape refuses every borrower until the admin replaces it through [Set Identity Gates](/endpoints/lending/set-identity-gates). Taking the lender-of-record role is not blocked in either case. `note` says which applies: show it verbatim.
</Warning>

<Note>
  `configurationStatus` here is a verdict without the calldata to act on it, and it is cached for up to 10 seconds. [Get Configuration Status](/endpoints/lending/get-configuration-status) returns the outstanding transactions and who must sign each. [Get Setup Steps](/endpoints/lending/get-setup-steps) returns them as an ordered checklist.
</Note>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/lending-external-securities-v2/api/markets/{marketId}" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/lending-external-securities-v2/api/markets/${marketId}`,
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { data } = await res.json();
if (data.errors.length > 0) console.warn('Partial read', data.errors);
console.log(`${data.borrowAssetSymbol} market, ${data.collateralDecimals} collateral decimals`);
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `MISSING_MARKET_ID` | `400` | `marketId` is longer than 100 characters |
| `MARKET_NOT_FOUND` | `404` | No market with this ID on your instance |
