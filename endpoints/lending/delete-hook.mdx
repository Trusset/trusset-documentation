---
title: 'Delete Hook'
api: 'DELETE /lending-external-securities-v2/api/hooks/{marketId}/{hookId}'
description: 'Delete a hook and its execution history'
---

Permanently removes the hook, every execution record written against it, and its deliveries, including any not yet sent, which are then never sent. This cannot be undone. To stop a hook without losing its history, use [Toggle Hook](/endpoints/lending/toggle-hook) instead.

<Warning>
  Other hooks that list the deleted hook in `triggerHookIds` keep its ID. An `afterLiquidation` hook with a deleted trigger never acts again, because its trigger check finds fewer hooks than it lists and records `Trigger condition not met`. Remove the ID from those hooks with [Update Hook](/endpoints/lending/update-hook).
</Warning>

## Path Parameters

<ParamField path="marketId" type="string" required>The market's record ID, as `id` on [List Markets](/endpoints/lending/list-markets), not its contract address. See [Market IDs](/endpoints/lending/list-markets#market-ids).</ParamField>
<ParamField path="hookId" type="string" required>Hook ID.</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="deleted" type="boolean">Always `true`.</ResponseField>
  </Expandable>
</ResponseField>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `MISSING_MARKET_ID` | `400` | `marketId` is longer than 100 characters |
| `MISSING_HOOK_ID` | `400` | `hookId` is longer than 100 characters |
| `MARKET_NOT_FOUND` | `404` | No market with this ID belongs to your instance |
| `HOOK_NOT_FOUND` | `404` | No hook with this ID exists on this market |
