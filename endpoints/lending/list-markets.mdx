---
title: 'List Markets'
api: 'GET /lending-external-securities-v2/api/markets'
description: 'List the active lending markets recorded on your instance'
---

Returns every active market recorded on the instance bound to your API key: the markets it deployed and the markets it took the lender-of-record role on. Archived and inactive markets are excluded.

The stored record is served by default and `onChain` is `null`. Live per-market state is opt-in through `includeOnChain`, because enriching a list runs a position sync per market and turns a list read into an unbounded chain scan. For live state on a single market, prefer [Get Market](/endpoints/lending/get-market) or [Get Market Metrics](/endpoints/lending/get-metrics).

Enrichment is best effort. When the chain cannot be read for a market, its `onChain` block carries `isOnChain: false` and zeroed figures, plus `readFailed: true` for a market that has a deployed contract. The stored fields are served regardless, so check `onChain.isOnChain` before reading from it.

## Query Parameters

<ParamField query="includeOnChain" type="boolean" default="false">
  Set to `true` to read live contract state for every market in the list. Any other value leaves `onChain` as `null`.
</ParamField>

        <ResponseField name="utilizationRate" type="string">Last recorded utilization in basis points.</ResponseField>
        <ResponseField name="borrowRate" type="string">Last recorded borrow rate in basis points. On a `FIXED` market it is the rate stamped onto new loans, not the model's curve.</ResponseField>
        <ResponseField name="supplyRate" type="string">Last recorded supply rate in basis points. It can carry up to four decimal places.</ResponseField>
        <ResponseField name="active" type="boolean">Always true in this response.</ResponseField>
        <ResponseField name="createdAt" type="string">ISO 8601 timestamp.</ResponseField>
        <ResponseField name="isOnChain" type="boolean">Whether the market has a deployed address recorded.</ResponseField>
        <ResponseField name="onChain" type="object">Live contract metrics. `null` unless `includeOnChain=true`. See [Get Market Metrics](/endpoints/lending/get-metrics) for the full field list.</ResponseField>

### Lender of record

<ResponseField name="data.markets" type="array">
  <Expandable>
    <ResponseField name="curator" type="string">The institution holding the lender-of-record role, or `null` while the market is still seeking one.</ResponseField>
    <ResponseField name="seekingCurator" type="boolean">`true` while no institution has taken the role. Opening a loan, borrowing more and providing liquidity are refused with `MARKET_PENDING_CURATOR` while this holds.</ResponseField>
    <ResponseField name="curatorImported" type="boolean">Whether this row exists because the instance took the role on another platform's market, rather than because it deployed the market itself.</ResponseField>
    <ResponseField name="realizationMode" type="string">How the lender of record declared it will realize seized collateral: `EXCHANGE_SALE`, `ISSUER_REDEMPTION` or `AUCTION`. `UNDECLARED` while the market is seeking a lender of record.</ResponseField>
    <ResponseField name="liquidityCommitment" type="string">Liquidity the lender of record committed when it took the role, as an integer string in the borrow asset's base units. A commitment of 1,000,000 USDC reads `"1000000000000"`.</ResponseField>
  </Expandable>
</ResponseField>

### Rate and term offering

Set at deployment. The rate mode, fixed-rate ceiling, term configuration, extension switch and reserve ratio can each change afterwards through their own endpoints. These columns are healed from the chain whenever the market is read in detail or an offering change is confirmed, so a list read can trail the chain. Rate values are basis-point strings, durations are strings of seconds.

<ResponseField name="data.markets" type="array">
  <Expandable>
    <ResponseField name="rateMode" type="string">`CURVE`, `CLAMPED` or `FIXED`.</ResponseField>
    <ResponseField name="rateFloor" type="string">Floor the model holds to. `"0"` on `CURVE`. On `FIXED` it equals the fixed rate.</ResponseField>
    <ResponseField name="rateCap" type="string">Cap the model holds to. `"0"` on `CURVE`. On `FIXED` it equals the fixed rate.</ResponseField>
    <ResponseField name="maxFixedRate" type="string">Ceiling on any fixed rate the rate model owner can set, or `null` when none is recorded. It can only move down.</ResponseField>
    <ResponseField name="operatorShare" type="string">The lender of record's share of repaid interest after the Trusset infrastructure fee, in basis points. On current markets it is the factory's fixed `800`, and a fixed 5 percent distributor share is taken beside it. [Get Fee Split](/endpoints/lending/get-fee-split) reads the whole split from the contracts.</ResponseField>
    <ResponseField name="reserveRatio" type="string">Share of the pool held back from borrowing, in basis points.</ResponseField>
    <ResponseField name="maxLoanDuration" type="string">Seconds a loan may run before it falls due. `"0"` means no rolling term, and the market makes open-ended loans unless `terminalDueDate` is set.</ResponseField>
    <ResponseField name="termGracePeriod" type="string">Seconds after the due date before an unpaid loan can be liquidated on its term.</ResponseField>
    <ResponseField name="terminalDueDate" type="string">Unix seconds every loan falls due by, whatever its own duration, or `null`.</ResponseField>
    <ResponseField name="termPenalty" type="string">Penalty charged when an overdue loan is liquidated on its term, in basis points.</ResponseField>
    <ResponseField name="marketDueFloor" type="string">Market-wide extension floor in unix seconds: no termed loan falls due before it. Raised through a `FLOOR` extension, `null` when never set.</ResponseField>
    <ResponseField name="allowExtension" type="boolean">Whether a borrower may be granted more time on a termed loan.</ResponseField>
  </Expandable>
</ResponseField>

### Oracle staleness

Read once per oracle across the whole list and attached to every market, so the list is safe to poll.

<ResponseField name="data.markets" type="array">
  <Expandable>
    <ResponseField name="isStale" type="boolean">Whether the stored price is older than the oracle's `maxPriceAge`. `null` when the oracle could not be read, which is not the same as fresh.</ResponseField>
    <ResponseField name="priceAge" type="integer">Seconds since the last price update, or `null`.</ResponseField>
    <ResponseField name="maxPriceAge" type="integer">The oracle's staleness bound in seconds, or `null`.</ResponseField>
    <ResponseField name="oracleLastUpdate" type="string">ISO 8601 timestamp of the last price update, or `null`.</ResponseField>
  </Expandable>
</ResponseField>

<Note>
  The stored totals are refreshed when loan and liquidity transactions are confirmed through this API, and when the market is synchronized from the chain. Treat the `onChain` block as authoritative for live figures.
</Note>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/lending-external-securities-v2/api/markets?includeOnChain=true" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(
  'https://api.trusset.org/lending-external-securities-v2/api/markets?includeOnChain=true',
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { data } = await res.json();

for (const m of data.markets) {
  const live = m.onChain?.isOnChain ? m.onChain : null;
  console.log(m.collateralTokenSymbol, m.collateralMode, live?.borrowableLiquidity ?? 'unavailable');
}
```
</RequestExample>
