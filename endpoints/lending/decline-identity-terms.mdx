---
title: 'Decline Identity Terms'
api: 'POST /public/identity-terms/sign/{token}/decline'
authMethod: 'none'
description: 'Record that a member will not sign a version of identity terms, with a reason'
---

Records that the member a signing link is for will not sign this version of the [identity terms](/endpoints/lending/identity-terms). The author sees the reason beside the member on [Get Identity Terms](/endpoints/lending/get-identity-terms) and can correct the terms, publish a new version and send a new link.

A decline uses up the link. It needs no wallet signature, so keep the link to the people who answer for the member. A member that already signed cannot decline afterwards: ask the author to publish a new version instead.

This route is public. It takes no API key, answers with `Cache-Control: no-store`, and allows 6 writes per minute from one address.

## Path Parameters

<ParamField path="token" type="string" required>
  The token of the link.
</ParamField>

## Body Parameters

<ParamField body="reason" type="string" required>
  Why the member declines: `NOT_OUR_ROLE`, `WRONG_DATA` or `NOT_AGREED`. No other field is accepted.
</ParamField>

| `reason` | Meaning |
|---|---|
| `NOT_OUR_ROLE` | The terms give the organisation a role it does not hold |
| `WRONG_DATA` | A fact in the terms is wrong, such as the organisation's name, LEI or wallet |
| `NOT_AGREED` | The organisation does not agree to the terms as written |

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="declined" type="boolean">`true`.</ResponseField>
    <ResponseField name="member" type="integer">The member's index.</ResponseField>
    <ResponseField name="version" type="integer">The version declined.</ResponseField>
    <ResponseField name="reason" type="string">The reason recorded.</ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.trusset.org/public/identity-terms/sign/3f9c1a7e5b2d4f6a8c0e1b3d5f7a9c2e4b6d8f0a1c3e5b7d9f2a4c6e8b0d1f3a/decline" \
  -H "Content-Type: application/json" \
  -d '{ "reason": "WRONG_DATA" }'
```
```typescript TypeScript
const res = await fetch(`https://api.trusset.org/public/identity-terms/sign/${token}/decline`, {

const { success, data, error } = await res.json();
```

## Error Codes

A refusal on the public routes carries `error.code`, `error.message` and, where there is one, `error.remedy` and `error.field`.

| Code | HTTP | Cause |
|---|---|---|
| `IDENTITY_TERMS_INVITE_INVALID` | `400` | The token is not 64 lower-case hex characters. Open the link exactly as you received it |
| `IDENTITY_TERMS_DECLINE_REASON` | `400` | The body is not `{ reason }` with `NOT_OUR_ROLE`, `WRONG_DATA` or `NOT_AGREED` |
| `IDENTITY_TERMS_INVITE_NOT_FOUND` | `404` | No link with this token exists. Ask the author for a new one |
| `IDENTITY_TERMS_ALREADY_SIGNED` | `409` | The member already signed this version. A signature cannot be declined afterwards |
| `IDENTITY_TERMS_INVITE_EXPIRED` | `410` | The link is older than 14 days. Ask the author for a new one |
| `IDENTITY_TERMS_INVITE_REVOKED` | `410` | The link was revoked, the terms were withdrawn, or a newer version was published |
| `IDENTITY_TERMS_INVITE_USED` | `410` | The link was already used. Ask the author for a new one if you still need to answer |
| `RATE_LIMIT_EXCEEDED` | `429` | More than 6 writes in a minute from one address. Wait a minute |
| `IDENTITY_TERMS_SIGNING_FAILED` | `500` | The request could not be completed. Retry in a moment |
