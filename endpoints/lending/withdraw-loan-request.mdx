---
title: 'Withdraw Loan Request'
api: 'POST /lending-external-securities-v2/api/markets/{marketId}/loan-requests/{ref}/withdraw'
description: 'Withdraw your own loan request while it still waits'
---

Withdraws a request that is still `REQUESTED`. Nothing is signed.

## Who can call

The borrower side.

## Path Parameters

<ParamField path="marketId" type="string" required>
  The market's record ID on your instance.
</ParamField>

<ParamField path="ref" type="string" required>
  The loan request reference: `lrq_` followed by 20 characters.
</ParamField>

## Body Parameters

None. Send an empty object.

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="request" type="object">The loan request. See [Get Loan Request](/endpoints/lending/get-loan-request#response-fields) for every field.</ResponseField>
    <ResponseField name="marketId" type="string">The market's record ID on your instance.</ResponseField>
  </Expandable>
</ResponseField>
