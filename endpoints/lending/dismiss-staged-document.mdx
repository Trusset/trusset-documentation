---
title: 'Dismiss Staged Document'
api: 'POST /lending-external-securities-v2/api/markets/{marketId}/legal-documents/staged/{stageId}/dismiss'
description: 'Close a staged loan document without recording it'
---

Marks a staged loan document `DISMISSED`. Nothing reaches the chain and the loan is untouched. The instance that staged the document may dismiss it, and so may an instance whose verified wallet administers the market. The dismissal is audited.

## Path Parameters

<ParamField path="marketId" type="string" required>
  The market's record ID on your instance.
</ParamField>

<ParamField path="stageId" type="string" required>
  The `id` of the staged document.
</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="stage" type="object">The staged document with `status: DISMISSED`.</ResponseField>
  </Expandable>
</ResponseField>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `STAGE_NOT_FOUND` | `404` | No staged document with that id for this market that your instance may see |
| `STAGE_NOT_PENDING` | `409` | The document is already recorded or dismissed |
| `MARKET_NOT_FOUND` | `404` | No market with this ID on your instance |
| `CHAIN_UNAVAILABLE`, `SERVICE_UNAVAILABLE` | `503` | The market admin role or this instance's wallets could not be read. Nothing changed. Retry shortly |
