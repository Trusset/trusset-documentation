---
title: 'List Terms Templates'
api: 'GET /lending-external-securities-v2/api/markets/terms-library'
description: "List the templates of this instance's terms library"
---

Returns the templates of this instance's terms library. A template is a terms of use document kept once and bound to many markets: [Save Terms](/endpoints/lending/save-terms) with `templateId` publishes its text on one market, and a [standing policy](/endpoints/operators/list-standing-policies) publishes it on every market adopted under the policy. Only the instance that authored a template can bind it.

Templates are versioned. A change to the title or the text writes a new version, and a market bound to the template keeps the version it published until it is bound again. `usage` counts the markets on each version state.

Any key of the instance can read the library. Creating, editing and archiving templates needs an account Trusset approved as a lender of record, which `canAuthor` reports. This is a database read: nothing is read from the chain.

## Query Parameters

<ParamField query="includeArchived" type="string" default="false">
  `true` or `1` to include archived templates. Any other value leaves them out.
</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="templates" type="array">
      Templates that are not archived first, then archived ones, each group by last change, newest first. The text itself is not included: read it with [Get Terms Template](/endpoints/lending/get-terms-template).
      <Expandable>
        <ResponseField name="id" type="string">Template ID. Save Terms takes it as `templateId`, and a standing policy as `termsTemplateId`.</ResponseField>
        <ResponseField name="instanceId" type="string">The instance that authored the template.</ResponseField>
        <ResponseField name="title" type="string">Template title.</ResponseField>
        <ResponseField name="version" type="integer">Current version. `1` for a new template, raised by every change to the title or the text.</ResponseField>
        <ResponseField name="contentHash" type="string">keccak256 over the UTF-8 bytes of the current text.</ResponseField>
        <ResponseField name="archived" type="boolean">`true` once archived. An archived template cannot be bound to a market or a standing policy.</ResponseField>
        <ResponseField name="archivedAt" type="string">ISO 8601 time of archiving, or `null`.</ResponseField>
        <ResponseField name="createdBy" type="string">The issuer account that created the template, or `null`.</ResponseField>
        <ResponseField name="updatedBy" type="string">The issuer account that last changed it, or `null`.</ResponseField>
        <ResponseField name="createdAt" type="string">ISO 8601.</ResponseField>
        <ResponseField name="updatedAt" type="string">ISO 8601.</ResponseField>
        <ResponseField name="contentBytes" type="integer">Size of the current text in bytes of UTF-8.</ResponseField>
        <ResponseField name="usage" type="object">
          The markets whose terms are bound to the template.
          <Expandable>
            <ResponseField name="markets" type="integer">Every market bound to the template, in any state.</ResponseField>
            <ResponseField name="current" type="integer">Markets serving the template's current version as published.</ResponseField>
            <ResponseField name="outdated" type="integer">Markets serving an older version, not customised.</ResponseField>
            <ResponseField name="customised" type="integer">Markets whose text was edited after binding.</ResponseField>
            <ResponseField name="unpublished" type="integer">Markets whose bound terms are a draft or offline.</ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="canAuthor" type="boolean">Whether this account may create, edit and archive templates: `true` only for an account Trusset approved as a lender of record.</ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/lending-external-securities-v2/api/markets/terms-library?includeArchived=true" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(
  'https://api.trusset.org/lending-external-securities-v2/api/markets/terms-library?includeArchived=true',
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { data } = await res.json();
const live = data.templates.filter((template) => !template.archived);
```
</RequestExample>
