---
title: 'Revoke Invite'
api: 'DELETE /lending-external-securities-v2/api/identity-terms/{id}/invites/{inviteId}'
description: 'Revoke an open signing link of identity terms'
---

Revokes a signing link created with [Create Invite](/endpoints/lending/create-identity-terms-invite), for example when it reached the wrong person. The link then answers `410 IDENTITY_TERMS_INVITE_REVOKED`. Create a new one for the member when you are ready.

Revoking an open link sets it to `REVOKED` and records the revocation in the audit log. A link that was used cannot be revoked: the member's signature or decline stands (`409 IDENTITY_TERMS_INVITE_USED`). Revoking a link that has already expired changes nothing: its state does not change, no audit entry is written, and it stays `EXPIRED`. Revoking a link that is already revoked changes nothing either.

## Path Parameters

<ParamField path="id" type="string" required>
  The terms id.
</ParamField>

<ParamField path="inviteId" type="string" required>
  The invite id, as `invites[].id` on [Get Identity Terms](/endpoints/lending/get-identity-terms) lists it.
</ParamField>

## Response Fields

The document, as [Get Identity Terms](/endpoints/lending/get-identity-terms#response-fields) returns it. A link that was open reads `state: REVOKED`, and the member no longer reads `INVITED`. A link that had expired still reads `EXPIRED`.

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `VALIDATION_ERROR` | `400` | `id` or `inviteId` is not 20 to 40 lower-case letters and digits |
| `IDENTITY_TERMS_NOT_FOUND` | `404` | No terms with this id exist in your instance |
| `IDENTITY_TERMS_INVITE_NOT_FOUND` | `404` | No invite with this id exists for these terms |
| `IDENTITY_TERMS_INVITE_USED` | `409` | The member already answered through this link. Read the terms for the answer |
| `RATE_LIMIT_EXCEEDED` | `429` | More than 10 writes in a minute. Retry after the interval in `Retry-After` |
| `IDENTITY_TERMS_INVITE_REVOKE_FAILED` | `500` | The link could not be revoked for a reason that carries no code of its own. Retry, or contact support with the request ID |
