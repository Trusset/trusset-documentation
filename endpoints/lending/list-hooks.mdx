---
title: 'List Hooks'
api: 'GET /lending-external-securities-v2/api/hooks/{marketId}'
description: 'List every hook configured on a lending market'
---

Returns every hook on the market, newest first. A hook is a rule Trusset stores and evaluates off-chain. It never signs or broadcasts a transaction.

Only `monitorRisk` hooks run on a schedule. Liquidating a loan of the market runs its active `beforeLiquidation` and `afterLiquidation` hooks, and no hook result blocks a liquidation. An `afterLiquidation` hook also runs when a monitor it lists in `triggerHookIds` evaluates to `false`, and every type runs when [Execute Hook](/endpoints/lending/execute-hook) is called. See [When each hook type runs](/endpoints/lending/create-hook#when-each-hook-type-runs).

## Path Parameters

<ParamField path="marketId" type="string" required>The market's record ID, as `id` on [List Markets](/endpoints/lending/list-markets), not its contract address. See [Market IDs](/endpoints/lending/list-markets#market-ids).</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="hooks" type="array">
      Hook records ordered by `createdAt`, newest first.
      <Expandable>
        <ResponseField name="id" type="string">Hook ID.</ResponseField>
        <ResponseField name="marketId" type="string">Market the hook belongs to.</ResponseField>
        <ResponseField name="hookType" type="string">`monitorRisk`, `beforeLiquidation` or `afterLiquidation`.</ResponseField>
        <ResponseField name="name" type="string">Display name.</ResponseField>
        <ResponseField name="active" type="boolean">Whether the scheduler, liquidations and chained triggers use the hook. [Execute Hook](/endpoints/lending/execute-hook) runs it either way.</ResponseField>
        <ResponseField name="riskUri" type="string | null">URL a monitor polls.</ResponseField>
        <ResponseField name="riskFields" type="array">Field checks applied to the `riskUri` response. Each has `path`, and optionally `operator` and `threshold`.</ResponseField>
        <ResponseField name="riskThreshold" type="number | null">Stored as sent. No evaluation reads it.</ResponseField>
        <ResponseField name="checkFrequency" type="string | null">A monitor's schedule, or `null` when it runs only on demand.</ResponseField>
        <ResponseField name="parameterChecks" type="array">Checks a `beforeLiquidation` hook applies to the loan data it is given. Each has `parameter`, `operator` and `threshold`.</ResponseField>
        <ResponseField name="triggerHookIds" type="string[]">Hooks whose last result must be `false` before this `afterLiquidation` hook acts.</ResponseField>
        <ResponseField name="actionType" type="string | null">`buy` or `inform` on an `afterLiquidation` hook.</ResponseField>
        <ResponseField name="maxBuyPrice" type="string | null">Price ceiling for a `buy` action.</ResponseField>
        <ResponseField name="webhookUrl" type="string | null">Destination of an `inform` action.</ResponseField>
        <ResponseField name="webhookPayload" type="object | null">Extra fields merged into the `inform` body.</ResponseField>
        <ResponseField name="signed" type="boolean">`true` when the hook holds a signing secret, so its deliveries carry `x-webhook-signature`. The secret itself is never listed. See [Signed deliveries](/endpoints/lending/create-hook#signed-deliveries), and [Rotate Hook Secret](/endpoints/lending/rotate-hook-secret) to issue one.</ResponseField>
        <ResponseField name="signerAddress" type="string | null">The instance's registered wallet when the hook was created, or `null` when none was registered. Informational: no run reads it.</ResponseField>
        <ResponseField name="signerFunded" type="boolean">Nothing on this surface sets it, so it reads `false`.</ResponseField>
        <ResponseField name="lastExecutedAt" type="string | null">Time of the last counted run, as defined under `executionCount`.</ResponseField>
        <ResponseField name="lastResult" type="boolean | null">Outcome of the last counted run. `null` before the first run, and after a monitor run that could not fetch or parse its `riskUri`. A `buy` run that returned steps records `false`.</ResponseField>
        <ResponseField name="executionCount" type="integer">Counted runs: an evaluated monitor or check, returned `buy` steps, or an `inform` delivery once it is delivered or has failed for good. A monitor that could not fetch its `riskUri` also counts. Refusals, unmet triggers and skipped bids do not.</ResponseField>
        <ResponseField name="createdAt" type="string">Creation time.</ResponseField>
        <ResponseField name="updatedAt" type="string">Last change to the record, including a run.</ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/lending-external-securities-v2/api/hooks/{marketId}" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/lending-external-securities-v2/api/hooks/${marketId}`,
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { data } = await res.json();
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `MISSING_MARKET_ID` | `400` | `marketId` is longer than 100 characters |
| `MARKET_NOT_FOUND` | `404` | No market with this ID belongs to your instance |
