---
title: 'Get Permit Quote'
api: 'POST /lending-external-securities-v2/api/positions/{marketId}/permit-quote'
description: 'The EIP-2612 permit a payer signs to repay a loan in one transaction'
---

Returns the EIP-2612 permit a payer signs to repay a loan through [Repay Loan](/endpoints/lending/repay) as one signature and one transaction. A wallet cannot read the figures the permit has to carry, so the quote supplies all of them. That is the value, the token's current nonce for the payer, a bounded deadline and the token's EIP-712 domain. The permit names the market as spender.

The quote exists only where the settlement asset provably implements EIP-2612. Any wallet without contract code can be the payer: the borrower, or a third party repaying for it. The payer signs the permit and also sends the repayment, because the market redeems the permit for the sender. The collateral still returns to the borrower. A multisig or smart account repays through the approval steps on [Repay Loan](/endpoints/lending/repay). Signing the permit moves nothing by itself: the repayment transaction redeems it.

## Path Parameters

<ParamField path="marketId" type="string" required>The market's record ID, as `id` on [List Markets](/endpoints/lending/list-markets), not its contract address. See [Market IDs](/endpoints/lending/list-markets#market-ids).</ParamField>

## Body Parameters

<ParamField body="loanId" type="integer" required>
  On-chain loan ID. A positive integer. Accepted as a JSON number or as a numeric string.
</ParamField>

<ParamField body="payer" type="string" required>
  The wallet that signs the permit and sends the repayment, `0x` and 40 hex characters. Its nonce is read for the permit. A call without it is refused with `PAYER_REQUIRED`, and a contract account with `PERMIT_REQUIRES_EOA`.
</ParamField>

<ParamField body="amount" type="string">
  Amount to repay, as a positive decimal string in borrow asset units. The permit is quoted over exactly this amount. Required unless `all` is `true`.
</ParamField>

<ParamField body="all" type="boolean">
  Quote a full repayment. The value is the live debt plus the interest it can accrue over one hour, plus the repayment fee, plus one base unit. The interest uses the loan's stamped fixed rate, or on a variable-rate loan the curve rate at full utilization. `forecast` carries the parts.
</ParamField>

<ParamField body="deadlineSeconds" type="integer">
  How long the permit stays valid, in seconds from the current block time. An integer from `300` to `1800`. Defaults to `1800`.
</ParamField>

## Sign and repay

<Steps>
  <Step title="Quote">
    Request the quote with the loan, the `payer`, and either `amount` or `all: true`.
  </Step>
  <Step title="Sign">
    Sign `typedData` from the wallet named in `payer` and split the signature into `v`, `r` and `s`.
  </Step>
  <Step title="Build the repayment">
    Call [Repay Loan](/endpoints/lending/repay) with the fields in `repay`, which already carry `mode: "permit"` and `payer`, plus a `permit` holding `permit.value`, `permit.deadline`, `v`, `r` and `s`.
  </Step>
  <Step title="Broadcast and confirm">
    Send the returned steps from the payer's wallet, then confirm with the hash of the step at `confirmStepIndex`. The optional last step clears the leftover allowance after a full repayment.
  </Step>
</Steps>

A partial quote is exact: the repayment must carry the same amount. A full-repayment quote covers the debt at quote time plus an hour of interest, while the permit lives at most 30 minutes, so a value signed unchanged covers the debt until its deadline. If the live debt plus the fee has outgrown the value by the time Repay Loan is called, it refuses with `INVALID_PERMIT`. If the value covers the debt now but not the interest until the deadline, the repayment builds with a `warning`.

Repay Loan accepts the permit only while its deadline lies between 2 and 31 minutes after the current block time. A permit that lapsed while the payer reviewed it is refused with `INVALID_PERMIT`: request a new quote and sign it. The repay call also checks the signature against the payer's current nonce. If another permit from the payer is redeemed on the token in between, the nonce moves and the repay call refuses this signature with `INVALID_PERMIT`. Request a fresh quote.

## Domain resolution

A token does not expose its EIP-712 domain as a readable struct, so the API rebuilds it from `name()` and `version()`. It tries the token's own `version()` first, then `1` and `2`, and accepts a candidate only when it reproduces the token's `DOMAIN_SEPARATOR`. A token without a `version()` getter is resolved the same way. The wallet therefore signs a digest the token will recover.

When no candidate matches, the call returns `PERMIT_DOMAIN_UNRESOLVED`. Sign with tooling that knows the token's domain, or use the approval steps.

<RequestExample>
```bash cURL
curl -X POST "https://api.trusset.org/lending-external-securities-v2/api/positions/{marketId}/permit-quote" \
  -H "X-API-Key: trusset_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{"loanId": 5, "all": true, "payer": "0xabc7f1093d5e26b804a1c3f78de025916b47c0d3"}'
```
```typescript TypeScript
import { ethers } from 'ethers';

const base = `https://api.trusset.org/lending-external-securities-v2/api/positions/${marketId}`;
const headers = {
  'X-API-Key': 'trusset_your_key_here',
  'Content-Type': 'application/json'
};
const payer = await payerWallet.getAddress();

const quoteRes = await fetch(`${base}/permit-quote`, {
  method: 'POST',
  headers,
  body: JSON.stringify({ loanId: 5, all: true, payer })
});
const { data: quote } = await quoteRes.json();

const { domain, types, message } = quote.typedData;
const signature = await payerWallet._signTypedData(domain, types, message);
const { v, r, s } = ethers.utils.splitSignature(signature);

const repayRes = await fetch(`${base}/repay`, {
  method: 'POST',
  headers,
  body: JSON.stringify({
    ...quote.repay,
    permit: { value: quote.permit.value, deadline: quote.permit.deadline, v, r, s }
  })
});
const { data: repayment } = await repayRes.json();

const repayStep = repayment.steps[repayment.confirmStepIndex];
const tx = await payerWallet.sendTransaction(repayStep.transaction);
await tx.wait();

await fetch(`${base}/repay`, {
  method: 'POST',
  headers,
  body: JSON.stringify({ loanId: 5, txHash: tx.hash })
});
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `NO_MARKET_ADDRESS` | `400` | The market has no on-chain address recorded |
| `MISSING_MARKET_ID` | `400` | `marketId` is longer than 100 characters |
| `VALIDATION_ERROR` | `400` | `loanId` is not a positive integer, neither `amount` nor `all: true` was supplied, `amount` is malformed or carries more decimal places than the borrow asset supports, `payer` is not an address, or `deadlineSeconds` is not an integer from `300` to `1800` |
| `INVALID_PAYER` | `400` | `payer` is the zero address, or a mixed-case address whose EIP-55 checksum does not match |
| `PAYER_REQUIRED` | `400` | No `payer` was sent |
| `LOAN_NOT_ACTIVE` | `400` | The loan is closed and can no longer be repaid |
| `NO_OUTSTANDING_DEBT` | `400` | `all` was set on a loan that owes nothing |
| `INSUFFICIENT_BALANCE` | `400` | The payer holds less than the loan owes now, or less than the partial `amount`, so no permit is quoted for a repayment that would revert. `details` names `balance`, `required`, `upTo`, `shortfall` and `fullRepayment` |
| `PERMIT_QUOTE_FAILED` | `400` | The quote could not be prepared and no more specific code applied |
| `LOAN_NOT_FOUND` | `404` | No such loan on this market |
| `MARKET_NOT_FOUND` | `404` | No market with this ID on your instance |
| `PERMIT_REQUIRES_EOA` | `409` | The payer is a contract account, which the token's permit check does not accept in this form. Repay with the approval steps |
| `PERMIT_UNSUPPORTED` | `409` | The settlement asset does not implement EIP-2612. `503` when its support could not be verified. Use the approval steps |
| `PERMIT_DOMAIN_UNRESOLVED` | `409` | No domain rebuilt from the token's `name()` and `version()` reproduces its `DOMAIN_SEPARATOR` |
| `CHAIN_UNAVAILABLE` | `503` | Whether the payer is a contract could not be read. Retry shortly |
| `LOAN_STATE_UNAVAILABLE` | `503` | The loan, its rate or the market's accrual could not be read from the network right now. Retry shortly |
| `MARKET_STATE_UNAVAILABLE` | `503` | The market's transaction fees could not be read. Retry shortly |
| `PERMIT_UNVERIFIABLE` | `503` | The token's permit domain or the payer's nonce could not be read or decoded. Retry, or use the approval steps |
