---
title: 'Withdraw Identity Terms'
api: 'POST /lending-external-securities-v2/api/identity-terms/{id}/withdraw'
description: 'Withdraw an identity terms document for good'
---

Withdraws an [identity terms](/endpoints/lending/identity-terms) document. Withdrawal is final:

- No draft can be opened, edited or published, and an open draft is discarded.
- Every open signing link is revoked, and no new one can be created.
- No market can attach any version of the document.

Markets that already carry a version keep the copy they attested. Their reads show the warning `TERMS_WITHDRAWN`, so the lender of record sees it. To describe the investors of new markets, create new terms. To take the withdrawn terms off a market, re-attest it with `identityTerms: null` or with other terms through [Attest Asset Data](/endpoints/lending/attest-asset-data).

Withdrawing a withdrawn document changes nothing and answers the document as it stands.

## Path Parameters

<ParamField path="id" type="string" required>
  The terms id.
</ParamField>

## Body Parameters

Send an empty object, `{}`.

## Response Fields

The document, as [Get Identity Terms](/endpoints/lending/get-identity-terms#response-fields) returns it, with `status` `WITHDRAWN`.

<RequestExample>
```bash cURL

  -H "X-API-Key: trusset_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{}'
```

const res = await fetch(

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `VALIDATION_ERROR` | `400` | The body is not empty |
| `IDENTITY_TERMS_NOT_FOUND` | `404` | No terms with this id exist in your instance |
| `RATE_LIMIT_EXCEEDED` | `429` | More than 10 writes in a minute. Retry after the interval in `Retry-After` |
| `IDENTITY_TERMS_WITHDRAW_FAILED` | `500` | The document could not be withdrawn for a reason that carries no code of its own. Retry, or contact support with the request ID |
