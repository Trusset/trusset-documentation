---
title: 'Get Terms'
api: 'GET /lending-external-securities-v2/api/markets/{marketId}/terms'
description: 'Read the published terms of use for a market'
---

Returns the terms of use published for the market. The lender of record authors them through [Save Terms](/endpoints/lending/save-terms), as can a wallet holding the market's admin or issuer role. A borrow button cannot be shipped compliantly without them. This is where an integrating application fetches them: by API key, on the market it already knows, in the form it renders.

The document is stored against the market's contract address, not against an instance. Every instance that holds the market reads the same terms, including the issuer instance that deployed it.

Only published terms are returned. A draft, or terms the author took down with [Unpublish Terms](/endpoints/lending/unpublish-terms), reads as if no terms exist. Loan builds on such a market, [Open Loan](/endpoints/lending/open-loan) and [Borrow More](/endpoints/lending/borrow-more), carry a `TERMS_NOT_PUBLISHED` warning, and nothing on chain enforces it.

## Path Parameters

<ParamField path="marketId" type="string" required>Market ID.</ParamField>

## Query Parameters

<ParamField query="format" type="string" default="markdown">
  `markdown` or `html`. Any other value is refused with `VALIDATION_ERROR`.
</ParamField>

The markdown form travels with its plain-text rendering in the same response, so displaying terms in a surface that has no markdown renderer never costs a second request. The plain text carries the title in capitals, drops a leading heading that repeats it, and keeps lists as indentation.

The HTML form is sanitized before it leaves, because the terms are authored by one tenant and displayed inside another's application. Tags outside a fixed allowlist of headings, paragraphs, lists, emphasis, code, quotes, links and tables are removed, and links keep only `http`, `https`, `mailto` and `#` targets.

<RequestExample>
```bash cURL
curl "https://api.trusset.org/lending-external-securities-v2/api/markets/{marketId}/terms" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/lending-external-securities-v2/api/markets/${marketId}/terms?format=html`,
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { success, data, error } = await res.json();
if (!success) throw new Error(`${error.code}: ${error.message}`);

document.getElementById('terms')!.innerHTML = data.terms.html;
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `MISSING_MARKET_ID` | `400` | The market ID is longer than 100 characters |
| `NO_MARKET_ADDRESS` | `400` | The market has no on-chain address |
| `VALIDATION_ERROR` | `400` | `format` is not `markdown` or `html` |
| `MARKET_NOT_FOUND` | `404` | No market with this ID on your instance |
| `TERMS_NOT_PUBLISHED` | `404` | No terms exist for this market, or they are a draft or were unpublished |
