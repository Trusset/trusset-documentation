---
title: 'Revise Identity Terms'
api: 'POST /lending-external-securities-v2/api/identity-terms/{id}/revise'
description: 'Open a draft of the next version of published identity terms'
---

Opens a draft of the next version of an [identity terms](/endpoints/lending/identity-terms) document. The draft starts as a copy of the latest published version, with `version` one higher and `supersedes` set to the latest core hash. Edit it with [Update Identity Terms](/endpoints/lending/update-identity-terms) and publish it with [Publish Identity Terms](/endpoints/lending/publish-identity-terms).

Nothing changes for the published version until the new one is published. Markets keep the version they attested until their issuer re-attests with the new one. Members sign each version on its own, so every member signs the new version again.

A revise while a draft is already open changes nothing and answers the document as it stands.

## Path Parameters

<ParamField path="id" type="string" required>
  The terms id.
</ParamField>

## Body Parameters

Send an empty object, `{}`.

## Response Fields

The document, as [Get Identity Terms](/endpoints/lending/get-identity-terms#response-fields) returns it, with the new draft in `draft` and `terms.hasDraft` `true`.

<RequestExample>
```bash cURL
curl -X POST "https://api.trusset.org/lending-external-securities-v2/api/identity-terms/cmx9t4k2p0007lq0cz3h8w1rd/revise" \
  -H "X-API-Key: trusset_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{}'
```
```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/lending-external-securities-v2/api/identity-terms/${termsId}/revise`,
  {
    method: 'POST',
    headers: { 'X-API-Key': 'trusset_your_key_here', 'Content-Type': 'application/json' },
    body: '{}'
  }
);
const { success, data, error } = await res.json();
if (!success) throw new Error(`${error.code}: ${error.message}`);
console.log(`Drafting version ${data.draft.version}, superseding ${data.draft.supersedes}`);
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `VALIDATION_ERROR` | `400` | The body is not empty |
| `IDENTITY_TERMS_NOT_FOUND` | `404` | No terms with this id exist in your instance |
| `IDENTITY_TERMS_CHANGED` | `409` | The document changed while the draft was being opened. Read it again |
| `IDENTITY_TERMS_NOT_PUBLISHED` | `409` | No version is published yet. Edit the draft and publish it first |
| `IDENTITY_TERMS_WITHDRAWN` | `409` | The document is withdrawn |
| `RATE_LIMIT_EXCEEDED` | `429` | More than 10 writes in a minute. Retry after the interval in `Retry-After` |
| `IDENTITY_TERMS_REVISE_FAILED` | `500` | The draft could not be opened for a reason that carries no code of its own. Retry, or contact support with the request ID |
