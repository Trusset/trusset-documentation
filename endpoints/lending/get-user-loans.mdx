---
title: 'Get User Loans'
api: 'GET /lending-external-securities-v2/api/positions/{marketId}/user-loans/{userAddress}'
description: 'List a borrower active loans in a market'
---

Returns every open loan held by one address in one market, read from the contract. Closed, repaid, and fully liquidated loans are excluded. An open loan with no debt left is still listed, with `debtFree: true`, until it is closed.

A borrower can hold several loans in the same market at once. Each is independent, with its own collateral, debt, health factor and due date, and each is liquidated separately.

## Path Parameters

<ParamField path="marketId" type="string" required>Market ID.</ParamField>
<ParamField path="userAddress" type="string" required>Borrower address, `0x` followed by 40 hex characters.</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="userAddress" type="string">The address queried, echoed back as sent.</ResponseField>
    <ResponseField name="loans" type="array">
      Active loans. Each entry has the shape of [Get Loan](/endpoints/lending/get-loan) without the `compliance` block: `loanId`, `borrower`, `collateralAmount`, `principal`, `accruedInterest`, `healthFactor`, `active`, `debtFree`, `fixedRateBps`, `dueAt` and `term`. The last four come from a batched read and are absent from every entry when that read fails and each loan is read on its own.
    </ResponseField>
  </Expandable>
</ResponseField>

<Note>
  An empty `loans` array means the borrower has no open loans here. It does not distinguish that from a failed chain read, which also returns an empty array. Confirm the market is reachable through [Get Market Metrics](/endpoints/lending/get-metrics) if an empty result is unexpected.
</Note>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/lending-external-securities-v2/api/positions/{marketId}/user-loans/0xabc7f1093d5e26b804a1c3f78de025916b47c0d3" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/lending-external-securities-v2/api/positions/${marketId}/user-loans/${address}`,
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { data } = await res.json();
const totalDebt = data.loans.reduce(
  (sum, l) => sum + Number(l.principal) + Number(l.accruedInterest),
  0
);
const pastGrace = data.loans.filter(l => l.term?.enforceable === true);
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `VALIDATION_ERROR` | `400` | `userAddress` is not `0x` followed by 40 hex characters |
| `NO_MARKET_ADDRESS` | `400` | The market has no on-chain address recorded |
| `MISSING_MARKET_ID` | `400` | The market ID is longer than 100 characters |
| `MARKET_NOT_FOUND` | `404` | No market with this ID on your instance |
