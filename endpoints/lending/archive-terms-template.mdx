---
title: 'Archive Terms Template'
api: 'DELETE /lending-external-securities-v2/api/markets/terms-library/{templateId}'
description: 'Archive a terms library template that nothing is bound to any more'
---

Archives one template of this instance's terms library. Nothing is deleted: the template, its text and every version stay readable through [Get Terms Template](/endpoints/lending/get-terms-template), and [List Terms Templates](/endpoints/lending/list-terms-templates) lists it with `includeArchived=true`. An archived template can no longer be bound to a market or a standing policy. Restore it with `archived: false` on [Update Terms Template](/endpoints/lending/update-terms-template).

The call is the same as Update Terms Template with `archived: true`. It writes no new version, so `changed` is `false`. Archiving a template that is already archived changes nothing.

Only an account Trusset approved as a lender of record can author templates. Any other account is refused with `403 CURATOR_NOT_APPROVED`.

## When archiving is refused

A template that is still in use cannot be archived, because the markets and policies bound to it would point at terms the library no longer lists, and a market adopted under such a policy would go live without terms of use. Archiving is refused with `409 TEMPLATE_IN_USE` while the template is bound to either of these:

- a market whose terms are published and not customised
- any standing policy, switched off or not

`error.details` names every one of them:

| Field | Content |
|---|---|
| `markets` | `[{ generation, marketAddress, templateVersion, customised, published }]`, one entry per bound market |
| `policies` | `[{ id, kind, address, label, enabled }]`, one entry per bound standing policy |

Release them first, then archive again:

- Bind each market to another template with [Save Terms](/endpoints/lending/save-terms) and `templateId`, or customise its terms with a save that changes the text.
- Bind each policy to another template, or to none with `termsTemplateId: null`, on [Update Standing Policy](/endpoints/operators/update-standing-policy).

## Path Parameters

<ParamField path="templateId" type="string" required>
  Template ID from [List Terms Templates](/endpoints/lending/list-terms-templates), 1 to 100 characters.
</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="template" type="object">The archived template, with the fields of [Get Terms Template](/endpoints/lending/get-terms-template#response-fields) except `versions` and `markets`. `archived` reads `true` and `archivedAt` is set.</ResponseField>
    <ResponseField name="changed" type="boolean">`false`: archiving writes no new version.</ResponseField>
  </Expandable>
</ResponseField>

```bash cURL
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/lending-external-securities-v2/api/markets/terms-library/${templateId}`,
  { method: 'DELETE', headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { success, data, error } = await res.json();
if (!success && error.code === 'TEMPLATE_IN_USE') {
  const { markets, policies } = error.details;
  console.log(markets.map((m) => m.marketAddress), policies.map((p) => p.id));
}
```

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `VALIDATION_ERROR` | `400` | `templateId` is longer than 100 characters |
| `TEMPLATE_ARCHIVE_FAILED` | `400` | The template could not be archived for a reason that carries no code of its own |
| `CURATOR_NOT_APPROVED` | `403` | Trusset has not approved this account to act as a lender of record |
| `TEMPLATE_NOT_FOUND` | `404` | No template with this ID exists on this instance |
| `TEMPLATE_IN_USE` | `409` | The template is still bound to a published, non-customised market or to a standing policy. `error.details` names them |
| `RATE_LIMIT_EXCEEDED` | `429` | More than 10 writes in the minute |
