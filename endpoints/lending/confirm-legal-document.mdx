---
title: 'Confirm Document'
api: 'POST /lending-external-securities-v2/api/markets/{marketId}/legal-documents/confirm'
description: 'Verify a registry transaction from its receipt and record the outcome'
---

Confirms a mined `setDocument` or `removeDocument` transaction. The server reads the receipt itself: the transaction must target the document registry, call `setDocument` or `removeDocument`, be signed by a verified wallet of your instance, and emit `DocumentUpdated` or `DocumentRemoved` for this market. What is recorded comes from those events, never from the request.

The confirm marks staged loan documents recorded when an event carries their loan, name, hash and locator, and writes one audit entry per event. Confirming the same transaction again changes nothing and writes no second audit entry. A transaction signed through a smart account that wraps the call is verified through the wrapped call.

## Path Parameters

<ParamField path="marketId" type="string" required>
  The market's record ID on your instance.
</ParamField>

## Body Parameters

<ParamField body="txHash" type="string" required>
  The hash of the mined transaction.
</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="txHash" type="string">The verified transaction.</ResponseField>
    <ResponseField name="signer" type="string">The wallet that signed it.</ResponseField>
    <ResponseField name="blockNumber" type="integer">The block it mined in.</ResponseField>
    <ResponseField name="recordedAt" type="string">The block time.</ResponseField>
    <ResponseField name="events" type="array">Each `{ kind, loanId, name, nameValid, nameBytes32, uri, documentHash, contentHash, visibility, by, logIndex }`. `kind` is `UPDATED` or `REMOVED`; `by` is the writing admin wallet.</ResponseField>
    <ResponseField name="stagesRecorded" type="integer">Staged loan documents this transaction recorded.</ResponseField>
  </Expandable>
</ResponseField>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `VALIDATION_ERROR` | `400` | `txHash` is missing or malformed |
| `TX_REVERTED` | `400` | The transaction reverted. Nothing was recorded |
| `TX_WRONG_TARGET`, `TX_WRONG_FUNCTION` | `400` | The transaction does not call `setDocument` or `removeDocument` on the registry |
| `TX_NOT_VERIFIED` | `400` | The transaction emits no document event for this market |
| `DOCUMENT_WRITE_NOT_INSTANCE_BOUND` | `403` | The signer is not a verified wallet of your instance |
| `TX_NOT_FOUND` | `404` | The transaction is not mined yet. Retry shortly |
| `MARKET_NOT_FOUND` | `404` | No market with this ID on your instance |
| `DOCUMENT_REGISTRY_NOT_CONFIGURED` | `501` | The document registry is not deployed on this network |
| `CHAIN_UNAVAILABLE`, `SERVICE_UNAVAILABLE` | `503` | The chain or this instance's wallets could not be read. The record on chain is unaffected; send the same `txHash` again shortly |
