---
title: 'Create Terms Template'
api: 'POST /lending-external-securities-v2/api/markets/terms-library'
description: "Add a template to this instance's terms library"
---

Adds a terms of use template to this instance's library and answers `201`. The template starts at version `1` and is bound to nothing. Bind it to a market with [Save Terms](/endpoints/lending/save-terms) and `templateId`, or to a [standing policy](/endpoints/operators/create-standing-policy) with `termsTemplateId`. This is a database write: nothing is signed and nothing goes on chain.

Only an account Trusset approved as a lender of record can author templates. Any other account is refused with `403 CURATOR_NOT_APPROVED` before the body is read. `canAuthor` on [List Terms Templates](/endpoints/lending/list-terms-templates) says whether this account is one.

## Body Parameters

<ParamField body="title" type="string" required>
  Template title, 1 to 200 characters. Trimmed, must not be blank, and must not contain control characters, tab and newline included.
</ParamField>

<ParamField body="content" type="string" required>
  The document as markdown. Stored verbatim apart from Windows line endings, which become `\n`. The stored text must fit in 262,144 bytes of UTF-8, must not be blank, and must not contain control characters other than tab, newline and carriage return.
</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="template" type="object">The new template with the fields of [Get Terms Template](/endpoints/lending/get-terms-template#response-fields) except `versions` and `markets`: `content` is included, and every `usage` count is `0`.</ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.trusset.org/lending-external-securities-v2/api/markets/terms-library" \
  -H "X-API-Key: trusset_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Secured credit line, house terms",
    "content": "# Terms of Use\n\n## 1. Lender of record\n\nACME Bank AG acts as lender of record for this market.\n"
  }'
```
```typescript TypeScript
import { readFile } from 'node:fs/promises';

const content = await readFile('./house-terms.md', 'utf8');

const res = await fetch(
  'https://api.trusset.org/lending-external-securities-v2/api/markets/terms-library',
  {
    method: 'POST',
    headers: {
      'X-API-Key': 'trusset_your_key_here',
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({ title: 'Secured credit line, house terms', content })
  }
);
const { success, data, error } = await res.json();
if (!success) throw new Error(`${error.code}: ${error.message}`);
const templateId = data.template.id;
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `VALIDATION_ERROR` | `400` | `title` or `content` is missing, empty or not a string, `title` is over 200 characters, or `content` is over 262,144 characters |
| `INVALID_TERMS_TITLE` | `400` | The title is blank after trimming, or contains control characters |
| `INVALID_TERMS_CONTENT` | `400` | The document is blank, or contains control characters other than tab, newline and carriage return |
| `TEMPLATE_SAVE_FAILED` | `400` | The template could not be saved for a reason that carries no code of its own |
| `CURATOR_NOT_APPROVED` | `403` | Trusset has not approved this account to act as a lender of record |
| `TERMS_TOO_LARGE` | `413` | The document exceeds 262,144 bytes of UTF-8 |
| `RATE_LIMIT_EXCEEDED` | `429` | More than 10 writes in the minute |
