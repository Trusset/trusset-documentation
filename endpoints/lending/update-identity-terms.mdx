---
title: 'Update Identity Terms'
api: 'PUT /lending-external-securities-v2/api/identity-terms/{id}'
description: 'Save the draft, the name or the requirements extension of an identity terms document'
---

Saves the open draft of an [identity terms](/endpoints/lending/identity-terms) document. Send the whole draft each time: `draft` replaces the saved one. A draft may stay incomplete. The answer lists the draft's validation problems in `draftProblems`. Publishing refuses each of them, and in addition a claim no gate can back (`IDENTITY_TERMS_CLAIM_NOT_BACKED`) and a draft that states exactly what the latest version states (`IDENTITY_TERMS_UNCHANGED`).

Only a draft can be edited. A published version is frozen: open the next one with [Revise Identity Terms](/endpoints/lending/revise-identity-terms) first. A withdrawn document cannot be edited at all.

Send `expectedUpdatedAt` with the `updatedAt` you read, so a save never overwrites a change someone else made in between. A stale save is refused with `409 IDENTITY_TERMS_CHANGED` and changes nothing. Two saves that race are refused the same way, even without it.

Saving refuses only what must never be stored, even in a draft:

- a text in the draft longer than 612 characters, or a draft nested deeper than 8 levels: `422 IDENTITY_TERMS_FIELD_INVALID`;
- a control or invisible character in a text: `422 IDENTITY_TERMS_TEXT_INVALID`;
- a text that looks like an e-mail address, a phone number or an IBAN: `422 IDENTITY_TERMS_PERSONAL_DATA`;
- a draft larger than 64 KB: `413 IDENTITY_TERMS_FIELD_INVALID`;
- a `requirementsExtJson` longer than 300,000 characters: `400 VALIDATION_ERROR`, and one larger than 256 KB in UTF-8 bytes: `413 IDENTITY_TERMS_EXT_INVALID`.

## Path Parameters

<ParamField path="id" type="string" required>
  The terms id.
</ParamField>

## Body Parameters

<ParamField body="draft" type="object">
  The whole draft, in the shape of the [schema](/endpoints/lending/identity-terms#schema). At most 64 KB. Leave it out to keep the saved draft and change only the name or the extension.
</ParamField>

<ParamField body="name" type="string">
  A new name, at most 200 characters. Leave it out to keep `draft.name`, or the current name.
</ParamField>

<ParamField body="expectedUpdatedAt" type="string">
  The `updatedAt` of the document as you read it, ISO 8601.
</ParamField>

<ParamField body="requirementsExtJson" type="string | null">
  The [requirements extension](/endpoints/lending/identity-terms#requirements-extension) as JSON text: an object or an array of at most 256 KB in UTF-8 bytes and at most 300,000 characters, with no personal data. The platform pins the exact bytes to IPFS and writes `requirementsExt: { uri, hash }` into the draft, where `hash` is keccak256 of the bytes. Send `null` to remove the extension.

  Do not set `draft.requirementsExt` to an extension of your own. A `requirementsExt` the platform did not pin for these terms is refused. Keeping the one already in the draft, or the one of the latest version, is accepted.
</ParamField>

## Response Fields

The document, as [Get Identity Terms](/endpoints/lending/get-identity-terms#response-fields) returns it.

<RequestExample>
```bash cURL
curl -X PUT "https://api.trusset.org/lending-external-securities-v2/api/identity-terms/cmx9t4k2p0007lq0cz3h8w1rd" \
  -H "X-API-Key: trusset_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "expectedUpdatedAt": "2026-11-25T11:02:47.000Z",
    "requirementsExtJson": "{\"investorQuestionnaire\":\"MiFID II suitability, annual review\"}"
  }'
```
```typescript TypeScript
const base = 'https://api.trusset.org/lending-external-securities-v2/api/identity-terms';
const headers = { 'X-API-Key': 'trusset_your_key_here', 'Content-Type': 'application/json' };

const current = await (await fetch(`${base}/${termsId}`, { headers })).json();
const draft = { ...current.data.draft, validTo: '2027-12-31' };

const res = await fetch(`${base}/${termsId}`, {
  method: 'PUT',
  headers,
  body: JSON.stringify({ draft, expectedUpdatedAt: current.data.terms.updatedAt })
});
const { success, data, error } = await res.json();
if (!success) throw new Error(`${error.code}: ${error.message}`);
console.log(data.draftProblems);
```

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `VALIDATION_ERROR` | `400` | The body carries a field other than the four above, one has the wrong type, or `requirementsExtJson` is longer than 300,000 characters |
| `IDENTITY_TERMS_FIELD_INVALID` | `400`, `413`, `422` | `expectedUpdatedAt` is not an ISO 8601 time or the name is longer than 200 characters (`400`), a text in the draft is longer than 612 characters or the draft is nested deeper than 8 levels (`422`), or the draft is larger than 64 KB (`413`) |
| `IDENTITY_TERMS_TEXT_INVALID` | `400`, `422` | The name (`400`) or a text in the draft (`422`) holds a control or invisible character. The name is also refused when it mixes alphabets |
| `IDENTITY_TERMS_PERSONAL_DATA` | `400`, `422` | The name or the extension (`400`), or a text in the draft (`422`), looks like an e-mail address, a phone number or an IBAN |
| `IDENTITY_TERMS_EXT_INVALID` | `400`, `413` | The extension is empty, not JSON, not an object or array, or larger than 256 KB in UTF-8 bytes (`413`), or `draft.requirementsExt` names an extension the platform did not pin for these terms |
| `IDENTITY_TERMS_NOT_FOUND` | `404` | No terms with this id exist in your instance |
| `IDENTITY_TERMS_CHANGED` | `409` | The document changed after you read it. Read it again and save your change on the current state |
| `IDENTITY_TERMS_NO_DRAFT` | `409` | No draft is open: the latest version is published and frozen. Revise first |
| `IDENTITY_TERMS_WITHDRAWN` | `409` | The document is withdrawn and cannot be edited |
| `RATE_LIMIT_EXCEEDED` | `429` | More than 10 writes in a minute. Retry after the interval in `Retry-After` |
| `IDENTITY_TERMS_UPDATE_FAILED` | `500` | The draft could not be saved for a reason that carries no code of its own. Retry, or contact support with the request ID |
| `IDENTITY_TERMS_EXT_PIN_FAILED` | `503` | The extension could not be pinned just now. Nothing was saved. Retry shortly |
