---
title: 'Report Signed Agreement'
api: 'POST /lending-external-securities-v2/api/markets/{marketId}/loan-agreements/{ref}/signed'
description: 'Report the signed contract as a salted commitment'
---

Reports the signed contract, and optionally the signing certificate, as salted commitments computed on your side with the agreement salt. Trusset never receives the file or its plain SHA-256: a body with file content or a plain hash is refused.

```
commitment = SHA-256( utf8("trusset.loan-document.v1") || salt || SHA-256(file bytes) )
```

The SDK computes it with `lending.agreements.reportSigned(marketId, ref, file)`. You may report again until the borrower accepts, for example after a copy mismatch; the same commitment sent again changes nothing (`changed: false`). If the published terms of use changed since the issue, the agreement becomes `STALE` and the borrower requests a new one.

## Who can call

The bank. This is the seam a signing-tool connector on the bank side calls.

## Path Parameters

<ParamField path="marketId" type="string" required>
  The market's record ID on your instance.
</ParamField>

<ParamField path="ref" type="string" required>
  The agreement reference: `agr_` followed by 20 characters.
</ParamField>

## Body Parameters

<ParamField body="documentCommitment" type="string" required>
  The salted commitment of the signed contract: 32 bytes as `0x` followed by 64 hex characters.
</ParamField>

<ParamField body="certificateCommitment" type="string">
  The salted commitment of the signing certificate, computed with the same salt.
</ParamField>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `DOCUMENT_CONTENT_REFUSED` | `400` | The body carries file content. Keep the file with you and send only the salted commitment |
| `PLAIN_HASH_REFUSED` | `400` | The body carries the plain hash of a file (`contentHash`, `sha256` and similar). Send the salted commitment instead |
| `PERSONAL_DATA_REFUSED` | `400` | The body carries a personal data field such as `name` or `email`. Use wallet addresses and `externalReference` only |
| `VALIDATION_ERROR` | `400` | A field is missing, has the wrong type, or is not part of this route |
| `INVALID_COMMITMENT` | `400` | A commitment is not 32 bytes of hex, is zero, or both commitments are equal |
| `AGREEMENT_BANK_ONLY` | `403` | No verified wallet of your instance holds `DEFAULT_ADMIN_ROLE` on the market |
| `AGREEMENT_STATE` | `409` | The agreement is in a status that does not allow this. `details.status` names it; read the agreement for its next step |
| `AGREEMENT_STALE` | `409` | The terms of use changed after the issue. The agreement is now `STALE`; the borrower requests a new one |
| `TERMS_UNAVAILABLE` | `503` | The terms of use could not be read just now. Retry shortly |
| `AGREEMENT_NOT_FOUND` | `404` | No agreement with this reference on this market, or your instance is not a party to it. List the agreements to find it |
| `MARKET_NOT_FOUND` | `404` | No market with this ID on your instance |
| `CHAIN_UNAVAILABLE`, `SERVICE_UNAVAILABLE` | `503` | The market or your instance's wallets could not be read just now. Nothing was decided. Retry shortly |
