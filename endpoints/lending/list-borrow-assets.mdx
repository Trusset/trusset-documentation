---
title: 'List Borrow Assets'
api: 'GET /lending-external-securities-v2/api/markets/borrow-assets'
description: 'List the curated settlement assets available for new markets'
---

Returns the settlement assets Trusset curates for your instance type and network, plus the decimal bounds enforced on custom assets. Use this to populate a borrow asset selector before calling [Deploy Market](/endpoints/lending/deploy-market).

A market's borrow asset is the settlement token (stablecoin) liquidity providers deposit, borrowers receive, and all debt is denominated in. It is fixed at deployment and cannot be changed afterwards.

<Info>
  You are not limited to this list. Any ERC-20 with 6 to 18 decimals can be passed as `borrowAssetAddress` at deployment. The contract is validated on-chain at that point: it must have deployed bytecode and readable `decimals()` and `balanceOf()`. Omitting `borrowAssetAddress` selects USDC.
</Info>

A production instance on Ethereum is offered USDC, USDT and DAI at their mainnet addresses. A development instance is offered test tokens for USDC, USDT, DAI, EURC and EUROP on the development networks, marked `(Mock)` in their names. An asset with no address configured for your network is left out.

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="assets" type="array">
      Curated assets for the instance type and network bound to your API key.
      <Expandable>
        <ResponseField name="address" type="string">Checksummed token address.</ResponseField>
        <ResponseField name="symbol" type="string">Token symbol.</ResponseField>
        <ResponseField name="name" type="string">Human-readable token name.</ResponseField>
        <ResponseField name="decimals" type="integer">Token decimals. Every amount you send or receive for this market's settlement side is a decimal string parsed at this precision.</ResponseField>
        <ResponseField name="mintable" type="boolean">Whether the test token can be minted on a development network. Always `false` for production assets.</ResponseField>
        <ResponseField name="isDefault" type="boolean">True for USDC, the asset selected when `borrowAssetAddress` is omitted.</ResponseField>
        <ResponseField name="saved" type="boolean">Present and `true` on a custom asset saved in your instance. Saved assets follow the curated ones. See [Saved stablecoins](#saved-stablecoins).</ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="savedRead" type="boolean">`false` when the saved assets could not be read, so `assets` lists the curated ones only. It is not an empty saved list.</ResponseField>
    <ResponseField name="custom" type="object">
      <Expandable>
        <ResponseField name="minDecimals" type="integer">Minimum decimals accepted for a custom borrow asset. Currently 6.</ResponseField>
        <ResponseField name="maxDecimals" type="integer">Maximum decimals accepted for a custom borrow asset. Currently 18.</ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

const res = await fetch(
  'https://api.trusset.org/lending-external-securities-v2/api/markets/borrow-assets',

## Saved stablecoins

A custom `borrowAssetAddress` is saved in your instance once a create build accepts it: [Deploy Market](/endpoints/lending/deploy-market) or a vault creation answers with the transaction to sign. A build that is refused saves nothing, and neither does the record step that confirms a deployment. Each instance keeps its 25 most recently used custom assets per network. Curated assets are never saved.

List or remove them with the same API key:

| Method | Path | Answer |
|---|---|---|
| `GET` | `/instances/api/saved-stablecoins` | `{ stablecoins, max }`: the saved assets of the instance your key belongs to, most recently used first, each with `address`, `symbol`, `name`, `decimals` and `saved: true`, and the cap of 25 |
| `DELETE` | `/instances/api/saved-stablecoins/{address}` | `{ address, removed: true }`. `404 SAVED_STABLECOIN_NOT_FOUND` when the address is not saved, `400 INVALID_ADDRESS` when it is not an address |

Removing an asset only takes it off the list. Markets and vaults that settle in it keep it.

## Custom Asset Rejections

When you pass a `borrowAssetAddress` that fails validation, [Deploy Market](/endpoints/lending/deploy-market) returns one of:

| Code | Cause |
|---|---|
| `INVALID_BORROW_ASSET` | A mixed-case address whose checksum does not match. A malformed address is refused earlier with `VALIDATION_ERROR` |
| `BORROW_ASSET_NOT_CONTRACT` | No deployed bytecode at the address on the resolved network |
| `BORROW_ASSET_NOT_ERC20` | `decimals()` or `balanceOf()` could not be read |
| `BORROW_ASSET_DECIMALS_UNSUPPORTED` | Decimals outside the 6 to 18 range |
