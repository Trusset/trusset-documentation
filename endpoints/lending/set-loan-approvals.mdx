---
title: 'Set Loan Approvals'
api: 'POST /lending-external-securities-v2/api/markets/{marketId}/loan-approvals'
description: 'Switch approve-only loans on or off for a market'
---

Builds the next transaction that switches [approve-only loans](/endpoints/lending/loan-approvals) on or off, and confirms it on a second call. Trusset never signs: the market admin signs the calldata this route returns.

Switching on takes up to two signatures:

1. `CREATE_APPROVALS` builds the market's approvals contract. The answer carries `remaining: 1`.
2. Call again with `enabled: true` for `SWITCH_ON`, which names the approvals contract on the market.

Switching off is one signature, `SWITCH_OFF`.

If approve-only loans were only requested at deployment and never switched on, `enabled: false` clears the request without a transaction. The answer is then `action: NONE` with `cleared: true`.

## Who can call

The market admin, the holder of `DEFAULT_ADMIN_ROLE`.

## Path Parameters

<ParamField path="marketId" type="string" required>
  The market's record ID on your instance.
</ParamField>

## Body Parameters

Send exactly one of `enabled` or `txHash`.

<ParamField body="enabled" type="boolean">
  `true` to switch approve-only loans on, `false` to switch them off.
</ParamField>

<ParamField body="signerAddress" type="string">
  The wallet that will sign.
</ParamField>

<ParamField body="txHash" type="string">
  Hash of the transaction you broadcast for the step this route built. Send it to confirm the step.
</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="action" type="string">`SIGN_TRANSACTION`, or `NONE` when a request was cleared without a transaction. Returned when `txHash` is omitted.</ResponseField>
    <ResponseField name="step" type="string">`CREATE_APPROVALS`, `SWITCH_ON` or `SWITCH_OFF`.</ResponseField>
    <ResponseField name="transaction" type="object">`{ to, data }`, the unsigned transaction. Returned when `txHash` is omitted.</ResponseField>
    <ResponseField name="functionName" type="string">`createLoanApprovals` or `setLoanApprovals`. Returned when `txHash` is omitted.</ResponseField>
    <ResponseField name="signer" type="string">The wallet that signs. When confirming, the wallet that sent the transaction.</ResponseField>
    <ResponseField name="requiredRole" type="string | null">`DEFAULT_ADMIN_ROLE`, or `null`. Returned when `txHash` is omitted.</ResponseField>
    <ResponseField name="approvals" type="string">The approvals contract the step names. Present when the step carries one.</ResponseField>
    <ResponseField name="remaining" type="number">`1` when another signature follows this step, `0` otherwise.</ResponseField>
    <ResponseField name="confirmWith" type="object">`{ endpoint, field }`: the call that confirms this transaction, and `txHash` as the body field that carries the hash. Returned when `txHash` is omitted.</ResponseField>
    <ResponseField name="cleared" type="boolean">`true` when the request made at deployment was cleared without a transaction.</ResponseField>
    <ResponseField name="mode" type="object">The mode after the change. See [Get Loan Approvals](/endpoints/lending/get-loan-approvals#response-fields). Returned when confirming, and when a request was cleared.</ResponseField>
    <ResponseField name="txHash" type="string">Transaction hash. Returned when confirming.</ResponseField>
    <ResponseField name="blockNumber" type="number">Block the transaction was mined in. Returned when confirming.</ResponseField>
    <ResponseField name="marketId" type="string">The market's record ID on your instance.</ResponseField>
  </Expandable>
</ResponseField>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `NOT_MARKET_ADMIN` | `403` | No verified wallet of your instance holds `DEFAULT_ADMIN_ROLE` on the market |
| `SIGNER_NOT_AUTHORIZED` | `403` | `signerAddress` is not a wallet that may sign this step |
| `MODE_CHANGE_NOT_INSTANCE_BOUND` | `403` | The transaction was signed by a wallet that is not verified for your instance |
| `MARKET_PENDING_CURATOR` | `409` | The market has no lender of record yet |
| `MARKET_UPGRADE_REQUIRED` | `409` | The market runs an implementation from before this feature. Its admin upgrades it through the seven-day notice first |
| `LOAN_APPROVALS_CURRENT` | `409` | Approve-only loans are already in the state you asked for. Nothing to sign |
| `LOAN_APPROVALS_NOT_AVAILABLE` | `409` | The network does not carry the approvals factory yet |
| `MODE_CHANGE_WOULD_REVERT` | `409` | The transaction would revert as it stands, so nothing was built |
| `CHAIN_UNAVAILABLE` | `503` | The chain could not be read just now |
