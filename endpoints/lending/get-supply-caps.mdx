---
title: 'Get Supply Caps'
api: 'GET /lending-external-securities-v2/api/markets/{marketId}/supply-caps'
description: 'Read collateral caps and current usage'
---

Returns the market's global and per-borrower collateral caps alongside the collateral currently locked. Use this before quoting a borrower a size. [Open Loan](/endpoints/lending/open-loan) and [Add Collateral](/endpoints/lending/add-collateral) refuse a request that would pass either cap with `SUPPLY_CAP_EXCEEDED` or `USER_SUPPLY_CAP_EXCEEDED` before a wallet signs, and the contract reverts on it too.

The per-borrower cap counts everything a borrower holds as collateral across all of their loans on this market, not the size of one loan. All three values are formatted in the collateral token's own decimals.

## Path Parameters

<ParamField path="marketId" type="string" required>The market's record ID, as `id` on [List Markets](/endpoints/lending/list-markets), not its contract address. See [Market IDs](/endpoints/lending/list-markets#market-ids).</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="maxTotalCollateral" type="string">Global cap across all borrowers. `0.0` means uncapped.</ResponseField>
    <ResponseField name="maxUserCollateral" type="string">Cap per borrower address. `0.0` means uncapped.</ResponseField>
    <ResponseField name="currentTotalCollateral" type="string">Collateral currently locked in the market.</ResponseField>
  </Expandable>
</ResponseField>

<Note>
  Returns `data: null` if the contract read fails. Both caps are set through [Update Market Config](/endpoints/lending/update-config).
</Note>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/lending-external-securities-v2/api/markets/{marketId}/supply-caps" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/lending-external-securities-v2/api/markets/${marketId}/supply-caps`,
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { data } = await res.json();
const capped = data && Number(data.maxTotalCollateral) > 0;
const headroom = capped ? Number(data.maxTotalCollateral) - Number(data.currentTotalCollateral) : Infinity;
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `NO_MARKET_ADDRESS` | `400` | The market has no on-chain address recorded |
| `MISSING_MARKET_ID` | `400` | `marketId` is longer than 100 characters |
| `MARKET_NOT_FOUND` | `404` | No market with this ID on your instance |
