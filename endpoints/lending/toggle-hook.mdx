---
title: 'Toggle Hook'
api: 'POST /lending-external-securities-v2/api/hooks/{marketId}/{hookId}/toggle'
description: 'Enable or disable a hook without deleting it'
---

Sets the `active` flag and returns the full hook record. Execution history is preserved, and nothing goes on-chain.

An inactive hook drops out of everything that runs on its own. The scheduler skips an inactive `monitorRisk` hook. A liquidation does not run an inactive `beforeLiquidation` or `afterLiquidation` hook, and a monitor that evaluates to `false` does not run an inactive `afterLiquidation` hook. An inactive hook listed in another hook's `triggerHookIds` never satisfies that trigger. [Execute Hook](/endpoints/lending/execute-hook) still runs an inactive hook when called for it directly. Deliveries the hook queued before it was disabled are still sent and retried.

Re-enabling a monitor puts it back on the schedule from the scheduler's next wake-up, not from this call.

## Path Parameters

<ParamField path="marketId" type="string" required>The market's record ID, as `id` on [List Markets](/endpoints/lending/list-markets), not its contract address. See [Market IDs](/endpoints/lending/list-markets#market-ids).</ParamField>
<ParamField path="hookId" type="string" required>Hook ID.</ParamField>

## Body Parameters

<ParamField body="active" type="boolean" required>
  `true` to enable, `false` to disable. Any non-boolean value, including the string `"false"`, returns `INVALID_ACTIVE`.
</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  The updated hook record. See [List Hooks](/endpoints/lending/list-hooks) for each field.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.trusset.org/lending-external-securities-v2/api/hooks/{marketId}/{hookId}/toggle" \
  -H "X-API-Key: trusset_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{"active": false}'
```
```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/lending-external-securities-v2/api/hooks/${marketId}/${hookId}/toggle`,
  {
    method: 'POST',
    headers: {
      'X-API-Key': 'trusset_your_key_here',
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({ active: false })
  }
);
const { data: hook } = await res.json();
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `INVALID_ACTIVE` | `400` | `active` is missing or not a boolean |
| `MISSING_MARKET_ID` | `400` | `marketId` is longer than 100 characters |
| `MISSING_HOOK_ID` | `400` | `hookId` is longer than 100 characters |
| `MARKET_NOT_FOUND` | `404` | No market with this ID belongs to your instance |
| `HOOK_NOT_FOUND` | `404` | No hook with this ID exists on this market |
