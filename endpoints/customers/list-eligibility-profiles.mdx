---
title: 'List Eligibility Profiles'
api: 'GET /customers/api/eligibility/profiles'
description: 'The verification profiles that carry an eligibility register'
---

Returns the verification profiles of your instance that carry an eligibility register, with the register each one stands for. These are the profiles a lending market or a vault can gate on, by key, and the ones [Request Admission](/endpoints/customers/request-admission) can queue wallets for.

A profile without a register is left out. Registers are deployed or bound in the Issuer Portal. [List Verification Profiles](/endpoints/customers/list-verification-profiles) returns every profile with its full requirements. See [Eligibility registers](/endpoints/customers/introduction#eligibility-registers).

## Response Fields

<ResponseField name="data" type="array">
  Presets first, then custom profiles, oldest first. Empty when no profile has a register.
  <Expandable>
    <ResponseField name="key" type="string">The profile key, as the lending endpoints take it in `identityRegistryProfile`, `providerRegistryProfile`, `borrowerProfile` and `providerProfile`.</ResponseField>
    <ResponseField name="name" type="string">Display name.</ResponseField>
    <ResponseField name="entityType" type="string">`INDIVIDUAL` or `COMPANY`.</ResponseField>
    <ResponseField name="professionalOnly" type="boolean">Whether the profile is limited to professional clients. Only the register of such a profile, in the `REGISTER` mode, can be the borrower gate of a `MARKET`-priced lending market. See [Professional borrowers](/endpoints/lending/set-identity-gates#professional-borrowers).</ResponseField>
    <ResponseField name="requirementsHash" type="string">The hash of the profile's current requirements. See [Requirements hash](/endpoints/customers/list-verification-profiles#requirements-hash).</ResponseField>
    <ResponseField name="registryAddress" type="string">The eligibility register, checksummed.</ResponseField>
    <ResponseField name="admissionMode" type="string">`REGISTER`, `INSTANCE_REGISTER` or `EXTERNAL`, recorded when the register was bound. Only `REGISTER` takes admissions through this API. See [Which registers can be signed here](/endpoints/customers/introduction#which-registers-can-be-signed-here).</ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/customers/api/eligibility/profiles" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const response = await fetch('https://api.trusset.org/customers/api/eligibility/profiles', {
  headers: { 'X-API-Key': 'trusset_your_key_here' }
});
const { data: profiles } = await response.json();

const professionalGates = profiles.filter(
  (profile: { professionalOnly: boolean }) => profile.professionalOnly
);
```
</RequestExample>
