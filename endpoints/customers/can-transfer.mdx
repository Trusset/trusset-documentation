---
title: 'Check Transfer Compliance'
api: 'POST /customers/api/identity/can-transfer'
description: 'Ask the identity register whether a transfer between two wallets would pass'
---

Asks the identity register your instance writes to whether a transfer between two wallets would pass its checks. Use it as a pre-flight check, so a refused transfer does not revert on chain.

<Warning>
  On an ERC-3643 register, `allowed: true` only means both wallets are verified on the register. No compliance rule is evaluated there, and `amount` and both balances are ignored.
</Warning>

On a Trusset register, the register checks the sender, then the receiver. Each must hold an identity that is not revoked, not hard-expired and not frozen. A soft-expired identity still passes. The register then asks each compliance module active on it, which sees `amount` and both balances.

## Body Parameters

<ParamField body="from" type="string" required>
  Sender wallet.
</ParamField>

<ParamField body="to" type="string" required>
  Receiver wallet.
</ParamField>

<ParamField body="amount" type="string" default="0">
  The amount as a whole number in the token's smallest unit, such as `"1000000000000000000000"` for 1,000 tokens with 18 decimals. A decimal string such as `"1000.5"` fails with `CHECK_FAILED`.
</ParamField>

<ParamField body="fromBalance" type="string" default="0">
  The sender's balance before the transfer, in the same unit.
</ParamField>

<ParamField body="toBalance" type="string" default="0">
  The receiver's balance before the transfer, in the same unit.
</ParamField>

<Note>
  The basic compliance module refuses a transfer larger than `fromBalance`. With the default of `0`, any nonzero `amount` fails wherever that module is active. Send the real balances.
</Note>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="allowed" type="boolean">Whether the transfer passes.</ResponseField>
    <ResponseField name="reason" type="integer">`0` when allowed. Otherwise the first check that failed, from the table below.</ResponseField>
    <ResponseField name="senderStatus" type="string">On a Trusset register, `active`, `soft_expired`, `hard_expired` or `revoked`. A wallet that was never verified also reads `revoked`. On an ERC-3643 register, `active` or `none`.</ResponseField>
    <ResponseField name="receiverStatus" type="string">The same, for the receiver.</ResponseField>
    <ResponseField name="registerKind" type="string">ERC-3643 only. Always `TREX`.</ResponseField>
  </Expandable>
</ResponseField>

| `reason` | Meaning |
|---|---|
| `0` | Allowed |
| `1` | The sender holds no active identity. A revoked or never-verified sender lands here |
| `2` | The receiver holds no active identity. A revoked or never-verified receiver lands here |
| `3` | The sender is frozen |
| `4` | The receiver is frozen |
| `5` | The sender's identity is hard-expired |
| `6` | The receiver's identity is hard-expired |
| `10` | A compliance module refused the transfer |
| `11` | A compliance module failed when asked |

An ERC-3643 register only answers `0`, `1` or `2`. A register that cannot be read answers `500 CHECK_FAILED`, never `allowed: false`.

<RequestExample>
```bash cURL
curl -X POST "https://api.trusset.org/customers/api/identity/can-transfer" \
  -H "Content-Type: application/json" \
  -H "X-API-Key: trusset_your_key_here" \
  -d '{
    "from": "0xaBc123DEf456789012345678901234567890aBCD",
    "to": "0x1234567890AbcdEF1234567890aBcdef12345678",
    "amount": "1000000000000000000000",
    "fromBalance": "5000000000000000000000",
    "toBalance": "200000000000000000000"
  }'
```
```typescript TypeScript
const response = await fetch(
  'https://api.trusset.org/customers/api/identity/can-transfer',
  {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'X-API-Key': 'trusset_your_key_here'
    },
    body: JSON.stringify({
      from: '0xaBc123DEf456789012345678901234567890aBCD',
      to: '0x1234567890AbcdEF1234567890aBcdef12345678',
      amount: '1000000000000000000000',
      fromBalance: '5000000000000000000000',
      toBalance: '200000000000000000000'
    })
  }
);
const { data } = await response.json();

if (!data.allowed) {
  console.error(`Transfer refused, reason ${data.reason}`);
}
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `INVALID_INPUT` | `400` | `from` or `to` is missing or not a valid address |
| `CHECK_FAILED` | `500` | The register could not be read, or on a Trusset register `amount` or a balance is not a whole number |
