---
title: 'Revoke ID Link'
api: 'PUT /customers/api/id-links/{linkId}/revoke'
description: 'Stop a verification link from being opened'
---

Stops the hosted page from opening a link. Use it when a link went to the wrong person or the onboarding is cancelled.

<Warning>
  Revoking does not refund a fee the customer already paid, and no endpoint does.

  Revoking does not withdraw an identity check the customer already submitted. If that check passes afterwards, the link still turns `COMPLETED` and its wallet is still queued for on-chain registration. A failed check turns it `REJECTED`. Check the link again before treating the onboarding as stopped, and close a queued row with [Dismiss Pending Verification](/endpoints/customers/dismiss-pending-verification).
</Warning>

The link's status becomes `EXPIRED` and `expiresAt` is set to the time of revocation. There is no separate revoked status, so a revoked link lists as `EXPIRED`.

Nothing else changes. The customer record, a queued registration and any on-chain identity stay as they are. A wallet already registered through the link is removed with [Revoke Identity](/endpoints/customers/revoke-identity).

A `COMPLETED` link cannot be revoked. A `REJECTED` link can be, and revoking an `EXPIRED` link succeeds again.

## Path Parameters

<ParamField path="linkId" type="string" required>
  The link `id` from [Create ID Link](/endpoints/customers/create-id-link) or [List ID Links](/endpoints/customers/list-id-links). Not the token.
</ParamField>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `NOT_FOUND` | `404` | No link with this ID exists on your instance |
| `ALREADY_COMPLETED` | `400` | The link is `COMPLETED` |
| `REVOKE_FAILED` | `500` | The link could not be updated |
