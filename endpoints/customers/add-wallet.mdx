---
title: 'Add Wallet'
api: 'POST /customers/api/manage/{customerId}/wallets'
description: 'Link an additional wallet to a customer record'
---

Attaches another wallet to a customer. A wallet can belong to one customer per instance, so linking one that is already in use is refused rather than moved.

Returns `201` on success.

## Path Parameters

<ParamField path="customerId" type="string" required>Customer record ID.</ParamField>

## Body Parameters

<ParamField body="walletAddress" type="string" required>The wallet to link. Stored checksummed.</ParamField>

<ParamField body="label" type="string">A label for the wallet, for your own reference. Trimmed and cut to 80 characters. A value that is not a string is dropped.</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="id" type="string">The link record ID. Use it to recognise the row on [List Wallets](/endpoints/customers/list-wallets).</ResponseField>
    <ResponseField name="address" type="string">The linked wallet, checksummed.</ResponseField>
    <ResponseField name="label" type="string">The label, or `null`.</ResponseField>
    <ResponseField name="isPrimary" type="boolean">Always `false`.</ResponseField>
    <ResponseField name="addedAt" type="string">ISO 8601.</ResponseField>
    <ResponseField name="addedBy" type="string">The issuer account that linked it.</ResponseField>
  </Expandable>
</ResponseField>

<Note>
  Linking a wallet is a record-keeping act. It does not verify the wallet on the identity registry, and a linked wallet holds no claims of its own until it is verified. Use [Verify Identity](/endpoints/customers/verify-identity) for that. Verify Identity records the wallet it verifies as the primary of a customer record, and it does not look at links. Verifying a linked wallet therefore creates a second record for it. Promote the wallet first with [Promote Wallet](/endpoints/customers/promote-wallet) to keep one record.
</Note>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `INVALID_ADDRESS` | `400` | `walletAddress` is missing or malformed |
| `NOT_FOUND` | `404` | No such customer on your instance, or the record is archived |
| `ALREADY_PRIMARY` | `409` | The wallet is already this customer's primary |
| `WALLET_ALREADY_LINKED` | `409` | The wallet is already linked to this customer |
| `WALLET_IN_USE` | `409` | The wallet is another active customer's primary, or is linked to another customer, archived ones included |
| `ADD_FAILED` | `500` | The link could not be written |
