---
title: 'List Customers'
api: 'GET /customers/api/manage'
description: 'Retrieve customers for the authenticated instance'
---

Returns a page of the customer records on your instance, newest first. By default, archived customers are excluded.

## Query Parameters

<ParamField query="search" type="string">
  Case-insensitive substring match on `walletAddress`, `name`, `externalId`, `referenceKey` and `companyUrl`. Only primary wallets are searched. To find a customer by a linked wallet, use [Get Customer](/endpoints/customers/get).
</ParamField>

<ParamField query="customerType" type="string">
  `INDIVIDUAL` or `COMPANY` to return only that type. Any other value is ignored.
</ParamField>

<ParamField query="includeArchived" type="string" default="false">
  Set to `true` to include archived customers in results.
</ParamField>

<ParamField query="limit" type="integer" default="100">
  Number of results per page. Values above 200 are capped at 200.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of results to skip for pagination.
</ParamField>

## Response Fields

<ResponseField name="success" type="boolean">Request status</ResponseField>
<ResponseField name="data" type="array">
  Customer records with the fields listed on [Get Customer](/endpoints/customers/get), without its linked wallets, members and audit entries. Each record adds two objects of its own.
  <Expandable>
    <ResponseField name="sumsubApplicant" type="object">`applicantId`, `reviewStatus` and `reviewAnswer`, or `null`.</ResponseField>
    <ResponseField name="company" type="object">For an individual linked to a company: its `id`, `name` and `companyUrl`. Otherwise `null`.</ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="metadata" type="object">
  <Expandable>
    <ResponseField name="total" type="integer">Total matching customers</ResponseField>
    <ResponseField name="requestId" type="string">Unique request identifier</ResponseField>
    <ResponseField name="timestamp" type="string">ISO 8601 response timestamp</ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/customers/api/manage?limit=20&search=acme" \
  -H "X-API-Key: trusset_abc123xy_secret..."
```
```typescript TypeScript
const params = new URLSearchParams({ limit: '20', search: 'acme' });

const response = await fetch(
  `https://api.trusset.org/customers/api/manage?${params}`,
  { headers: { 'X-API-Key': 'trusset_abc123xy_secret...' } }
);
const { data: customers, metadata } = await response.json();
```
</RequestExample>

| Code | HTTP | Cause |
