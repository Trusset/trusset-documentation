---
title: 'Issue SDK Token'
api: 'POST /customers/api/onboarding/{customer}/token'
description: 'A fresh Sumsub access token for the identity check of an onboarding'
---

Returns a Sumsub access token for the identity check of the onboarding. Pass it to the Sumsub WebSDK or MobileSDK in your app. [Start Onboarding](/endpoints/customers/start-onboarding) already hands out the first token, so call this from the SDK's token expiration handler, or when the customer comes back later.

The token is valid for 20 minutes. Every token is issued for the same applicant, so a customer who stopped halfway continues where they left off.

A token is issued while the check is open: the status is `IDENTITY_CHECK`, `RESUBMISSION` or `IN_REVIEW`. Once the review has settled, no token is issued.

## Path Parameters

<ParamField path="customer" type="string" required>
  The customer `id`, your `externalId`, the reference key or a wallet address of the customer.
</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="token" type="string">The Sumsub access token. Pass it to the SDK as is.</ResponseField>
    <ResponseField name="expiresInSeconds" type="integer">`1200`.</ResponseField>
    <ResponseField name="levelName" type="string">The Sumsub level of the check. A review from any other level is refused.</ResponseField>
    <ResponseField name="applicantType" type="string">`company` for a `COMPANY` profile, otherwise `individual`.</ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.trusset.org/customers/api/onboarding/client-48213/token" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const issueToken = async (): Promise<string> => {
  const response = await fetch(
    'https://api.trusset.org/customers/api/onboarding/client-48213/token',
    { method: 'POST', headers: { 'X-API-Key': 'trusset_your_key_here' } }
  );
  const { success, data, error } = await response.json();
  if (!success) throw new Error(`${error.code}: ${error.message}`);
  return data.token;
};
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `ALREADY_USED` | `400` | The identity check is complete |
| `EXPIRED` | `400` | The check was cancelled or is past `identityCheck.expiresAt`. Start the onboarding again |
| `COUNTRY_BLOCKED` | `403` | The profile now blocks the customer's country |
| `CUSTOMER_NOT_FOUND` | `404` | No customer of your instance matches `customer` |
| `NO_IDENTITY_CHECK` | `409` | The onboarding runs through a KYC source, or was not started |
| `LINK_REJECTED` | `409` | The identity check was refused or rejected |
| `SUMSUB_LEVEL_UNKNOWN` | `409` | The profile names a Sumsub level that does not exist |
| `RATE_LIMIT_EXCEEDED` | `429` | More than 120 onboarding writes in the minute |
| `ONBOARDING_TOKEN_FAILED` | `500` | The token could not be issued |
| `KYC_UNAVAILABLE` | `503` | The Trusset identity check is not available |
| `SUMSUB_UNAVAILABLE` | `503` | Sumsub did not issue a token. Retry shortly |
