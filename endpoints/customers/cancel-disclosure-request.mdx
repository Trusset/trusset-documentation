---
title: 'Cancel Disclosure Request'
api: 'POST /customers/api/disclosure-requests/{id}/cancel'
description: 'Withdraw an open disclosure request before the holder answers'
---

Withdraws an open disclosure request. The holder can no longer answer it, and it leaves their list of open requests on verify.trusset.org.

Only an `OPEN` request can be cancelled. An approved request stays approved, and its consent and disclosure stay readable through [Get Disclosure Request](/endpoints/customers/get-disclosure-request).

The check looks at the status, not at the expiry. A request past `expiresAt` that no read has marked `EXPIRED` yet is cancelled rather than refused.

## Path Parameters

<ParamField path="id" type="string" required>
  The request `id`. Letters and digits only, at most 100 characters.
</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  The request with `status` set to `CANCELLED`, in the shape [Create Disclosure Request](/endpoints/customers/create-disclosure-request) returns. `respondedAt` is still `null` in this response. A later read shows the cancellation time.
</ResponseField>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `VALIDATION_ERROR` | `400` | `id` contains characters other than letters and digits, or is longer than 100 characters |
| `NOT_FOUND` | `404` | No request with this ID was made by your instance |
| `REQUEST_CLOSED` | `409` | The request is not `OPEN`, or the holder answered it while the cancellation was being written |
| `CANCEL_DISCLOSURE_REQUEST_FAILED` | `500` | The request could not be cancelled |
