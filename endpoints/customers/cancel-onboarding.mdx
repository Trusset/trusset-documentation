---
title: 'Cancel Onboarding'
api: 'POST /customers/api/onboarding/{customer}/cancel'
description: 'Close a running onboarding before it finishes'
---

Closes a running onboarding. Use it when a customer abandons verification, or before you start again under another profile or provider.

| Onboarding | Cancel |
|---|---|
| `TRUSSET`, check open and not yet approved | Revokes the identity check. A review that arrives later changes nothing |
| `TRUSSET`, `AWAITING_SIGNATURE` for the registration | Dismisses the registration from the [pending queue](/endpoints/customers/list-pending-verifications), so it can no longer be signed |
| `KYC_SOURCE`, no record delivered yet | Stops waiting for the record |
| Any other running onboarding | Refused with `409 CANNOT_CANCEL` |

An onboarding that is not running answers `200` with `cancelled: false` and stays as it is. Cancelling removes nothing from a register: an identity your wallet already registered stays until you revoke it with [Revoke Identity](/endpoints/customers/revoke-identity).

A cancelled identity check reads `EXPIRED` afterwards, with `reason.code` `CHECK_CANCELLED` or `REGISTRATION_DISMISSED`. [Start Onboarding](/endpoints/customers/start-onboarding) opens a new one.

## Path Parameters

<ParamField path="customer" type="string" required>
  The customer `id`, your `externalId`, the reference key or a wallet address of the customer.
</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="cancelled" type="boolean">`false` when nothing was running.</ResponseField>
    <ResponseField name="onboarding" type="object">The onboarding after the call.</ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.trusset.org/customers/api/onboarding/client-48213/cancel" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const response = await fetch(
  'https://api.trusset.org/customers/api/onboarding/client-48213/cancel',
  { method: 'POST', headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { data } = await response.json();
console.log(data.cancelled, data.onboarding.status);
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `CUSTOMER_NOT_FOUND` | `404` | No customer of your instance matches `customer` |
| `CANNOT_CANCEL` | `409` | The identity check was submitted through the hosted page or approved, the identity is registered, or a sealed record was delivered. Reject a delivered record with [Decide Record](/endpoints/customers/decide-onboarding-record) |
| `RATE_LIMIT_EXCEEDED` | `429` | More than 120 onboarding writes in the minute |
| `ONBOARDING_CANCEL_FAILED` | `500` | The cancel failed on the server |
