---
title: 'List Disclosure Requests'
api: 'GET /customers/api/disclosure-requests'
description: 'List the disclosure requests your instance has made'
---

Returns the disclosure requests your instance has made, newest first. Requests made in the Issuer Portal are included.

Before the list is read, every open request of your instance past its `expiresAt` is marked `EXPIRED`, so the statuses are current. The items carry no consent or disclosure. Fetch an approved request with [Get Disclosure Request](/endpoints/customers/get-disclosure-request) to read them.

## Query Parameters

<ParamField query="status" type="string">
  `OPEN`, `APPROVED`, `DECLINED`, `EXPIRED` or `CANCELLED`, in any case.
</ParamField>

<ParamField query="walletAddress" type="string">
  Only requests to this wallet, matched in any case. Send it lowercase or correctly checksummed.
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Requests per page, from 1 to 100. A missing, zero or non-numeric value gives 50, and a larger one is capped at 100.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Requests to skip.
</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="items" type="array">
      The requests, each with the fields of [Create Disclosure Request](/endpoints/customers/create-disclosure-request): `id`, `walletAddress`, `scope`, `scopeLabel`, `referenceUrl`, `message`, `status`, `environment`, `createdAt`, `expiresAt`, `respondedAt` and `proofLevel`.
    </ResponseField>
    <ResponseField name="pagination" type="object">
      `total`, the requests matching the filters, and the `limit` and `offset` that were applied.
    </ResponseField>
  </Expandable>
</ResponseField>

<Note>
  Pagination sits inside `data` here, unlike the lists under `/manage` and `/id-links`, which put `total` in `metadata`.
</Note>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/customers/api/disclosure-requests?status=APPROVED&limit=20" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const params = new URLSearchParams({ status: 'APPROVED', limit: '20' });

const response = await fetch(
  `https://api.trusset.org/customers/api/disclosure-requests?${params}`,
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { data } = await response.json();
const { items, pagination } = data;
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `VALIDATION_ERROR` | `400` | `status` is not one of the five states |
| `INVALID_ADDRESS` | `400` | `walletAddress` is not `0x` and 40 hex characters |
| `LIST_DISCLOSURE_REQUESTS_FAILED` | `500` | The requests could not be read. A mixed-case `walletAddress` with a wrong checksum also ends here |
