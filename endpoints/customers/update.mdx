---
title: 'Update Customer'
api: 'PUT /customers/api/manage/{customerId}'
description: 'Update an existing customer record'
---

Updates fields on an existing customer. Only the provided fields are modified; omitted fields remain unchanged. Fields not listed below, such as `externalId`, are ignored.

<Warning>
  The `walletAddress` and `status` fields change the record only, never the registry. A new wallet address replaces the primary outright. The old primary is dropped rather than kept as a linked wallet. The record's `status`, `verifiedAt` and `kycHash` stay as they were. Sending `null` removes the primary.

  These fields can still reach the registry later. When the instance switches identity registers, each `verified` record that holds a `kycHash` is queued for registration on the new register, with that `kycHash`, under its current primary.

  To swap primaries and keep the old one, use [Add Wallet](/endpoints/customers/add-wallet) and then [Promote Wallet](/endpoints/customers/promote-wallet).
</Warning>

## Path Parameters

<ParamField path="customerId" type="string" required>
  Customer ID.
</ParamField>

## Body Parameters

<ParamField body="name" type="string">
  Updated display name.
</ParamField>

<ParamField body="country" type="string">
  ISO 3166-1 alpha-2, alpha-3 or numeric code, stored as alpha-3. `null` or an empty string clears it.
</ParamField>

<ParamField body="investorType" type="string">
  The same values as on [Create Customer](/endpoints/customers/create): a preset or the key of one of your custom [verification profiles](/endpoints/customers/list-verification-profiles), in any letter case, stored as the profile spells it. `null`, an empty string, or the record's current type in another letter case leaves the type as it is. Anything else, a number included, is refused with `INVALID_INVESTOR_TYPE`.
</ParamField>

<ParamField body="walletAddress" type="string">
  Replaces the primary wallet. Stored checksummed. Read the warning above before sending it.
</ParamField>

<ParamField body="status" type="string">
  Written to the record as sent. It is not checked against the registry or against the values the platform itself writes: `pending`, `verified`, `revoked` and `rejected`.
</ParamField>

<ParamField body="metadata" type="object">
  Updated metadata. Replaces existing metadata entirely. The platform keeps `idLinks` here, the ID links created for this customer, and on an ERC-3643 register also `onchainId` and `onchainIdTxHash`. Carry all three over. Without `idLinks`, an older ID link no longer finds this customer when it completes, and can create a second record or be refused. Without the ONCHAINID fields, registering a wallet that is not yet on the register plans a new ONCHAINID deployment instead of reusing the one already deployed.
</ParamField>

<ParamField body="avatarUrl" type="string">
  A base64 data URL of a PNG, JPEG, WEBP or GIF image, up to 250,000 characters. Stored as `metadata.avatarUrl`. `null` or an empty string removes it.
</ParamField>

<ParamField body="contactChannels" type="string[]">
  Replaces the list. Up to 20 strings of up to 200 characters each, trimmed, with blank entries dropped and duplicates removed ignoring case. `null` empties it.
</ParamField>

<ParamField body="companyUrl" type="string">
  Company records only. Normalised as on [Create Customer](/endpoints/customers/create). `null` or an empty string clears it.
</ParamField>

<ParamField body="companyId" type="string">
  Individual records only. The ID of a company record on your instance that is not archived. `null` or an empty string unlinks it.
</ParamField>

<ParamField body="customerType" type="string">
  Accepted only when it matches the record's current type. A different value is refused with `TYPE_IMMUTABLE`.
</ParamField>

When `country` or `investorType` is sent, the resulting pair is checked. A country on the blocked-country list of the profile that `investorType` names is refused with `COUNTRY_BLOCKED`.

## Response Fields

<ResponseField name="success" type="boolean">Request status</ResponseField>
<ResponseField name="data" type="object">The updated customer record, with the fields listed on [Get Customer](/endpoints/customers/get) other than its linked wallets, company links, Sumsub applicant record and audit entries.</ResponseField>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `INVALID_COUNTRY` | `400` | `country` is not an ISO 3166-1 code |
| `INVALID_INVESTOR_TYPE` | `400` | `investorType` names neither a preset nor one of your verification profiles, or is not a string |
| `TYPE_IMMUTABLE` | `400` | `customerType` differs from the record's type |
| `INVALID_COMPANY_URL` | `400` | `companyUrl` was sent for an individual, or is not a usable URL |
| `COMPANY_URL_TOO_LONG` | `400` | `companyUrl` is over 300 characters |
| `COMPANY_CANNOT_LINK` | `400` | `companyId` was sent for a company |
| `INVALID_COMPANY` | `400` | `companyId` is not a string of 20 to 40 characters, or is the record's own ID |
| `INVALID_ADDRESS` | `400` | `walletAddress` is not a valid address |
| `INVALID_CONTACT_CHANNELS` | `400` | `contactChannels` is not an array |
| `TOO_MANY_CONTACT_CHANNELS` | `400` | More than 20 contact channels |
| `INVALID_CONTACT_CHANNEL` | `400` | A contact channel is not a string |
| `CONTACT_CHANNEL_TOO_LONG` | `400` | A contact channel is over 200 characters |
| `INVALID_AVATAR` | `400` | `avatarUrl` is not a base64 PNG, JPEG, WEBP or GIF data URL |
| `COUNTRY_BLOCKED` | `403` | The resulting `country` is on the blocked-country list of the profile the resulting `investorType` names |
| `NOT_FOUND` | `404` | No such customer on your instance, or the record is archived |
| `COMPANY_NOT_FOUND` | `404` | `companyId` names no company record on your instance that is not archived |
| `CUSTOMER_EXISTS` | `409` | `walletAddress` is another active customer's primary or another customer's linked wallet |
| `AVATAR_TOO_LARGE` | `413` | `avatarUrl` is over 250,000 characters |
| `UPDATE_FAILED` | `500` | The update could not be written |
