---
title: 'Get KYC Record'
api: 'GET /customers/api/kyc-records/{recordId}'
description: 'One sealed KYC record with its state and whitelists'
---

Returns one sealed KYC record: its clear header fields, its status, the whitelists bound to its source and the next step that is yours. The KYC file itself is not returned. While the record is `RECEIVED`, [Download Envelope](/endpoints/customers/get-kyc-record-envelope) returns its ciphertext.

## Path Parameters

<ParamField path="recordId" type="string" required>
  The record `id` from [List KYC Records](/endpoints/customers/list-kyc-records), or the `recordId` of a `customer.kyc_record_received` event.
</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="record" type="object">The record, with the fields described on [List KYC Records](/endpoints/customers/list-kyc-records#response-fields).</ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/customers/api/kyc-records/cmhw3k9t20007l80c5q2x7m4d" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/customers/api/kyc-records/${recordId}`,
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { data } = await res.json();

if (data.record.action === 'APPROVE') {
  // The file is in your records folder. Review it, then approve or reject.
}
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `RECORD_NOT_FOUND` | `404` | No KYC record with this ID belongs to your instance |
| `RATE_LIMIT_EXCEEDED` | `429` | Your instance went over its budget of 240 KYC record reads per minute |
| `GET_KYC_RECORD_FAILED` | `500` | The record could not be read |
