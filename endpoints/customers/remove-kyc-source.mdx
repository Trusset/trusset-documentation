---
title: 'Remove KYC Source'
api: 'DELETE /customers/api/kyc-sources/{sourceId}'
description: 'End a source for good'
---

Removes a KYC source. Its status becomes `REVOKED`, its token stops working, and every call to its inbox answers `401 UNAUTHORIZED` from then on. The source stays in [List KYC Sources](/endpoints/customers/list-kyc-sources) with its records.

<Warning>
  Removal is final. A removed source cannot be changed, invited again or made active. To stop deliveries for a while, set `status: PAUSED` with [Update KYC Source](/endpoints/customers/update-kyc-source) instead.

  A removed source can no longer revoke the records it delivered, because its inbox is closed. Its whitelists also stop being bound to it: [Set Whitelist Members](/endpoints/lending/set-access-list-members) no longer asks for a record on a list that only this source was bound to, unless the instance that keeps the list bound a source of its own. Its records no longer count on any whitelist: approving one of them is the decision only and builds no listing. Wallets already listed stay listed until you remove them.
</Warning>

The records the source delivered are kept. A removed source's name and signing key are free to use for a new source. Removing a source that is already removed answers with the source unchanged.

## Path Parameters

<ParamField path="sourceId" type="string" required>
  The source `id` from [List KYC Sources](/endpoints/customers/list-kyc-sources).
</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="source" type="object">The source, as on [List KYC Sources](/endpoints/customers/list-kyc-sources), with `status: REVOKED` and `tokenHint: "----"`.</ResponseField>
  </Expandable>
</ResponseField>

<Note>
  The removal is written to the customer audit log as `KYC_SOURCE_REVOKED`.
</Note>

<RequestExample>
```bash cURL
curl -X DELETE "https://api.trusset.org/customers/api/kyc-sources/cmhw2a6r10003l80c9d4h1n8v" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const res = await fetch(
  `https://api.trusset.org/customers/api/kyc-sources/${sourceId}`,
  { method: 'DELETE', headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { data } = await res.json();
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `SOURCE_NOT_FOUND` | `404` | No KYC source with this ID belongs to your instance |
| `RATE_LIMIT_EXCEEDED` | `429` | Your instance went over its budget of 20 KYC source writes per minute |
| `REMOVE_KYC_SOURCE_FAILED` | `500` | The source could not be removed |
