---
title: 'Resend ID Link'
api: 'POST /customers/api/id-links/{linkId}/resend'
description: 'Deliver an existing verification link again by email or SMS'
---

Sends an existing link to its recipient again. The URL is the same one, and the link's expiry does not move.

A link past its `expiresAt` that was never revoked still reads `PENDING`, and it is re-sent although the hosted page refuses it. Check `expiresAt` first, and [create a new link](/endpoints/customers/create-id-link) if it has passed.

## Path Parameters

<ParamField path="linkId" type="string" required>
  The link `id`, not the token.
</ParamField>

## Body Parameters

<ParamField body="channels" type="string[]" required>
  A non-empty array of `email`, `sms`, or both. Email goes to the link's `recipientEmail` and SMS to its `recipientPhone`. A channel whose recipient is missing is skipped, and other values are ignored, so the call can succeed with nothing sent.
</ParamField>

The email states the days left before the link expires, rounded up and never below one. The SMS uses the link's `customMessage` when it has one.

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="verificationUrl" type="string">The URL that was sent.</ResponseField>
    <ResponseField name="delivery" type="object">
      One entry per channel attempted, each `{ sent, error }` with `error` present only on failure. Empty when no channel was attempted. For email, `sent: true` does not confirm delivery, because a refusal by the mail provider is not reported here.
    </ResponseField>
  </Expandable>
</ResponseField>

  -H "X-API-Key: trusset_your_key_here" \

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `INVALID_INPUT` | `400` | `channels` is missing, not an array, or empty |
| `NOT_FOUND` | `404` | No link with this ID exists on your instance |
| `INVALID_STATE` | `400` | The link was consumed, is `COMPLETED`, or was revoked |
| `RESEND_FAILED` | `500` | The link could not be read. A failed send is reported in `delivery` instead |
