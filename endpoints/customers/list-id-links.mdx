---
title: 'List ID Links'
api: 'GET /customers/api/id-links'
description: 'List the verification links created on your instance'
---

Returns the verification links created on your instance, newest first. Links created in the Issuer Portal are included.

The status alone does not tell you whether a link can still be used. A link that ran past `expiresAt` without being revoked still reads `PENDING`, and the hosted page refuses it. Compare `expiresAt` with the current time.

## Query Parameters

<ParamField query="status" type="string">
  Exact, case-sensitive match on the link status: `PENDING`, `COMPLETED`, `REJECTED` or `EXPIRED`. `EXPIRED` means revoked. Any other value returns an empty list.
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Links per page. Values above 200 are capped at 200.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Links to skip.
</ParamField>

## Response Fields

<ResponseField name="data" type="array">
  <Expandable>
    <ResponseField name="id" type="string">Link ID.</ResponseField>
    <ResponseField name="token" type="string">The 64 hex character secret in the URL.</ResponseField>
    <ResponseField name="verificationUrl" type="string">`https://verify.trusset.org/link/{token}`. Anyone holding it can open the link.</ResponseField>
    <ResponseField name="recipientEmail" type="string">Or `null`.</ResponseField>
    <ResponseField name="recipientWallet" type="string">The bound wallet, checksummed, or `null` until one is attached on the hosted page.</ResponseField>
    <ResponseField name="recipientPhone" type="string">Or `null`.</ResponseField>
    <ResponseField name="status" type="string">`PENDING`, `COMPLETED`, `REJECTED` or `EXPIRED`. `COMPLETED` alone is not a verdict: it is set when the customer finishes the hosted flow, and a failed check later turns it `REJECTED`.</ResponseField>
    <ResponseField name="note" type="string">Or `null`.</ResponseField>
    <ResponseField name="investorType" type="string">The verification profile key the link was created with.</ResponseField>
    <ResponseField name="country" type="string">ISO 3166-1 alpha-3, or `null`. After completion, the country the customer confirmed or the identity check reported.</ResponseField>
    <ResponseField name="expiresAt" type="string">ISO 8601. A revoked link carries its revocation time.</ResponseField>
    <ResponseField name="used" type="boolean">Whether the link was consumed.</ResponseField>
    <ResponseField name="usedAt" type="string">ISO 8601, or `null`.</ResponseField>
    <ResponseField name="createdAt" type="string">ISO 8601.</ResponseField>
    <ResponseField name="feeCents" type="integer">Or `null`.</ResponseField>
    <ResponseField name="currency" type="string">Or `null`.</ResponseField>
    <ResponseField name="paidAt" type="string">When the fee was paid, ISO 8601, or `null`.</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="metadata" type="object">
  <Expandable>
    <ResponseField name="total" type="integer">Links matching `status`, ignoring `limit` and `offset`.</ResponseField>
    <ResponseField name="requestId" type="string">Unique request identifier.</ResponseField>
    <ResponseField name="timestamp" type="string">ISO 8601 response timestamp.</ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl "https://api.trusset.org/customers/api/id-links?status=PENDING&limit=20" \
  -H "X-API-Key: trusset_your_key_here"
```
```typescript TypeScript
const params = new URLSearchParams({ status: 'PENDING', limit: '20' });

const response = await fetch(
  `https://api.trusset.org/customers/api/id-links?${params}`,
  { headers: { 'X-API-Key': 'trusset_your_key_here' } }
);
const { data: links, metadata } = await response.json();

const usable = links.filter(
  (link: { expiresAt: string }) => new Date(link.expiresAt) > new Date()
);
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `FETCH_FAILED` | `500` | The links could not be read, including when `limit` or `offset` is not a number |
