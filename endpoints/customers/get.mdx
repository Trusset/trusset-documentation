---
title: 'Get Customer'
api: 'GET /customers/api/manage/{identifier}'
description: 'Retrieve a single customer by ID, wallet, reference key or external ID'
---

Returns one customer record from your instance, with its linked wallets, company links and recent audit entries. Archived records are not returned.

## Path Parameters

<ParamField path="identifier" type="string" required>
  Resolved in this order. A valid address matches a linked wallet first, then a primary wallet, in any letter case. A value starting with `ref_` matches a `referenceKey`. A value of 20 to 30 characters is read as a customer ID. Anything else matches an `externalId`.
</ParamField>

<Note>
  Because a 20 to 30 character value is always read as an ID, a customer whose `externalId` has that length cannot be found by it. Look that customer up by ID, wallet or reference key instead. A mixed-case address with a wrong checksum is not a valid address, so it is matched as an `externalId` and usually answers `404`.
</Note>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="id" type="string">Customer ID.</ResponseField>
    <ResponseField name="instanceId" type="string">The instance the record belongs to.</ResponseField>
    <ResponseField name="issuerId" type="string">The issuer account that created the record.</ResponseField>
    <ResponseField name="walletAddress" type="string">The primary wallet, checksummed, or `null`.</ResponseField>
    <ResponseField name="externalId" type="string">Your own reference, or `null`.</ResponseField>
    <ResponseField name="name" type="string">Display name, or `null`.</ResponseField>
    <ResponseField name="country" type="string">ISO 3166-1 alpha-3 code such as `DEU`, or `null`. An older record can still hold the value as it was first stored, such as an alpha-2 code.</ResponseField>
    <ResponseField name="investorType" type="string">The key of the [verification profile](/endpoints/customers/list-verification-profiles) the customer is classed under. Defaults to `RETAIL`.</ResponseField>
    <ResponseField name="customerType" type="string">`INDIVIDUAL` or `COMPANY`.</ResponseField>
    <ResponseField name="companyUrl" type="string">A company record's website, or `null`.</ResponseField>
    <ResponseField name="companyId" type="string">For an individual, the ID of the company record it belongs to, or `null`.</ResponseField>
    <ResponseField name="status" type="string">`pending`, `verified`, `revoked` or `rejected`, as the platform last recorded it, or whatever value [Update Customer](/endpoints/customers/update) last wrote. This is not a registry read. For the live answer, use [Identity Status](/endpoints/customers/identity-status).</ResponseField>
    <ResponseField name="frozen" type="boolean">Whether the record is marked frozen.</ResponseField>
    <ResponseField name="kycHash" type="string">The KYC hash recorded when the identity was verified, or `null`.</ResponseField>
    <ResponseField name="onChainTxHash" type="string">The verification transaction the platform recorded, or `null`.</ResponseField>
    <ResponseField name="sumsubApplicantId" type="string">The Sumsub applicant ID, or `null`.</ResponseField>
    <ResponseField name="idLinkId" type="string">The [ID link](/endpoints/customers/create-id-link) most recently created for this customer or completed by them, or `null`.</ResponseField>
    <ResponseField name="referenceKey" type="string">Set when the record was created without a wallet, and kept after a wallet is linked. Otherwise `null`.</ResponseField>
    <ResponseField name="contactChannels" type="string[]">Contact channels, possibly empty.</ResponseField>
    <ResponseField name="metadata" type="object">Your metadata, or `null`.</ResponseField>
    <ResponseField name="archived" type="boolean">Always `false` here.</ResponseField>
    <ResponseField name="archivedAt" type="string">ISO 8601, or `null`.</ResponseField>
    <ResponseField name="verifiedAt" type="string">ISO 8601, or `null`.</ResponseField>
    <ResponseField name="revokedAt" type="string">ISO 8601, or `null`.</ResponseField>
    <ResponseField name="onChainSyncedAt" type="string">When the record was last reconciled with the registry, or `null`.</ResponseField>
    <ResponseField name="createdAt" type="string">ISO 8601.</ResponseField>
    <ResponseField name="updatedAt" type="string">ISO 8601.</ResponseField>
    <ResponseField name="linkedWallets" type="array">Additional wallets, oldest first, each with `id`, `walletAddress`, `label`, `addedAt` and `addedBy`. The primary is not in this list.</ResponseField>
    <ResponseField name="company" type="object">For an individual linked to a company: its `id`, `name`, `companyUrl` and `archived`. Otherwise `null`.</ResponseField>
    <ResponseField name="members" type="array">For a company: up to 100 individuals linked to it that are not archived, oldest first, each with `id`, `name`, `walletAddress`, `status`, `country` and `createdAt`.</ResponseField>
    <ResponseField name="sumsubApplicant" type="object">The Sumsub applicant record, including the provider's raw payload in `rawData`, or `null`.</ResponseField>
    <ResponseField name="auditLogs" type="array">The 20 most recent audit entries, newest first, each with `id`, `instanceId`, `customerId`, `walletAddress`, `action`, `performedBy`, `metadata` and `timestamp`.</ResponseField>
  </Expandable>
</ResponseField>

```bash cURL
curl "https://api.trusset.org/customers/api/manage/0xaBc123DEf456789012345678901234567890aBCD" \
  -H "X-API-Key: trusset_abc123xy_secret..."
```
```typescript TypeScript
const response = await fetch(
  'https://api.trusset.org/customers/api/manage/0xaBc123DEf456789012345678901234567890aBCD',
  { headers: { 'X-API-Key': 'trusset_abc123xy_secret...' } }
);
const { data: customer } = await response.json();
```

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `NOT_FOUND` | `404` | Nothing on your instance matches `identifier`, or the match is archived |
| `FETCH_FAILED` | `500` | The record could not be read |
