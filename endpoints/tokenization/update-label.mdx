---
title: 'Update Label'
api: 'PUT /external-tokens/api/{tokenAddress}/label'
description: 'Set or clear the label on an imported token'
---

Sets the label on an import record, or clears it. A label is your own short text for grouping imports, for example `Real estate`. It is private to your instance and carries no meaning on chain. Removing the import removes its label.

An instance keeps at most 50 different labels.

## Path Parameters

<ParamField path="tokenAddress" type="string" required>The imported contract address.</ParamField>

## Body Parameters

<ParamField body="label" type="string" required>
  Text of at most 40 characters, without angle brackets and without control or invisible characters (a zero-width space, a blank filler such as U+3164 or U+2800). Whitespace is collapsed and trimmed before the label is stored.

  Send `null` to clear the label. An empty string clears it as well.

  Only the `label` field is accepted.
</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="tokenAddress" type="string">The address of the import.</ResponseField>
    <ResponseField name="label" type="string">The stored label, or `null` when cleared.</ResponseField>
    <ResponseField name="previousLabel" type="string">The label before this call, or `null` when there was none.</ResponseField>
    <ResponseField name="updatedAt" type="string">ISO 8601 timestamp of the write.</ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl -X PUT "https://api.trusset.org/external-tokens/api/0x9f8c1d4b2e7a3056c1b8f4d29e0a7c3518b6d24f/label" \
  -H "X-API-Key: trusset_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{"label": "Real estate"}'
```
```typescript TypeScript
await fetch(
  `https://api.trusset.org/external-tokens/api/${tokenAddress}/label`,

```
</RequestExample>

## Rate Limit

Strict: 10 requests per minute.

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `INVALID_LABEL` | `400` | `label` is not text of at most 40 characters, or carries an angle bracket or a control or invisible character. Send `null` to clear |
| `LABEL_LIMIT_REACHED` | `400` | Your instance already keeps 50 different labels |
| `IMPORT_NOT_FOUND` | `404` | No active import for that address on your instance |
| `LABELS_UNAVAILABLE` | `503` | Labels are unavailable just now |
