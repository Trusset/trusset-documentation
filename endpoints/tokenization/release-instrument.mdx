---
title: 'Release Instrument'
api: 'DELETE /instruments/api/{tokenAddress}'
description: 'Stop standing behind an instrument record'
---

Releases the instrument record your instance asserts. The record stays readable for every lender with its values and their provenance, but no instance stands behind it any more, and your published profile keeps only its overview. The token's controller can then take it over, through an instance it controls or through the [issuer-signed flow](/endpoints/tokenization/issuer-signed-record).

Only the asserting instance can release, and a release needs no signature.

## Path Parameters

<ParamField path="tokenAddress" type="string" required>The token contract address.</ParamField>

## Response Fields

<ResponseField name="data" type="object">
  <Expandable>
    <ResponseField name="released" type="boolean">Always `true`.</ResponseField>
    <ResponseField name="instrument" type="object">The record after the release, with `released: true`.</ResponseField>
    <ResponseField name="note" type="string">What the release changes.</ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl -X DELETE "https://api.trusset.org/instruments/api/0x9f8c1d4b2e7a3056c1b8f4d29e0a7c3518b6d24f" \
  -H "X-API-Key: trusset_your_key_here"
```
</RequestExample>

## Error Codes

| Code | HTTP | Cause |
|---|---|---|
| `INVALID_ADDRESS` | `400` | `tokenAddress` is not a valid address |
| `NOT_INSTRUMENT_ASSERTER` | `403` | Your instance does not assert the record |
| `INSTRUMENT_NOT_FOUND` | `404` | No record exists for the token on this chain |
| `INSTRUMENT_WRITE_CONFLICT` | `409` | Another write landed first. Read the record and retry |
